# Provider watch — 2026-08-25

- **Deepgram's `extra`/`addons` escape hatch is a crash path** — the only `high` item this run. Any key `deepgram-sdk`'s `connect()` does not declare raises inside the connection handler, is retried three times, and retires the service mid-call; `filler_words` and `measurements` are unreachable as a result. Needs a call on forwarding undeclared keys as query params versus rejecting them at construction.
- **Four draft PRs are ready to review**, each a small self-contained change: [#5429](https://github.com/pipecat-ai/pipecat/pull/5429) Anthropic adaptive thinking, [#5430](https://github.com/pipecat-ai/pipecat/pull/5430) Cartesia `normalization`, [#5431](https://github.com/pipecat-ai/pipecat/pull/5431) ElevenLabs `eleven_v3_conversational` 400 fix, [#5432](https://github.com/pipecat-ai/pipecat/pull/5432) OpenAI `"max"` reasoning effort.
- **Three default bumps were held back on latency, not novelty** — `claude-sonnet-5`, `gemini-3.7-flash` and the `gpt-5.6` tiers are all GA successors that probed slower to first token than the current defaults. Each needs a maintainer's call on the latency/quality trade for voice; the Gemini and Anthropic ones also turn on reasoning by default.
- **Two SDK pins now exclude their provider's current major** — `anthropic<1` (1.0.0, 2026-08-20) and `openai<3` (3.3.1, 2026-08-19). Neither bump is mechanical: SDK 1.0 drops the sampling parameters the Anthropic service always sends, and openai 3.0 stops installing `httpx`, which `_create_client` imports.
- **Deprecated sampling parameters are still forwarded silently.** Gemini 3.6+ ignores `temperature`/`top_p`/`top_k`, and Claude Opus 4.7+ rejects them with a 400 — in both services a user carrying settings across a model switch gets a no-op or a failed turn with no warning.

**7 units researched** — 4 PRs, 0 branches, 26 changes to consider, 0 errors, 0 with nothing new.
