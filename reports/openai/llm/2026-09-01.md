# OpenAI LLM — 2026-09-01

Nothing is breaking today, but `temperature`/`max_tokens` are unusable with the entire current OpenAI lineup, and the default is a model OpenAI no longer lists.

## What's new for Pipecat

### PRs
Nothing.

### To consider

- **`temperature` and `max_tokens` 400 on gpt-5.x** (high, since 2026-09-01) — `Settings.temperature=0.7` on `gpt-5.6-terra` returns `unsupported_value` ("Only the default (1) value is supported") and `Settings.max_tokens=200` returns `unsupported_parameter` ("Use 'max_completion_tokens' instead"); the pipeline then marks the service unusable. Both fields are inherited `LLMSettings`, so any user who sets them and picks a current model hits this. — *Needs a call: whether the service should drop `temperature` and map `max_tokens` to `max_completion_tokens` for reasoning models, or surface a clearer error.*
- **Default is a generation behind** (medium, since 2026-09-01) — OpenAI's models page now recommends gpt-5.6-sol (flagship), gpt-5.6-terra (balanced) and gpt-5.6-luna (cost); gpt-4.1 no longer appears there, though it is not deprecated and the API still serves it. aiewf-eval medium-context: gpt-5.6-terra (medium) 97.8% / 927 ms P50 vs gpt-4.1 96.3% / 536 ms; luna (none) is 88.3%, below the current default. Our probe agrees on latency: terra 619 ms vs gpt-4.1 314 ms median TTFAT on a trivial turn, and forcing `reasoning_effort=none` only gets terra to 578 ms — the short-turn gap is the model, not reasoning. On a river-crossing prompt terra is the faster one (519 vs 572 ms). — *Needs a call: whether roughly doubled TTFAT on short turns buys enough quality, and which gpt-5.6 tier becomes the default.*
- **openai SDK pin stops at 2.x** (medium, since 2026-09-01) — `pyproject.toml` pins `openai>=1.74.0,<3`; PyPI is at 3.6.0. openai 3.0.0 (2026-08-12) switches to HTTPX2 and no longer installs httpx, and `create_client` passes a `DefaultAsyncHttpxClient` built from `httpx.Limits`. — *Needs a call: HTTPX2 migration is repo-wide, not an openai/llm change.*
- **gpt-4o pinned in an example** (low, since 2026-09-01) — `examples/transports/transports-moq.py` is the only example that passes `model=` to `OpenAILLMService`, and it names gpt-4o. — *Needs a call: whether examples should pin a model at all rather than track the service default.*
