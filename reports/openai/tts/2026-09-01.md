# OpenAI TTS — 2026-09-01

Nothing is retiring and the default is right: OpenAI still calls `gpt-4o-mini-tts` its newest and most reliable TTS model, and no speech model appears on the deprecation table. The one capability gap is custom voices, which our allowlist blocks.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Custom voices blocked by the allowlist** (medium, since 2026-09-01) — `/v1/audio/speech` accepts a custom voice object `{"id": "voice_1234"}` alongside the 13 built-in names (custom voices shipped 2025-12-15 for eligible customers, usable from the TTS, Realtime and Chat Completions APIs). `run_tts` checks `voice not in VALID_VOICES` and yields an `ErrorFrame` first, so a custom voice ID never reaches OpenAI — probed with `voice=voice_abc123`, which failed client-side with no audio. — *Needs a call: whether to pass unknown voice strings (and the `{id: ...}` shape) through and drop the client-side typo check; there is no way to probe a real custom voice from this account.*
- **SDK pin behind openai 3.x** (medium, since 2026-08-25) — `openai>=1.74.0,<3` in `pyproject.toml` against 3.6.0 on PyPI (2026-08-28). Carried over from the openai/responses-llm report: openai-python 3.0.0 makes HTTPX2 the default client and no longer installs httpx, which this service's `http_client` argument documents users into. — *Needs a call: whether Pipecat migrates to HTTPX2; until then the pin cannot simply be widened.*
- **Default voice** (low, since 2026-09-01) — the text-to-speech guide recommends `marin` or `cedar` for best quality; we default to `alloy`. Both are in the allowlist already, so this is only a default. — *Needs a call: changing it changes what existing users hear.*

Not a gap: `gpt-4o-mini-tts-2025-12-15` is the current snapshot behind the `gpt-4o-mini-tts` alias and both probe fine, so the default needs no pinning. `stream_format="sse"` is not exposed and should not be a simple `Settings` pass-through — `run_tts` consumes raw PCM bytes from the streaming response, so SSE would need a different reader.
