# Together LLM — 2026-09-01

`TogetherLLMService` is broken out of the box: Together removed `zai-org/GLM-5.1` from
serverless inference on 2026-07-10, so the shipped default returns `model_not_available`
for anyone without a dedicated endpoint. The branch moves the default to `zai-org/GLM-5.2`.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5570 — Default TogetherLLMService to zai-org/GLM-5.2

### To consider
- **GLM thinking is on by default** (medium, since 2026-09-01) — GLM-5.2 emits reasoning before its
  first answer token (median TTFAT 619 ms, 524 ms of it thinking). It can be turned off today, but
  only via `extra={"extra_body": {"chat_template_kwargs": {"thinking": false}}}`, which drops median
  TTFAT to 163 ms; putting `chat_template_kwargs` directly in `extra` fails client-side because
  `BaseOpenAILLMService` splats `extra` into the OpenAI SDK call. — *Needs a call: document the idiom
  on `TogetherLLMService`, or give it a first-class thinking field, and decide whether voice pipelines
  should ship with thinking off.*
- **GLM-5.3 as the default** (low, since 2026-09-01) — Together added `zai-org/GLM-5.3` and
  `GLM-5.3-Flash` as serverless models in August 2026, but aiewf-eval's `aiwf_medium_context` puts
  glm-5.3 (low reasoning) at 98.7% / 2376 ms TTFAT P50 against glm-5.2 (none) at 99.7% / 936 ms, and
  one of five probe turns on GLM-5.3 errored. — *Needs a call: a released model's row is final, so
  GLM-5.3 only becomes the default if a maintainer overrides the benchmark condition.*
