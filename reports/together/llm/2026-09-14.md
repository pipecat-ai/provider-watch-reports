# Together LLM — 2026-09-14

`zai-org/GLM-5.2` shipped as the default in #5570 and is healthy: not deprecated, serverless,
and every probe turn succeeded. Nothing to review this run; two items remain for a maintainer.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **GLM thinking is on by default** (medium, since 2026-09-01) — GLM-5.2 spends 572 ms of a
  758 ms median TTFAT on reasoning before its first answer token. It can be turned off today, but
  only via `extra={"extra_body": {"chat_template_kwargs": {"thinking": false}}}`, which drops median
  TTFAT to 179 ms; putting `chat_template_kwargs` directly in `extra` fails client-side because
  `BaseOpenAILLMService` splats `extra` into the OpenAI SDK call. — *Needs a call: document the idiom
  on `TogetherLLMService`, or give it a first-class thinking field, and decide whether voice pipelines
  should ship with thinking off.*
- **GLM-5.3 as the default** (low, since 2026-09-01) — GLM-5.3 has got markedly faster since the last
  run (trivial-prompt TTFAT 301 ms against GLM-5.2's 758 ms, all five turns clean), and
  `BasetenLLMService` now defaults to it (#5730). Against that: aiewf-eval's `aiwf_medium_context`
  is unchanged at glm-5.3 (low reasoning) 98.7% / 2376 ms versus glm-5.2 (none) 99.7% / 936 ms, one
  of three reasoning-prompt turns errored, and GLM-5.3 opened that answer with a markdown heading
  (`# Working`), which reads badly through TTS. — *Needs a call: a released model's row is final, so
  GLM-5.3 only becomes the Together default if a maintainer overrides the benchmark condition
  (#5447) or the leaderboard gains a better row.*
