# Together STT — 2026-10-12

Quiet cycle on both sides: no STT catalogue or API change at Together, no change to `together/stt.py`, so the five known items carry forward unchanged.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **`language` is dropped** (high, since 2026-09-01) — `_connect_websocket` builds the URL from `model`, `turn_detection` and `input_audio_format` only, so the `language` field that the class docstring and docs.pipecat.ai both advertise (default `Language.EN`) has no effect. Open for three runs now. — *Needs a call: wiring the field up as-is turns today's autodetect into forced English; the alternative is defaulting the field to `None` and sending it only when set.*
- **Interim transcriptions are unreachable** (medium, since 2026-09-28) — `_handle_transcription_delta` reads `evt.get("transcript", "")`, but Together's streaming page documents the delta event's text as `delta` and last run's raw-socket probe found no `transcript` key on it, so the `InterimTranscriptionFrame` push never happens. It is unreachable a second way: with the class's hard-coded `turn_detection=none` the endpoint sends only one `completed` event. Our docs page still says the service supports interim results. — *Needs a call: `turn_detection=none` is deliberate, since the class commits on `VADUserStoppedSpeakingFrame`, so correcting the key on its own changes no behavior. Someone has to decide whether interim results are a feature to make work or the handler is dead code to remove along with the docs claim.*
- **Streaming ASR models** (medium, since 2026-09-01) — `nvidia/parakeet-tdt-0.6b-v3` and `nvidia/nemotron-3.5-asr-streaming-0.6b` are serverless on Together and work through the class unchanged. Parakeet was again the faster of the two probed, with the same transcript as Whisper. — *Needs a call: Together's STT page names no recommended model and no successor to Whisper, so there is nothing to bump the default to; revisit if Together designates one.*
- **`prompt` biasing** (low, since 2026-09-01) — a documented transcription parameter with no `Settings` field. Together's STT page says prompts apply to Whisper-family models only, yet earlier runs' raw-socket probes on Whisper left the transcript unchanged. — *Needs a call: confirm the realtime endpoint applies the hint at all before adding a field for it.*
- **Hard-coded 16 kHz declaration** (low, since 2026-09-01) — `input_audio_format=pcm_s16le_16000` is fixed while audio is sent at whatever rate the pipeline delivers. Latent rather than broken. — *Needs a call: the fix is either a resample to 16 kHz or a format string derived from `self.sample_rate`, depending on which other rates the endpoint accepts.*
