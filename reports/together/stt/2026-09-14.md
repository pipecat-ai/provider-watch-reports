# Together STT — 2026-09-14

Nothing changed on Together's side in this cycle: `openai/whisper-large-v3` is still current and transcribes correctly, and the four gaps from 2026-09-01 all still stand.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **`language` is dropped** (high, since 2026-09-01) — `_connect_websocket` builds the URL from `model`, `turn_detection` and `input_audio_format` only, so the `language` field that the class docstring and docs.pipecat.ai both advertise (default `Language.EN`) has no effect. The endpoint documents and honours the parameter. — *Needs a call: wiring the field up as-is turns today's autodetect into forced English; the alternative is defaulting the field to `None` and sending it only when set.*
- **Streaming ASR models** (medium, since 2026-09-01) — `nvidia/parakeet-tdt-0.6b-v3` and `nvidia/nemotron-3.5-asr-streaming-0.6b` are serverless on Together and work through the class unchanged. This run both returned the clip's full two sentences, so last run's nemotron truncation did not reproduce; nemotron was slow (TTFB 944 ms vs Whisper's 235 ms) on this single sample, parakeet marginally faster than Whisper. — *Needs a call: Together still doesn't position either as Whisper's successor, so there is nothing to bump the default to; revisit if Together designates one.*
- **`prompt` biasing** (low, since 2026-09-01) — a documented query parameter with no `Settings` field. Together's model page says prompts apply to Whisper-family models only, yet last run's raw-socket probes on Whisper left the transcript unchanged. — *Needs a call: confirm the realtime endpoint applies the hint at all before adding a field for it.*
- **Hard-coded 16 kHz declaration** (low, since 2026-09-01) — `input_audio_format=pcm_s16le_16000` is fixed while audio is sent at whatever rate the pipeline delivers. Latent rather than broken. — *Needs a call: the fix is either a resample to 16 kHz or a format string derived from `self.sample_rate`, depending on which other rates the endpoint accepts.*
