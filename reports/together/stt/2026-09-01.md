# Together STT — 2026-09-01

`openai/whisper-large-v3` is current and transcribes correctly; the one thing worth fixing is that `Settings.language` never reaches the API.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **`language` is dropped** (high, since 2026-09-01) — `_connect_websocket` builds the URL from `model`, `turn_detection` and `input_audio_format` only, so the `language` field that the class docstring and docs.pipecat.ai both advertise has no effect. The endpoint honours it: the same English clip came back as *"le foie vert rapide tombe sur le chien délicat…"* with `&language=fr`. — *Needs a call: the stored default is `Language.EN`, so wiring the field up as-is turns today's autodetect into forced English; the alternative is defaulting the field to `None` and sending it only when set.*
- **Streaming ASR models** (medium, since 2026-09-01) — `nvidia/nemotron-3.5-asr-streaming-0.6b` and `nvidia/parakeet-tdt-0.6b-v3` are serverless on Together and already work through the class unchanged; parakeet matched Whisper's transcript at a lower TTFB. Nemotron-3.5 returned only the first of the clip's two sentences, in both the class probe and a raw-socket repeat. — *Needs a call: Together doesn't position either as Whisper's successor, and nemotron's dropped tail has to be attributed to our commit-driven flow or to the model before a default bump is worth considering.*
- **`prompt` biasing** (low, since 2026-09-01) — a documented query parameter with no `Settings` field. The endpoint accepts it, but neither `prompt=Pipecat` nor a full sentence changed the transcript. — *Needs a call: confirm the realtime endpoint applies the hint at all before adding a field for it.*
- **Hard-coded 16 kHz declaration** (low, since 2026-09-01) — `input_audio_format=pcm_s16le_16000` is fixed while audio is sent at whatever rate the pipeline delivers. A 24 kHz clip still transcribed correctly, so this is latent rather than broken. — *Needs a call: Together documents only `pcm_s16le_16000`, so the fix is either a resample to 16 kHz or a format string derived from `self.sample_rate`, depending on which other rates the endpoint accepts.*
