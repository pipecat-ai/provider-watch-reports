# Whisper STT — 2026-09-01

Nothing is retiring and both SDK pins are current; the urgent item is that `pipecat init` scaffolds a local-Whisper bot that raises on startup.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5558 — Expose Faster Whisper's hotwords in WhisperSTTService.Settings

### To consider
- **`pipecat init` wiring for local Whisper** (high, since 2026-09-01) — `whisper_stt` carries `env_prefix="OPENAI"`, so the generated bot reads `model=os.getenv("OPENAI_MODEL")` while `env.example.jinja2` emits only `OPENAI_API_KEY`, a key the local service never uses. With `OPENAI_MODEL` unset, `Settings(model=None)` overrides the hardcoded default (confirmed: `apply_update` applies an explicit `None`) and `_load()` raises `Whisper model must be specified`. When the project also picks an OpenAI LLM, `OPENAI_MODEL` holds an LLM name that `WhisperModel` cannot fetch. — *Needs a call: renaming the variable is user-visible and spans `service_metadata.py`, `_configs.py` and the `.env` template, so the maintainer picks the name — `WHISPER_STT_MODEL` is what Moonshine's prefix-less entry produces.*
- **Unexposed transcription knobs** (medium, since 2026-09-01) — `run_stt` passes only `language` (and, on the branch, `hotwords`). `initial_prompt`, `beam_size`, `temperature`, `vad_filter`, `condition_on_previous_text` and `word_timestamps` are all `WhisperModel.transcribe` parameters with no Settings field; `temperature` exists on `WhisperSTTServiceMLX` but not here. `BatchedInferencePipeline`, faster-whisper 1.1's ~4x-faster path, is unused. — *Needs a call: which of these belong in Settings versus init-only inference config, and whether batched inference pays off for single-utterance segments.*
- **`Model` enum lags the alias table** (low, since 2026-09-01) — faster-whisper 1.2.1 resolves 19 aliases; `Model` carries 8, missing `distil-large-v3.5` (support added in 1.2.0), `distil-large-v3`, `distil-small.en`, the `.en` sizes and the `large-v3-turbo`/`turbo` shorthands. `Settings.model` is a plain string, so any of these already work — the enum is only the curated list. — *Needs a call: which aliases belong in a curated enum.*
- **`Model.LARGE_V3_TURBO` repo** (low, since 2026-09-01) — the enum pins `deepdml/faster-whisper-large-v3-turbo-ct2`; faster-whisper's own `large-v3-turbo` alias resolves to `mobiuslabsgmbh/faster-whisper-large-v3-turbo`, and `_unsupported_language()` tells users to use `'large-v3-turbo'`, so the two documented paths download different weights. — *Needs a call: changing the value changes which weights existing users download.*
- **Default ignores prompt conditioning** (low, since 2026-09-01) — `hotwords="Pipecat"` left the default `Systran/faster-distil-whisper-medium.en` transcribing "Pippecut" unchanged, while the same hint corrected `small.en` from "Pipikut" to "Pipecat"; distil-whisper checkpoints are trained without the previous-context prompt. — *Needs a call: whether the default should move off a distil checkpoint, trading speed for the hint working.*
