# Whisper STT — 2026-09-28

Nothing moved upstream — faster-whisper 1.2.1 and mlx-whisper 0.4.3 are still the latest and both pins are current — but probing the merged vocabulary fields turned up a transcript-truncating interaction on the shipped default.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default distil model loses a sentence when both vocabulary fields are set** (medium, since 2026-09-01) — on `Systran/faster-distil-whisper-medium.en`, `hotwords="Pipecat"` and `initial_prompt="Pipecat makes voice agents easy to build."` each leave the transcript at "Pippecut"; with both set, faster-whisper returns only the first of the clip's two segments and the second spoken sentence disappears (reproduced twice through the service, and again straight against `WhisperModel.transcribe`, where the surviving segment reports `no_speech_prob=0.058` — our 0.4 threshold is not what drops it). `small.en` keeps both sentences in all four combinations and either field corrects "Pipecat", so this is the distil checkpoint, which is what we ship as the default. — *Needs a call: move the default off a distil checkpoint, suppress one field when the other is set, or document that the pair is unsafe on distil models.*
- **Remaining transcription knobs** (medium, since 2026-09-01) — with `hotwords` (#5558) and `initial_prompt` (#5755) merged, `run_stt` still never passes `beam_size`, `temperature`, `vad_filter`, `condition_on_previous_text` or `word_timestamps`; `temperature` exists on `WhisperSTTServiceMLX` but not on `WhisperSTTService`, and `WhisperSTTServiceMLX.Settings` exposes neither vocabulary field (mlx-whisper has `initial_prompt` but no `hotwords`). `BatchedInferencePipeline`, faster-whisper 1.1's ~4x-faster path, is unused. — *Needs a call: which of these belong in Settings versus init-only inference config, whether batched inference pays off for single-utterance segments, and who probes the MLX class, which only runs on Apple Silicon.*
- **`Model` enum lags the alias table** (low, since 2026-09-01) — faster-whisper 1.2.1 resolves 19 aliases; `Model` carries 8, missing `distil-large-v3.5`, `distil-large-v3`, `distil-small.en`, the `.en` sizes and the `large-v3-turbo`/`turbo` shorthands. `Settings.model` is a plain string, so any of these already work — the enum is only the curated list. — *Needs a call: which aliases belong in a curated enum.*
- **`Model.LARGE_V3_TURBO` repo** (low, since 2026-09-01) — the enum pins `deepdml/faster-whisper-large-v3-turbo-ct2`; faster-whisper's own `large-v3-turbo` alias resolves to `mobiuslabsgmbh/faster-whisper-large-v3-turbo`, and `_unsupported_language()` tells users to use `'large-v3-turbo'`, so the two documented paths download different weights. — *Needs a call: changing the value changes which weights existing users download.*

Closed since the last report: `initial_prompt`, merged as #5755.
