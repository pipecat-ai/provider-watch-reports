# Whisper STT — 2026-09-14

No model or SDK movement since the last run; the branch adds `initial_prompt` to `WhisperSTTService.Settings`, and the two items the last report led with are closed in main.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5755 — Expose Faster Whisper's initial_prompt in WhisperSTTService.Settings

### To consider
- **Remaining transcription knobs** (medium, since 2026-09-01) — with `hotwords` merged and `initial_prompt` on the branch, `run_stt` still never passes `beam_size`, `temperature`, `vad_filter`, `condition_on_previous_text` or `word_timestamps`; `temperature` exists on `WhisperSTTServiceMLX` but not on `WhisperSTTService`, and `WhisperSTTServiceMLX.Settings` exposes neither vocabulary field (mlx-whisper has `initial_prompt` but no `hotwords`). `BatchedInferencePipeline`, faster-whisper 1.1's ~4x-faster path, is unused. — *Needs a call: which of these belong in Settings versus init-only inference config, whether batched inference pays off for single-utterance segments, and who probes the MLX class, which only runs on Apple Silicon.*
- **`Model` enum lags the alias table** (low, since 2026-09-01) — faster-whisper 1.2.1 resolves 19 aliases; `Model` carries 8, missing `distil-large-v3.5`, `distil-large-v3`, `distil-small.en`, the `.en` sizes and the `large-v3-turbo`/`turbo` shorthands. `Settings.model` is a plain string, so any of these already work — the enum is only the curated list. — *Needs a call: which aliases belong in a curated enum.*
- **`Model.LARGE_V3_TURBO` repo** (low, since 2026-09-01) — the enum pins `deepdml/faster-whisper-large-v3-turbo-ct2`; faster-whisper's own `large-v3-turbo` alias resolves to `mobiuslabsgmbh/faster-whisper-large-v3-turbo`, and `_unsupported_language()` tells users to use `'large-v3-turbo'`, so the two documented paths download different weights. — *Needs a call: changing the value changes which weights existing users download.*
- **Default ignores prompt conditioning** (low, since 2026-09-01) — on `Systran/faster-distil-whisper-medium.en`, `hotwords="Pipecat"` and `initial_prompt="Pipecat makes voice agents easy to build."` both leave the transcript at "Pippecut" (the prompt shifts capitalization and punctuation only), while the same hint corrects `small.en` from "Pipikut" to "Pipecat". — *Needs a call: whether the default should move off a distil checkpoint, trading speed for the hints working.*

Closed since the last report: `pipecat init`'s local-Whisper wiring (the registry entry now carries `env_prefix="WHISPER"`, the generated bot reads `os.getenv("WHISPER_MODEL", "Systran/faster-distil-whisper-medium.en")`, and `env.example.jinja2` documents the variable), and `hotwords`, merged as #5558.
