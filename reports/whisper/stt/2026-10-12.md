# Whisper STT — 2026-10-12

Current: no upstream movement of any kind since the last run, and the service file is unchanged; the four open gaps all still hold, including the transcript truncation that reproduced again on `19fca83d2`.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default distil model loses a sentence when both vocabulary fields are set** (medium, since 2026-09-01) — on `Systran/faster-distil-whisper-medium.en`, setting `hotwords="Pipecat"` and `initial_prompt="Pipecat makes voice agents easy to build."` together makes the transcript stop after the clip's first sentence; reproduced again this run through `probe.py run`. Either field alone keeps both sentences and neither corrects "Pippecut" on this checkpoint. `small.en` keeps both sentences in all four combinations and either field corrects the spelling, so this is the distil checkpoint we ship as the default. — *Needs a call: move the default off a distil checkpoint, suppress one field when the other is set, or document that the pair is unsafe on distil models.*
- **Remaining transcription knobs** (medium, since 2026-09-01) — `run_stt` passes only `language`, `hotwords` and `initial_prompt` of `transcribe()`'s 35 parameters; `beam_size`, `temperature`, `vad_filter`, `condition_on_previous_text` and `word_timestamps` are unreachable, `temperature` exists on `WhisperSTTServiceMLX` but not on `WhisperSTTService`, and `WhisperSTTServiceMLX.Settings` exposes neither vocabulary field (mlx-whisper has `initial_prompt` but no `hotwords`). `BatchedInferencePipeline` is still unused. — *Needs a call: which of these belong in Settings versus init-only inference config, whether batched inference pays off for single-utterance segments, and who probes the MLX class, which only runs on Apple Silicon.*
- **`Model` enum lags the alias table** (low, since 2026-09-01) — faster-whisper 1.2.1 resolves 19 aliases; `Model` carries 8, missing `distil-large-v3.5`, `distil-large-v3`, `distil-small.en`, the `.en` sizes and the `large-v3-turbo`/`turbo` shorthands. `Settings.model` is a plain string, so any of these already work — the enum is only the curated list. — *Needs a call: which aliases belong in a curated enum.*
- **`Model.LARGE_V3_TURBO` repo** (low, since 2026-09-01) — the enum pins `deepdml/faster-whisper-large-v3-turbo-ct2`; faster-whisper's own `large-v3-turbo` alias resolves to `mobiuslabsgmbh/faster-whisper-large-v3-turbo`, and `_unsupported_language()` tells users to use `'large-v3-turbo'`, so the two documented paths download different weights. — *Needs a call: changing the value changes which weights existing users download.*
