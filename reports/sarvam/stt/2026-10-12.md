# Sarvam STT — 2026-10-12

Nothing to change in the services: both classes cover every documented parameter on both endpoints, and both defaults match Sarvam's own.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Registry still scaffolds the legacy endpoint** (medium, since 2026-08-31) — Sarvam's streaming-api page calls the endpoint `SarvamSTTService` uses "the generally-available legacy WebSocket" and states that realtime supersedes it for new voice-agent and live-transcription work, with no sunset date. `sarvam_stt` in `cli/registry/service_metadata.py` still lists `class_name=["SarvamSTTService"]`. — *Needs a call: whether SarvamRealtimeSTTService should become, or join, the registry's Sarvam STT entry while Sarvam still labels realtime beta.*
- **sarvamai pin behind PyPI** (low, since 2026-08-31) — `pyproject.toml` pins `sarvamai==0.1.28`; 0.1.36 shipped 2026-10-06. Diffing the wheels, the one STT-facing change across the range is a `keyterms` parameter on `speech_to_text_streaming.connect()`, which our service already sends through `request_options.additional_query_parameters`; the rest is new non-STT modules (dubbing, voice cloning, doc AI, responses) and model-Literal text. — *Needs a call: whether the exact pin moves when the only STT-facing change is a parameter we already pass by hand.*
- **SDK ships a realtime client** (low, since 2026-09-14) — `sarvamai.speech_to_text_realtime_streaming` covers the endpoint `SarvamRealtimeSTTService` implements by hand, and its connect signature matches `_query_params()` field for field. — *Needs a call: whether the hand-rolled realtime websocket is worth replacing with the SDK client, which would also require moving the pin.*

Closed since the last run: the realtime allowlist gap (pipecat-ai/pipecat#5758, merged 2026-09-14), keyterm prompting on both WebSocket endpoints (#6013), and the partial language maps — #6010 brought both connect-side maps and the transcript-side map to Sarvam's full code list, and every realtime code now resolves to a `Language` member.
