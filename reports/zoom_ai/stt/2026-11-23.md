# Zoom AI STT — 2026-11-23

Nothing moved on Zoom's side since 2026-11-09 — the AI Services changelog's newest entry is Interpreter, not Scribe — so the same six gaps stand, every one of them blocked on a live session this environment has no key for.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **Top-level `language`** (medium, since 2026-11-09) — the Live field table and every example nest it (`config.language`, "Recognition language or preferred initial language. Defaults to `en-US`"); `_session_update()` sends `update["language"]` while putting model, diarization, vocabulary and language detection in `config`. If Scribe ignores the top-level field, a user setting `Language.DE_DE` silently gets en-US. — *Needs a call: confirm with a live session (set a non-English language, read the effective `language` back from `session.updated`) before moving the field; no ZOOM_AI_API_KEY here to do it.*
- **Polishing plus language detection** (medium, since 2026-11-09) — Zoom states Text Polishing can't be combined with `config.language_detection`, even for en-US; in Live the session update is rejected with a nonfatal `invalid_config`, so the session falls back to defaults entirely. `ZoomAISTTSettings` accepts both at once. — *Needs a call: validate the combination client-side, or only document it?*
- **Vocabulary Assets** (medium, since 2026-11-09) — `config.vocabulary_id` (a persistent, immutable phrase list, created at `POST /aiservices/assets/vocabularies`) has no Settings field; only the inline `vocabulary` list does. — *Needs a call: Zoom forbids sending `vocabulary` and `vocabulary_id` together, so the field needs a stance on the conflict.*
- **Undocumented Live fields** (medium, since 2026-11-09) — both turn-detection modes rely on `turn_detection.silence_duration_ms`, `turn_detection: {"type": "none"}` and `input_audio_buffer.commit`; none of those strings occur in Scribe's Live reference, which documents only `session.update`, `input_audio_buffer.append`, `session.close` and bare binary audio frames (they are documented for the separate Voice Agent Live API). — *Needs a call: get Zoom to confirm Scribe Live honors them; if not, `silence_duration_ms` and `vad_force_turn_endpoint=True` are no-ops.*
- **Captions / interim results** (low, since 2026-11-09) — `config.interim_results` makes Scribe send `transcription.delta` (accumulated partial text per `item_id`); the service enables neither and pushes finals only. Still flagged as preview. — *Needs a call: re-check when it leaves preview, then decide on `InterimTranscriptionFrame`.*
- **`profanity_filter`** (low, since 2026-11-09) — documented Live boolean, reachable today only through `extra`. — *Needs a call: a live probe with the field set, which a missing key blocked again this run.*

Dropped since 2026-11-09: the "Pipecat docs lag" item — the published service page now documents `vad_force_turn_endpoint` and `ttfs_p99_latency`.
