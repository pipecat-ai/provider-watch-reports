# Zoom AI STT — 2026-11-09

Nothing in Scribe is retired or renamed, and the service pins no model; the one thing worth a maintainer with a Zoom key is whether Scribe still accepts `language` at the top level of `session.update`, since the current docs put it under `config`.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **Top-level `language`** (medium, since 2026-11-09) — Zoom's Live schema documents `config.language`, and every example on live-mode, text-polishing and speech-configuration nests it; `_session_update()` sends `update["language"]` (the older flat schema) while putting model, diarization, vocabulary and language detection in `config`. If Scribe ignores the top-level field, a user setting `Language.DE_DE` silently gets Scribe's default en-US. — *Needs a call: confirm with a live session (set a non-English language, read the effective `language` back from `session.updated`) before moving the field; no ZOOM_AI_API_KEY here to do it.*
- **Polishing plus language detection** (medium, since 2026-11-09) — Zoom states Text Polishing can't be combined with `config.language_detection`; in Live the session update is rejected with a nonfatal `invalid_config`, so the session falls back to defaults entirely. `ZoomAISTTSettings` accepts both at once. — *Needs a call: validate the combination client-side, or only document it?*
- **Vocabulary Assets** (medium, since 2026-11-09) — `config.vocabulary_id` (a persistent, reusable phrase list) has no Settings field; only the inline `vocabulary` list does. — *Needs a call: Zoom forbids sending `vocabulary` and `vocabulary_id` together, so the field needs a stance on the conflict.*
- **Undocumented Live fields** (medium, since 2026-11-09) — both turn-detection modes rely on `turn_detection.silence_duration_ms`, `turn_detection: {"type": "none"}` and `input_audio_buffer.commit`, none of which appear in Scribe's Live reference (they are documented for the separate Voice Agent Live API). — *Needs a call: get Zoom to confirm Scribe Live honors them; if not, `silence_duration_ms` and `vad_force_turn_endpoint=True` are no-ops.*
- **Captions / interim results** (low, since 2026-11-09) — `config.interim_results` makes Scribe send `transcription.delta` (accumulated partial text per `item_id`); the service enables neither and pushes finals only. Zoom marks the feature as preview that "may not work as documented". — *Needs a call: re-check when it leaves preview, then decide on `InterimTranscriptionFrame`.*
- **`profanity_filter`** (low, since 2026-11-09) — documented Live boolean, reachable today only through `extra`. — *Needs a call: a live probe with the field set, which a missing key blocked this run.*
- **Pipecat docs lag** (low, since 2026-11-09) — the published service page omits `vad_force_turn_endpoint` and still says the service reports no TTFS. — *Needs a call: the fix belongs in the docs repo, not here.*
