# SambaNova LLM — 2026-09-14

SambaNova published nothing new since 2026-09-01; `Meta-Llama-3.3-70B-Instruct` remains current and undeprecated, and the sampling-parameter branch merged as #5565.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **SambaNova-only body parameters unreachable** (medium, since 2026-09-14) — SambaNova's schema documents `top_k`, `do_sample` and `chat_template_kwargs`, none of which the openai SDK declares. `Settings.top_k` is stored and never sent (the probe with `top_k=40` succeeds and changes nothing), and `Settings.extra` is not an escape hatch for them: the request is built as kwargs to `chat.completions.create(**params)`, so `extra={"top_k": 40}` raises `AsyncCompletions.create() got an unexpected keyword argument 'top_k'`. The only route that works today is `extra={"extra_body": {"top_k": 40}}`, which is documented nowhere. — *Needs a call: `base_llm.py` states that `top_k` is ignored for openai-client services, so wiring it here deviates from the base class, and a service-built `extra_body` would have to merge with a user's own `extra["extra_body"]` rather than be overwritten by it.*
- **Default model age** (low, since 2026-09-01) — `Meta-Llama-3.3-70B-Instruct` is the oldest of SambaNova's four production models (`MiniMax-M2.7`, `DeepSeek-V3.1`, `gpt-oss-120b`), but SambaNova lists it as a replacement target, not a deprecated one; the preview models (`MiniMax-M3`, `DeepSeek-V3.2`, `gemma-4-31B-it`) are not default candidates. — *Needs a call: SambaNova designates no successor, and the aiewf-eval medium-context leaderboard still carries no Llama row and no SambaNova-hosted row (`gpt-oss-120b` appears only via Groq at 86.3%), so there is no comparable benchmark to justify a bump.*

The previous report's openai-pin item is gone: the pin now reads `openai>=1.74.0,<4` and PyPI's latest is 3.13.0, inside it.
