# Deepgram Flux STT — 2026-09-14

Deepgram shipped nothing new for Flux STT since its 2026-08-28 turn-control release; `flux-general-en` stays the default, and the only open work is PR 5584 plus a one-line docstring branch.

## What's new for Pipecat

### PRs

- https://github.com/pipecat-ai/pipecat/pull/5584 — Add manual turn finalization to Deepgram Flux STT (open since 2026-09-01; adds a `turn_detection` mode and a public `force_end_turn()`, which is what the previous report's `ForceEndTurn` item asked for)
- https://github.com/pipecat-ai/pipecat/pull/5739 — Document Deepgram Flux's default URL as its GA endpoint

### To consider

- **`flux_encoding` overstates Flux's constraint** (low, since 2026-09-01) — both constructors document the encoding as "Must be `linear16`", while Deepgram's feature overview lists multiple encodings for all Flux versions. The default is still the only workable value in Pipecat, since transports deliver linear16 PCM. — *Needs a call: whether Flux should accept the other encodings at all; if not, the wording should attribute the constraint to Pipecat rather than to Flux.*

PR 5523 (`profanity_filter`/`redact`) merged on 2026-09-02, so every query parameter the `/v2/listen` reference documents — `model`, `encoding`, `sample_rate`, `eager_eot_threshold`, `eot_threshold`, `eot_timeout_ms`, `keyterm`, `language_hint`, `profanity_filter`, `numerals`, `redact`, `mip_opt_out`, `tag` — is now reachable from `Settings` or the constructor. Deepgram's September changelog entries touch Flux TTS (speed range, expressivity, pricing from 2026-09-13), Nova-3 languages, and the Voice Agent API (`defer_until_eot`, `FunctionCallCancelled`) — none of them this unit. The Flux feature overview now mentions a self-hosted deployment; `DeepgramFluxSTTService` already takes an arbitrary `url`, so it needs no code change. `DeepgramFluxSageMakerSTTService` was not probed: it needs a deployed SageMaker endpoint. No decisions file exists for this unit and the digest comments name no Deepgram item, so nothing was recorded.
