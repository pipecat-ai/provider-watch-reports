# OpenRouter LLM — 2026-09-14

Nothing needs doing: `openai/gpt-4.1` is healthy and not retiring, and the only actionable item is PR #5550, still awaiting review.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5550 — Add a provider setting to OpenRouterLLMService (open since last run)

### To consider
- **Normalized `reasoning` field** (medium, since 2026-09-01) — OpenRouter's `reasoning={enabled, effort, max_tokens, exclude}` is the one knob that turns thinking off the same way across all 445 catalogue models, which is what a voice pipeline wants; reaching it today requires `extra={"extra_body": {"reasoning": ...}}`. — *Needs a call: OpenAI-family models also accept `reasoning_effort` through `extra`, so a first-class field has to define which one wins.*
- **Model-level fallback** (medium, since 2026-09-01) — `models: [...]` lets OpenRouter retry the next model when the first errors; a long-running call would benefit, and the field is not reachable from `Settings`. The companion `route` field is now marked deprecated in the API reference (superseded by `provider.sort.partition`), so only the array matters. — *Needs a call: how a fallback list should interact with `Settings.model` and with runtime model updates.*
- **`transforms` and `plugins`** (low, since 2026-09-01) — middle-out context compression and a growing beta plugin list (auto-router, moderation, web, file-parser, fusion, response-healing, context-compression, pareto-router) are plain pass-through request fields with no `Settings` equivalent. — *Needs a call: whether either belongs in a voice pipeline, or stays an `extra` escape-hatch feature.*
- **Default model age** (low, since 2026-09-01) — `openai/gpt-6-astra` joined the catalogue this run but aiewf-eval has not benchmarked it, and it probes at 1667 ms median TTFAT against gpt-4.1's 616 ms. gpt-4.1 stays GA, absent from OpenAI's deprecation table, and at 96.3% on `aiwf_medium_context`; gpt-5.1 remains the only higher-scoring candidate and was 83% slower last run. — *Needs a call: whether quality alone justifies the latency cost, and whether this wrapper should track `OpenAILLMService`'s default (also gpt-4.1) instead of moving on its own.*
- **Stale docs examples** (low, since 2026-09-01) — the API reference page names `google/gemini-pro` and `anthropic/claude-sonnet-4-20250514`, neither of which is in `GET /models`. — *Needs a call: the page lives in pipecat-ai/docs and cannot be fixed from this repo.*

Closed since last run: the `openai` SDK pin gap. `pyproject.toml` now pins `openai>=1.74.0,<4`, which admits the current 3.13.0.

Presets, which OpenRouter launched on 2026-09-11, need no new field: a preset is addressed as `model="@preset/<slug>"`, which `Settings.model` already passes through.
