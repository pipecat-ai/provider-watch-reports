# OpenRouter LLM — 2026-09-01

`openai/gpt-4.1` remains a sound default; the actionable item is provider routing, OpenRouter's headline feature, which the service could not express until now.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5550 — Add a provider setting to OpenRouterLLMService

### To consider
- **Normalized `reasoning` field** (medium, since 2026-09-01) — OpenRouter's `reasoning={effort, max_tokens, exclude, enabled}` is the one knob that turns thinking off the same way across all 425 catalogue models, which is what a voice pipeline wants; reaching it today requires `extra={"extra_body": {"reasoning": ...}}`. — *Needs a call: OpenAI-family models also accept `reasoning_effort` through `extra`, so a first-class field has to define which one wins.*
- **Model-level fallback** (medium, since 2026-09-01) — `models: [...]` plus `route: "fallback"` lets OpenRouter retry a different model when the first is unavailable; a long-running call would benefit, and neither field is reachable from `Settings`. — *Needs a call: how a fallback list should interact with `Settings.model` and with runtime model updates.*
- **`transforms` and `plugins`** (low, since 2026-09-01) — middle-out context compression and the web/file-parser plugins are plain pass-through request fields with no `Settings` equivalent. — *Needs a call: whether either belongs in a voice pipeline, or stays an `extra` escape-hatch feature.*
- **Default model age** (low, since 2026-09-01) — `openai/gpt-4.1` is GA on OpenRouter (served by openai and azure), does not appear in OpenAI's API deprecation table, and scores 96.3% on aiewf-eval `aiwf_medium_context`. Candidates at or above that pass rate are all slower: gpt-5.1 is 98.0% on the leaderboard but 709 ms median TTFAT through OpenRouter against gpt-4.1's 388 ms. — *Needs a call: whether quality alone justifies the latency cost, and whether this wrapper should track `OpenAILLMService`'s default (also gpt-4.1) instead of moving on its own.*
- **Stale docs examples** (low, since 2026-09-01) — the API reference page names `google/gemini-pro` and `anthropic/claude-sonnet-4-20250514`, neither of which is in `GET /models`; the live slugs are `~google/gemini-pro-latest` and `anthropic/claude-sonnet-4`. — *Needs a call: the page lives in pipecat-ai/docs and cannot be fixed from this repo.*
- **`openai` SDK pin** (low, since 2026-09-01) — `openai>=1.74.0,<3` excludes 3.6.0 (2026-08-28). The `openrouter` extra is empty, so this is the shared base dependency. — *Needs a call: moving to the 3.x line affects every OpenAI-compatible service, not this unit alone.*
