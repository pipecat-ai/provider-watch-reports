# Smallest STT — 2026-11-23

Nothing to ship: no new STT model, no STT deprecation, no parameter removal, and `pulse` is still
the right default. The run's one new finding is a diagnosis gap — the service silently drops the
server's error frames.

Probing `pulse-2` failed twice with the generic "connection failed 3 times immediately after
connecting". An ad-hoc WebSocket connect with the exact query the service builds showed the real
cause: the server sends `{"type":"error","error_code":"MODEL_NOT_ENABLED","message":"Pulse 2.0 is
currently disabled for this account… Use model=pulse in the meantime."}` and closes. That is an
entitlement on the probing account, not a provider change — the pulse-2 model card is still live
and labelled "Latest Release" — but it shows that every server-side rejection reaches a Pipecat
user as an opaque reconnect loop ending in "can no longer do its job". That is the same failure the
language-map item predicts for `language=pl`, now observed.

Smallest also added a fourth streaming aggregator, `indic` (all ten Indian languages in one stream,
India region only), which widens the existing language-map gap; the streaming table is now 26
entries. The response-format page documents `start` and `duration` on every transcription message,
which users already get through the frame's `result` payload, so that needs no code change.

PR #5518 stays closed unmerged from 2026-11-07 with both halves already in the code, so it is not
carried forward and no decision was recorded — nothing was declined on its merits.

### To consider
- **Language map vs. Pulse's streaming set** (high, since 2026-08-31) — 15 mapped codes are pre-recorded-only or undocumented on streaming; `language=pl` fails the WebSocket handshake and the user sees only a reconnection error. The streaming East Asian codes (`zh`, `yue`, `ja`, `ko`) and `hi-dev` are missing from the map, and the four aggregators — `north_indic`, `multi-asian`, `multi-south-indic` and the new `indic` — are reachable only by passing a raw string, while being the only way to get Pulse's streaming language detection. East Asian codes and `multi-asian` need `wss://api.us.smallest.ai`; the South Indian codes, `indic` and `hi-dev` are India-region only. — *Needs a call: trimming the map breaks anyone passing those codes today, so choose between removing them, failing with a clear message, or documenting the streaming/batch and region split.*
- **Server error frames are discarded** (medium, since 2026-11-23) — Smallest answers a rejected connection with a JSON error frame naming the cause and the fix, then closes; `_process_response` reads only `transcript`, so the message is lost and the user sees three reconnect attempts and an unusable processor. Observed this run with `MODEL_NOT_ENABLED` on `pulse-2`; the same path hides `LANGUAGE_NOT_SUPPORTED_BY_MODEL` and `LANGUAGE_NOT_ENABLED_IN_REGION`. — *Needs a call: whether an error frame should become a fatal or non-fatal `push_error`, and whether it should stop the reconnect loop, since these rejections never succeed on retry.*
- **No `close_stream` at session end** (medium, since 2026-10-28) — `_disconnect_websocket` closes the socket directly; the response-format page documents `{"type":"close_stream"}` and an `is_last: true` final to wait for ("Do not close the WebSocket connection immediately after sending"), and the AsyncAPI spec lists it as `sendClose`. The service never sends it, so the `is_last` branch in `_process_response` is dead code and its docstring is wrong. Four `pulse` probes in a row returned a final truncated at the same point. — *Needs a call: whether `stop()` should send `close_stream` and await the final under a timeout, or whether the docstring should just be corrected.*
- **Finalize control** (medium, since 2026-08-31) — `finalize_on_words` and `max_words` are absent from `Settings`; Pulse documents `finalize_on_words=false` plus a per-turn client `finalize` as the agentic pattern, which the service already does, while pulse-2 tells clients not to send either. — *Needs a call: they change when finals arrive and must not reach pulse-2, so exposing them needs a stance on per-model gating.*
- **VAD events** (low, since 2026-08-31) — `vad_events=true` interleaves `speech_started` / `speech_ended` messages on the same socket for both models; `_process_response` reads only `transcript`, so they would be dropped. — *Needs a call: whether server VAD events should become frames at all, given the pipeline runs its own VAD.*
- **`numerals` is undocumented** (low, since 2026-08-31) — the service always sends `numerals=auto`, but neither the AsyncAPI bindings nor pulse-2's parameter table has such a parameter, and both point at `itn_normalize`, which is in `Settings`. — *Needs a call: confirm with Smallest whether `numerals` is still honored before dropping the field.*
- **`punctuate` / `capitalize`** (low, since 2026-08-31) — the spec documents both (default `true`) alongside `format`, which is all `Settings` exposes and all the feature pages describe. — *Needs a call: whether the finer-grained pair earns two fields next to `format`, which overlaps them.*
- **`external_session_id`** (low, since 2026-10-12) — documented on the pulse-2 card as a client-supplied correlation id; not reachable today. — *Needs a call: it is a per-session logging knob rather than a transcription setting, and changing a setting reconnects the socket, so decide whether it belongs in `Settings` or as a constructor argument.*
- **Keepalive sends billed silence** (low, since 2026-10-28) — the inherited `_send_keepalive` writes 100 ms of PCM silence on an idle socket and records it as STT usage; Smallest documents a free `{"type":"ping"}` / `pong` keep-alive that resets the 20-minute inactivity timer, plus a `timeout` URL parameter raising that window to 3 hours. — *Needs a call: `ping` does not reset the separate model-session idle timer that silence does, so swapping them is a trade, not a strict improvement.*
- **Pulse Pro** (low, since 2026-08-31) — English-only and batch-only, so using it needs a class against `POST /waves/v1/stt/`. — *Needs a call: a new service class is outside provider-watch's remit; decide whether a batch Smallest STT service is wanted.*
