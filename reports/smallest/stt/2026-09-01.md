# Smallest STT — 2026-09-01

Nothing moved at Smallest since the last run: `pulse` is still the only model the live endpoint accepts,
PR #5518 carries the two documented realtime parameters, and the language map is unchanged and still
rejects codes it advertises.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5518 — Add eou_timeout_ms and itn_normalize to SmallestSTTService settings (open since last run)

### To consider
- **Language map vs. Pulse's streaming set** (high, since 2026-08-31) — 15 mapped codes are pre-recorded-only or undocumented on streaming; `language=pl` still fails the WebSocket handshake today and the user sees only a reconnection error. The streaming East Asian codes (`zh`, `yue`, `ja`, `ko`) and the three aggregators are missing, so they reach the API only through `resolve_language`'s unverified fallback. — *Needs a call: trimming the map breaks anyone passing those codes today, so choose between removing them, failing with a clear message, or documenting the streaming/batch split.*
- **Finalize control** (medium, since 2026-08-31) — `finalize_on_words` and `max_words` are absent from `Settings`; Pulse documents `finalize_on_words=false` plus a per-turn client `finalize` as the voice-agent pattern, and the service already sends that `finalize` on `VADUserStoppedSpeakingFrame`. — *Needs a call: they change when finals arrive, so it is a question of whether the service should adopt the agentic pattern by default rather than only pass the flags through.*
- **VAD events** (low, since 2026-08-31) — `vad_events=true` interleaves `speech_started` / `speech_ended` messages on the same socket; `_process_response` reads only `transcript`, so they would be dropped. — *Needs a call: whether server VAD events should become frames at all, given the pipeline runs its own VAD.*
- **`numerals` is undocumented** (low, since 2026-08-31) — the service always sends `numerals=auto`, but the AsyncAPI spec for the live endpoint has no such parameter and points at `itn_normalize` for written-form numbers. — *Needs a call: confirm with Smallest whether `numerals` is still honored before dropping the field.*
- **`punctuate` / `capitalize`** (low, since 2026-08-31) — the spec documents both alongside `format`, which is all `Settings` exposes. — *Needs a call: whether the finer-grained pair earns two fields next to `format`.*
- **Pulse Pro** (low, since 2026-08-31) — GA, English-only, batch-only; the live endpoint rejects `model=pulse-pro` with 400 and a directive to use HTTP, so using it needs a class against `POST /waves/v1/stt/`. — *Needs a call: a new service class is outside provider-watch's remit; decide whether a batch Smallest STT service is wanted.*
