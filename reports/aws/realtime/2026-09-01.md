# AWS Nova Sonic (realtime) — 2026-09-01

Nothing moved on either side since yesterday: `amazon.nova-2-sonic-v1:0` is still AWS's current
speech-to-speech model and still the right default, the code is at the same commit, and the gap list
carries forward unchanged. The clock item is first-generation `amazon.nova-sonic-v1:0`, 13 days from
EOL.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5508 — Correct the Nova Sonic supported-region lists (open since last run)

### To consider
- **First-generation Nova Sonic hits EOL on 2026-09-14** (high, since 2026-08-31) — Bedrock's
  lifecycle table still has `amazon.nova-sonic-v1:0` Legacy since 2026-03-13 with EOL 2026-09-14 and
  no public-extended-access date, after which requests fail. `AWSNovaSonicLLMService` still branches
  on it: `_is_first_generation_sonic_model()` gates the `ready.wav` assistant-response-trigger hack,
  `AWAIT_TRIGGER_ASSISTANT_RESPONSE_INSTRUCTION` and the "endpointing_sensitivity is not supported"
  downgrade, and the constructor docstring plus `examples/realtime/realtime-aws-nova-sonic.py`
  explain how to use the older model. — *Needs a call: deprecate-and-remove the first-generation path
  (and `ready.wav`) for 2.0.0, or only strip the guidance from docstrings and examples?*
- **SDK pin is seven releases behind** (medium, since 2026-08-31) — `pyproject.toml` pins
  `aws_sdk_bedrock_runtime~=0.4.0` (released 2026-02-24); PyPI's latest is still 0.11.0 (2026-08-24).
  The package is pre-1.0 and its own description warns of breaking changes before 1.0. — *Needs a
  call: someone has to walk 0.5.0 → 0.11.0 for breaking changes to
  `invoke_model_with_bidirectional_stream` and pick a new pin.*
- **Cross-modal text input is connect-only** (medium, since 2026-08-31) — Nova 2 Sonic's cross-modal
  feature is a text `contentStart` with `interactive: true` sent *during* a live voice session. The
  wire support is there (`send_text(..., interactive=True)`), but `_handle_context()` only uses it
  for the last message of the initial context; on a later `LLMContextFrame` it just flushes completed
  function-call results, so text typed mid-call never reaches the model. — *Needs a call: which frame
  carries mid-session text, and how it should interact with an in-flight assistant turn.*
- **`SYSTEM_SPEECH` role missing** (low, since 2026-08-31) — Nova 2 Sonic accepts
  `role: "SYSTEM_SPEECH"` on a text `contentStart` to choose the transcription script for Hindi
  code-switching (Latin / Devanagari / mixed). `Role` in
  `src/pipecat/adapters/services/aws_nova_sonic_adapter.py` has only SYSTEM, USER, ASSISTANT, TOOL.
  — *Needs a call: is Hindi script selection worth a user-facing knob, and what would it be called?*
- **`endpointing_sensitivity` is a free-form `str`** (low, since 2026-08-31) — AWS documents exactly
  `HIGH` / `MEDIUM` / `LOW`; a typo reaches the API instead of failing at construction. — *Needs a
  call: narrow the type now, or keep it open for values AWS may add?*

Not a gap: the Nova 2 Sonic release-notes page (new this cycle as a source) records only in-place
model refreshes in March and May 2026 — quality and latency improvements deployed with no API or
configuration change — plus the June 2026 raise of conversation-history limits to 50 KB per message
and 200 KB total, which loosens a constraint rather than adding one. Voices and locales still pass
through, since `Settings.voice` is a free-form `str`.

`probe.py run` still cannot fill AWS credentials on its own: the `aws_nova_realtime` registry entry
has an empty `include_params`, so `build_kwargs` never looks up `AWS_ACCESS_KEY_ID` /
`AWS_SECRET_ACCESS_KEY` / `AWS_REGION` and the constructor raises `TypeError`. The probe above passed
once those were supplied with `--kwarg`. Adding `access_key_id`, `secret_access_key` and `region` to
that entry's `include_params` would let future runs probe this unit unattended (provider-watch
tooling, not a service gap).

`probe.py list-models --provider aws` reports no OpenAI-compatible catalogue; `models_seen` comes from
Bedrock's lifecycle and regional-availability tables.
