# AWS Transcribe STT — 2026-09-14

PR #5509 merged, so the language map now covers all 99 streaming codes and the nine missing `Language` members exist. A branch exposes `partial_results_stability`; the sample-rate clamp is unchanged and still the only high-priority item.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5743 — Expose AWS Transcribe partial-results stability
- https://github.com/pipecat-ai/pipecat/pull/2849 — Add language options in AWS Transcribe STT Service; adds `identify_language`, `identify_multiple_languages` and `language_options`. Open since 2025-10-14, untouched since 2025-10-16. It rewrites much of `stt.py`, so it now conflicts with merged #5509 as well.

### To consider

- **Sample rate is relabelled, not converted** (high, since 2026-08-31) — `_connect_websocket` clamps anything that is not 8000 or 16000 Hz to 16000 and warns "Converting from 24000 Hz to 16000 Hz", but nothing converts: no resampler sits between the pipeline and `run_stt`, which sends the pipeline's bytes as they are. The 2026-08-31 run measured the damage — a 24 kHz clip declared as 16000 produced 15 interims instead of 10, and 16 kHz audio declared as 8000 lost the second half of the transcript. The clamp is not needed at all: presigned URLs declaring 24000 and 48000 Hz were both accepted, and `MediaSampleRateHertz` is documented as 8000-48000. — *Needs a call: pass the pipeline rate through when it is in range, or resample to 16 kHz the way `OpenAIRealtimeSTTService` already does with `create_stream_resampler`.*
- **Remaining streaming request parameters unreachable** (medium, since 2026-08-31) — with `partial_results_stability` on the branch, what is left out of reach is custom vocabulary and vocabulary filter (`get_presigned_url` already takes `vocabulary_name` and `vocabulary_filter_name`, and the service never passes them), `vocabulary-filter-method`, PII redaction/identification with `pii-entity-types`, `language-model-name`, speaker labels and channel identification. — *Needs a call: which subset to expose first. None of them can be probed end to end without account-side resources, so they cannot ride an automatic PR.*
- **`transcript-format` unreachable** (medium, since 2026-09-14) — AWS renders numbers, dates and currency in written form ("$50", "10:30 AM") unless a request asks for `spoken` ("fifty dollars", "ten thirty a m"). The parameter is absent from `get_presigned_url` and from the signer's canonical querystring, so it needs plumbing in `utils.py` on top of a Settings field. Not recorded by earlier runs; the AWS document-history page carries no entry for it either way. — *Needs a call: which rendering serves a voice agent's downstream LLM better, and therefore whether Pipecat keeps AWS's `written` default.*
- **Reconnects lose the session** (medium, since 2026-08-31) — the presigned URL carries neither `session-id` nor `session-resume-window`, so when `WebsocketSTTService` reconnects, AWS treats it as a brand-new stream and the in-flight segment is gone. AWS supports resuming within a 1-300 minute window. — *Needs a call: whether resume earns the state it adds, given how short a voice turn is.*

Closed since the last run: the 46 unmapped streaming language codes and the nine missing `Language` members, both by #5509 (merged 2026-09-03).
