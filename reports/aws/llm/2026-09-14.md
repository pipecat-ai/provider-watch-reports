# AWS Bedrock LLM — 2026-09-14

Nothing at Bedrock moved against the service this fortnight; the retired example model is fixed and merged, and all seven remaining items still need a maintainer's call, so there is no branch.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **Reasoning output is dropped** (medium, since 2026-08-31) — `_process_context` reads `delta["text"]` and `delta["toolUse"]` only, so `delta.reasoningContent` never becomes an `LLMThinking*` frame and never lands in thinking metrics. Re-confirmed today: a plain `converse_stream` to `us.openai.gpt-5.6-terra`, with no reasoning configuration at all, returns a `reasoningContent` delta ahead of its text. Bedrock's 2026-08-24 correction says Claude Sonnet 5 has adaptive thinking on by default, but two probes of `us.anthropic.claude-sonnet-5` through Converse (trivial and reasoning-triggering prompts) returned no `reasoningContent` at all, so the exposure through this service is the same as before. — *Needs a call: whether Bedrock reasoning should map onto the LLMThinking frames the Anthropic service emits, including whether reasoning blocks must be echoed back in later requests and whether the service should ever set a thinking config of its own.*
- **`latency="optimized"` almost never applies** (medium, since 2026-08-31) — the setting sends `performanceConfig`, which Bedrock still previews for Nova Pro, Llama 3.1 70B/405B and Claude 3.5 Haiku only, and Claude 3.5 Haiku is retired, so no Claude model can accept it. Setting it on the default model fails the request with `ValidationException` ("Latency performance configuration is not supported for amazon.nova-lite-v1:0 in us-east-1"), while the docstring offers it as a plain "standard or optimized" mode. — *Needs a call: whether to name the supported models in the docstring, validate before sending, or drop the field as Bedrock narrows the preview.*
- **Nova 2 Lite as the default** (medium, since 2026-08-31) — GA 2025-12-02, works through the class untouched, but it is not faster: TTFAT 602 ms against the default's 524 ms today, in line with the 609/520 ms medians of 2026-08-31. `amazon.nova-lite-v1:0` is still ACTIVE with no EOL date, so there is no deadline. — *Needs a call: aiewf-eval still has no Amazon Nova row of any generation, so the benchmark condition for a default bump cannot be met yet.*
- **Guardrails** (medium, since 2026-08-31) — ConverseStream's `guardrailConfig` (`guardrailIdentifier`, `guardrailVersion`, `trace`, `streamProcessingMode`) has no Settings field and is never sent. — *Needs a call: no guardrail exists in the probe account to verify a pass-through against, and guardrail interventions arriving mid-stream need a stance on what the pipeline should see.*
- **Newer Converse request fields** (low, since 2026-08-31) — `serviceTier` (priority/default/flex/reserved), `outputConfig.textFormat` (Bedrock's JSON-Schema structured output, `OutputFormat.structure.jsonSchema`; no `LLMSettings` field expresses structured output for any provider), and `Tool.systemTool`, which is how Nova 2's built-in web grounding and code interpreter are requested — the Bedrock adapter emits `toolSpec` tools only. — *Needs a call: whether any of these matter for real-time voice, or belong in `additional_model_request_fields`.*
- **`top_k` and `seed` are silently ignored** (low, since 2026-08-31) — `_build_inference_config` sends only what Bedrock's `InferenceConfiguration` accepts (maxTokens/stopSequences/temperature/topP), but docs.pipecat.ai lists both among the service's settings, so setting them looks supported and does nothing. — *Needs a call: whether to route `top_k` through `additionalModelRequestFields` or drop the two from the documented settings.*
- **The service reaches far more than Nova and Claude** (low, since 2026-09-01) — nothing in the class gates the model, and Bedrock's text catalogue is 98 model IDs: `openai.gpt-6-astra` (new on Bedrock 2026-09-08), `xai.grok-4.6`, `zai.glm-5`, `nvidia.nemotron-super-3-120b`, Qwen, Mistral, Llama. The class docstring and docs.pipecat.ai still describe the service as Nova and Claude support. — *Needs a call: whether to widen the wording, and whether the docs change belongs in this repo or in the docs repo.*

Closed since the last run: `examples/flows/python/llm_switching.py` now pins `us.anthropic.claude-haiku-4-5-20251001-v1:0` (ACTIVE), via pipecat-ai/pipecat#5525, merged 2026-09-03.
