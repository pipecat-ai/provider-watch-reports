# AWS Bedrock LLM — 2026-09-01

Nothing the service ships is retiring and the catalogue is unchanged since yesterday; the one actionable item is the LLM switching example, whose Bedrock model is past end of life — the branch is rebuilt since last run's PR cap kept it unpublished.

## What's new for Pipecat

### PRs

- https://github.com/pipecat-ai/pipecat/pull/5525 — Use an available Bedrock Haiku in the LLM switching example

### To consider

- **Reasoning output is dropped** (medium, since 2026-08-31) — `_process_context` reads `delta["text"]` and `delta["toolUse"]` only, so `delta.reasoningContent` never becomes an `LLMThinking*` frame and never lands in thinking metrics. This is no longer confined to models a user opts into: a plain `converse_stream` to `us.openai.gpt-5.6-terra`, with no reasoning configuration at all, returns one `reasoningContent` delta ahead of its 74 text deltas. — *Needs a call: whether Bedrock reasoning should map onto the LLMThinking frames the Anthropic service emits, including whether reasoning blocks must be echoed back in later requests and whether the service should ever set a thinking config of its own.*
- **`latency="optimized"` almost never applies** (medium, since 2026-08-31) — the setting sends `performanceConfig`, which Bedrock previews for Nova Pro, Llama 3.1 70B/405B and Claude 3.5 Haiku only — and Claude 3.5 Haiku is now retired, so no Claude model can accept it. Setting it fails the request outright with `ValidationException`, while the docstring offers it as a plain "standard or optimized" mode. — *Needs a call: whether to name the supported models in the docstring, validate before sending, or drop the field as Bedrock narrows the preview.*
- **Nova 2 Lite as the default** (medium, since 2026-08-31) — GA 2025-12-02, one-million-token context, reasoning off by default, and it works through the class untouched. Last run measured it slower than the current default (TTFAT 609 ms against 520 ms, medians of 5). `amazon.nova-lite-v1:0` is still ACTIVE with no EOL date, so there is no deadline. — *Needs a call: aiewf-eval still has no Amazon Nova row of any generation, so the benchmark condition for a default bump cannot be met yet.*
- **Guardrails** (medium, since 2026-08-31) — ConverseStream's `guardrailConfig` (`guardrailIdentifier`, `guardrailVersion`, `trace`, `streamProcessingMode`) has no Settings field and is never sent. — *Needs a call: no guardrail exists in the probe account to verify a pass-through against, and guardrail interventions arriving mid-stream need a stance on what the pipeline should see.*
- **Newer Converse request fields** (low, since 2026-08-31) — `serviceTier` (priority/default/flex/reserved), `outputConfig`, and `Tool.systemTool`, which is how Nova 2's built-in web grounding and code interpreter are requested; the Bedrock adapter emits `toolSpec` tools only. — *Needs a call: whether any of these matter for real-time voice, or belong in `additional_model_request_fields`.*
- **`top_k` and `seed` are silently ignored** (low, since 2026-08-31) — `_build_inference_config` sends only what Bedrock's `inferenceConfig` accepts, but docs.pipecat.ai lists both among the service's settings, so setting them looks supported and does nothing. — *Needs a call: whether to route `top_k` through `additionalModelRequestFields` or drop the two from the documented settings.*
- **The service reaches far more than Nova and Claude** (low, since 2026-09-01) — nothing in the class gates the model, and Bedrock's text catalogue is 80+ models: `openai.gpt-5.6-terra`, `xai.grok-4.6`, `zai.glm-5`, `nvidia.nemotron-super-3-120b`, Qwen, Mistral, Llama. A probe of `us.openai.gpt-5.6-terra` through the class returns text with no changes. The class docstring and docs.pipecat.ai still describe the service as Nova and Claude support. — *Needs a call: whether to widen the wording, and whether the docs change belongs in this repo or in the docs repo.*

Probes need `AWS_BEARER_TOKEN_BEDROCK` unset: the runner exports it empty, botocore then signs Bedrock requests as bearer auth, and the service rejects them. Not a Pipecat defect, but it is what a first failing probe on this unit looks like.

`.pw-scratch/bedrock_catalogue.py` and `.pw-scratch/bedrock_text_models.py` are the ad-hoc catalogue listings (`ListFoundationModels` / `ListInferenceProfiles`); `.pw-scratch/bedrock_delta_kinds.py` makes one `converse_stream` call and counts event and delta kinds, which is how the `us.openai.gpt-5.6-terra` reasoning delta was found.
