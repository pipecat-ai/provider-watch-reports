# Soniox STT — 2026-08-25

Current: `stt-rt-v5` is Soniox's recommended real-time model and the one we ship; nothing is retiring and no branch is proposed.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Real-time translation** (medium, since 2026-08-25) — v5 does transcription and translation on one stream via a `translation` config object (`one_way` with `target_language`, or `two_way` with `language_a`/`language_b`); `SonioxSTTSettings` has no field for it and `_connect_websocket` never sends the key. — *Needs a call: translation tokens arrive interleaved with the originals and are distinguished only by `translation_status`, with no timestamps, so `_receive_messages` would have to decide whether they become their own frames or are dropped from the transcript — not a pass-through field.*
- **Legacy context wording** (low, since 2026-08-25) — `SonioxContextObject`'s docstring says it is "for models with context_version 2, for Soniox stt-rt-v3-preview and higher", and `SonioxSTTSettings.context` repeats the version-1-string / version-2-object split; Soniox's current context docs describe a single object form and name no versions, and v1–v3 preview models are retired. — *Needs a call: whether stt-rt-v5 still honours a plain-string `context` — if it does the string branch stays and only the wording changes, if not the branch is dead.*
