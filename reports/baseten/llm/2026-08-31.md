# Baseten LLM — 2026-08-31

Nothing to ship: `moonshotai/Kimi-K2.6` is still offered and undeprecated, and its successor Kimi K3 is not eligible for a default bump yet.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **Kimi K3 as the default** (medium, since 2026-08-31) — Moonshot released K3 on 2026-07-16 as the flagship successor to the K2 family (K2.6, K2.7 Code) and Baseten added it to Model APIs on 2026-07-27. Out of the box it reasons: `thinking_ms` 806, TTFAT 1632 ms median of 5, against 618 ms for the current default. Baseten documents `reasoning_effort: none` for K3, which Pipecat can already pass through `Settings.extra`; with it, K3 measures 623 ms — parity with K2.6. — *Needs a call: aiewf-eval's `aiwf_medium_context` leaderboard has no Kimi K3 row, so there is no pass-rate evidence against K2.6's 98.3% (thinking on) / 93.9% (thinking off); and a bump would have to decide whether Pipecat ships `reasoning_effort: none` for it.*
