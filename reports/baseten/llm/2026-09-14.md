# Baseten LLM — 2026-09-14

`zai-org/GLM-5.3` became the default yesterday (pipecat-ai/pipecat#5730) and it reasons at `high` out of the box: TTFAT is 2167 ms median against 363 ms for GLM-5.2 — a latency call for a maintainer, not something to ship automatically.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **GLM-5.3 reasons by default** (high, since 2026-09-14) — Baseten documents `reasoning_effort` for the GLM 5.3 family as "enabled by default" at `high`, and the probes show it: TTFAT 2167 ms median of 5 (thinking 1470 ms) on a trivial prompt, 1278 ms on a reasoning-triggering one, against 363 ms / 304 ms for `zai-org/GLM-5.2`. `Settings.extra={"reasoning_effort":"none"}` gets it to 1253 ms — Baseten notes GLM 5.3 can still return short reasoning content under `none`, which the residual 273 ms of thinking confirms — and `zai-org/GLM-5.3-Fast`, same weights on dedicated capacity, is 1672 ms at its default effort. aiewf-eval's `aiwf_medium_context` puts glm-5.3 (low reasoning, Z.AI) at 98.7% / 2376 ms TTFAT P50, below glm-5.2 (none, Baseten) at 99.7% / 936 ms. — *Needs a call: shipping `reasoning_effort: none` by default changes behavior for every user on the default and still leaves ~1.25 s; defaulting to GLM-5.2 instead means moving backwards in model version. Either way it is a deliberate choice, not a mechanical bump.*
- **Docs name a retiring model as the default** (low, since 2026-09-14) — https://docs.pipecat.ai/api-reference/server/services/llm/baseten still documents `moonshotai/Kimi-K2.6`, which Baseten retires at 5pm PT on 2026-09-25, and recommends it for low time-to-first-word. The code defaults to `zai-org/GLM-5.3`. — *Needs a call: the page lives in the docs repo, outside this repo's reach.*

Baseten's 2026-09-13 notice retires GLM 4.7, Kimi K2.7, Kimi K2.6, Inkling, Inkling Small and DeepSeek v4 Pro on 2026-09-25. Nothing in `src/`, `examples/` or the tests pins any of those strings, so only users who set them explicitly are affected. The 2026-09-01 gap — Kimi K3 as successor to the K2.6 default — no longer holds now that the default has left the Kimi family; K3 is still served and still absent from the aiewf-eval leaderboard. The two catalogue additions since the last run, `zai-org/GLM-5.3-Fast` and `deepseek-ai/DeepSeek-V4.1-Flash`, need no code change: the service passes `model` through untouched, and the Fast slug probed clean.
