# DeepSeek LLM — 2026-09-01

`deepseek-v4-flash` remains the right default; the open question is thinking, which DeepSeek runs by default and Pipecat cannot currently switch off except through an `extra_body` incantation.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5528 — Add a thinking setting to DeepSeekLLMService

### To consider
- **Thinking is on by default** (high, since 2026-09-01) — every V4 model thinks before answering at `high` effort unless the request says otherwise. Median TTFAT on `deepseek-v4-flash` is 1269 ms vs 921 ms with thinking disabled on a trivial prompt, and 2392 ms vs 790 ms on a reasoning-triggering one. aiewf-eval's medium-context rows agree that less thinking is better here: `deepseek-v4-flash-0731 (low)` 96.7% / 677 ms beats `(high)` 93.9% / 763 ms. `AnthropicLLMService._maybe_disable_thinking` already does the equivalent for Sonnet 5 and later. — *Needs a call: turning thinking off by default changes behavior for existing bots, so it is a maintainer's decision rather than an automatic bump.*
- **Dead penalty parameters** (low, since 2026-09-01) — `_build_chat_completion_params` always sends `frequency_penalty` and `presence_penalty`, which DeepSeek documents as no longer supported and silently ignores; the method docstring still names only `seed` and `max_completion_tokens`. — *Needs a call: whether to drop them from the request or keep sending them for OpenAI-compatible symmetry.*
- **`reasoning_effort` has no field** (low, since 2026-09-01) — DeepSeek accepts `low`/`high`/`max` (with `medium` and `xhigh` folded into `high`) as a top-level OpenAI-format parameter, so `extra={"reasoning_effort": "low"}` reaches the API today. — *Needs a call: whether `extra` is enough for a parameter the OpenAI client forwards unchanged, or it deserves a typed field beside `thinking`.*

No default bump. `deepseek-v4-pro` is GA and scores marginally higher on aiewf-eval (97.3% / 752 ms at low effort), but DeepSeek positions it as the higher-cost tier rather than flash's successor, and it probes slower (median TTFAT 1941 ms vs 1269 ms). `deepseek-v4-flash-vision-exp` is experimental, so never a default; the service takes any model string, so nothing blocks a user from selecting either.
