# Speechmatics TTS — 2026-10-28

Nothing moved on either side. This run pulled the preview host's own OpenAPI spec, which settles
the API-surface question: the request body is `{"text": str}` and nothing else, and the one query
parameter is `output_format` restricted to `wav_16000|pcm_16000`. Pipecat sends all of it, so
there is no missing `Settings` field to add. The five known gaps are unchanged; no branch, since
every one needs a maintainer's call rather than a mechanical edit.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Non-16 kHz sample rate fails every request** (medium, since 2026-08-31) — the spec validates `output_format` against `^(wav_16000|pcm_16000)$`, but the URL builder emits `output_format=pcm_{sample_rate}`. With `sample_rate=None` the service adopts the pipeline's output rate (24 kHz by default) and every synthesis returns 422 with `Service unavailable [422]` and no audio; construction only logs "may cause issues". Reproduced again this run. — *Needs a call: pin 16 kHz regardless of the caller's sample rate, or raise at construction. Pinning is not one line — `run_tts` tags its `TTSAudioRawFrame`s with `self.sample_rate`, so forcing the format without forcing the rate would hand the pipeline mislabelled audio.*
- **Install guard points at a package the extra dropped** (low, since 2026-09-14) — the `speechmatics` extra is `speechmatics-agent-stt~=0.3.0` and `stt.py` imports `speechmatics.agent_stt`, but `tts.py` still does `import speechmatics.rt` as its "did you install the extra?" check. That resolves today only because `speechmatics-agent-stt` requires `speechmatics-rt>=1.1.1` (still true in 0.3.0); the TTS path itself is pure aiohttp. — *Needs a call: point the guard at `speechmatics.agent_stt` to match the extra, or drop it since TTS imports no Speechmatics SDK.*
- **Caller must supply an `aiohttp_session`** (low, since 2026-08-31) — the only Pipecat HTTP TTS service that requires one; `probe.py` cannot construct it, so this unit needs an ad-hoc probe each run. — *Needs a call: making the session optional means the service owns its lifecycle, a constructor change.*
- **Still a preview endpoint** (low, since 2026-08-31) — `base_url` defaults to `https://preview.tts.speechmatics.com`, documented as preview and free with pricing and features subject to change. No GA host is named anywhere, and the changelog has never carried a TTS entry. — *Needs a call: nothing to do until GA announces a stable hostname; re-check each run.*
- **Speechmatics' Pipecat page is out of date** (low, since 2026-08-31) — their integration doc still shows the deprecated `voice_id=` argument. — *Needs a call: the page is in Speechmatics' docs repo; someone has to raise it with them.*
