# Speechmatics TTS — 2026-11-09

Nothing moved. The one new thing since the last run is `speechmatics-tts` 0.2.0 on PyPI (first
release since 2025-11-11), and reading it settles the question: same four voices, same two output
formats, same `{"text": ...}` body, still pointed at the preview host — no affordance Pipecat is
missing. The five known gaps are unchanged; each needs a maintainer's call rather than a
mechanical edit, so there is no branch.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Non-16 kHz sample rate fails every request** (medium, since 2026-08-31) — the OpenAPI spec validates `output_format` against `^(wav_16000|pcm_16000)$`, but the URL builder emits `output_format=pcm_{sample_rate}`. With `sample_rate=None` the service adopts the pipeline's output rate (24 kHz by default) and every synthesis returns 422 with `Service unavailable [422]` and no audio; construction only logs "may cause issues". Reproduced again this run. — *Needs a call: pin 16 kHz regardless of the caller's sample rate, or raise at construction. Pinning is not one line — `run_tts` tags its `TTSAudioRawFrame`s with `self.sample_rate`, so forcing the format without forcing the rate would hand the pipeline mislabelled audio.*
- **Install guard points at a package the extra dropped** (low, since 2026-09-14) — the `speechmatics` extra is `speechmatics-agent-stt~=0.3.0` and `stt.py` imports `speechmatics.agent_stt`, but `tts.py` still does `import speechmatics.rt` as its "did you install the extra?" check. That resolves today only because `speechmatics-agent-stt` 0.3.0 requires `speechmatics-rt>=1.1.1`; the TTS path itself is pure aiohttp. — *Needs a call: point the guard at `speechmatics.agent_stt` to match the extra, or drop it since TTS imports no Speechmatics SDK.*
- **Caller must supply an `aiohttp_session`** (low, since 2026-08-31) — the only Pipecat HTTP TTS service that requires one; `probe.py run` fails at the constructor, so this unit needs an ad-hoc probe each run. — *Needs a call: making the session optional means the service owns its lifecycle, a constructor change.*
- **Still a preview endpoint** (low, since 2026-08-31) — `base_url` defaults to `https://preview.tts.speechmatics.com`, documented as preview and free with pricing and features subject to change. Speechmatics' own 0.2.0 client hardcodes the same preview default, no GA host is named anywhere, and the changelog has never carried a TTS entry. — *Needs a call: nothing to do until GA announces a stable hostname; re-check each run.*
- **Speechmatics' Pipecat page is out of date** (low, since 2026-08-31) — their integration doc still shows the deprecated `voice_id=` argument and never mentions `Settings`. — *Needs a call: the page is in Speechmatics' docs repo; someone has to raise it with them.*
