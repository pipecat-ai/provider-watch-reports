# Speechmatics TTS — 2026-09-01

Nothing moved on the provider side: the preview API still takes only `text`, a voice in
the path and `output_format`, and Pipecat reaches all of it. One branch fixes the version
we self-report — the same change last run prepared but the per-run PR cap dropped, so it
is re-cut here.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5569 — Report Pipecat's version in the Speechmatics TTS sm-app tag

### To consider
- **Non-16 kHz sample rate fails every request** (medium, since 2026-08-31) — the API serves only `pcm_16000`/`wav_16000`, but the URL builder emits `output_format=pcm_{sample_rate}`. With `sample_rate=None` the service adopts the pipeline's output rate (24 kHz by default) and every synthesis returns 422 with `Service unavailable [422]`; construction only logs "may cause issues". — *Needs a call: pin 16 kHz regardless of the caller's sample rate, or raise at construction — either changes behavior.*
- **Caller must supply an `aiohttp_session`** (low, since 2026-08-31) — the only Pipecat HTTP TTS service that requires one; `probe.py` cannot construct it, so this unit needs an ad-hoc probe each run. — *Needs a call: making the session optional means the service owns its lifecycle, a constructor change.*
- **Still a preview endpoint** (low, since 2026-08-31) — `base_url` defaults to `https://preview.tts.speechmatics.com`, which Speechmatics documents as preview and free with pricing and features subject to change. — *Needs a call: nothing to do until GA announces a stable hostname; re-check each run.*
- **Speechmatics' Pipecat page is out of date** (low, since 2026-08-31) — their integration doc still shows the deprecated `voice_id=` argument. — *Needs a call: the page is in Speechmatics' docs repo; someone has to raise it with them.*
