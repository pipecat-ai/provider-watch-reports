# Cartesia STT — 2026-09-01

Cartesia published nothing new for STT since the last run; the actionable item is still the pair of missing finalization settings, on a rebuilt branch.

## What's new for Pipecat

Nothing on Cartesia's side. The STT model page still lists `ink-2` (2026-05-22, English) as the only stable model with `ink-whisper` on the older-models page, the changelog's newest STT entry is still July's keyterms/turns-endpoint release, and no STT retirement or sunset date is announced. The `cartesia` extra declares no SDK dependency, so there is no pin to move.

Last run's branch for the finalization settings was never published — it is not in the repo and no `provider-watch` PR exists for this unit — so it is rebuilt here and re-verified against the live API.

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5531 — Expose Cartesia's silence-based finalization controls

### To consider
- **ink-whisper is the older model** (high, since 2026-08-31) — Cartesia's model page marks `ink-2` stable and recommended and files `ink-whisper` under older models, but ink-2 is English-only (`language` accepts only `en`) and, on the manual endpoint this class uses, took 506 ms from speech end to the final transcript against ink-whisper's 205 ms (medians of 5). Cartesia positions ink-2 for the auto-finalizing turns endpoint, which Pipecat already exposes as `CartesiaTurnsSTTService`. No sunset date is announced. — *Needs a call: whether this service should follow ink-2 despite English-only support and the TTFS regression, or stay on ink-whisper and leave ink-2 to `CartesiaTurnsSTTService`.*
- **API version pin** (low, since 2026-08-31) — the STT websocket reference documents `cartesia_version` as `2026-08-14`; the service sends `Cartesia-Version: 2026-03-01`, which still connects and transcribes on both models. — *Needs a call: what 2026-08-14 changes for STT; the API-versioning page is behind a login, so the diff could not be read.*
