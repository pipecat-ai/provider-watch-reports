# Cartesia STT — 2026-08-31

Cartesia now files `ink-whisper` under older models and positions `ink-2` as the stable one, so the default needs a maintainer's call; the clear-cut change is the pair of missing finalization settings, on a branch.

## What's new for Pipecat

Cartesia's STT model page lists exactly one stable model, `ink-2` (2026-05-22, English), and moves `ink-whisper` to an "older models" page. Both still work on the manual `/stt/websocket` endpoint this class uses; ink-2's built-in turn detection lives on the separate `/stt/turns/websocket` endpoint, which Pipecat covers with `CartesiaTurnsSTTService` (unit `cartesia/turns-stt`), so the turn events and their thresholds are not a gap here. The 2026 changelog announces no STT retirement, and Cartesia's batch `/stt` endpoint still requires `ink-whisper`. The `cartesia` extra declares no SDK dependency, so there is no pin to move.

### PRs
- `provider-watch/cartesia-stt-finalization-controls` — review: `git show provider-watch/cartesia-stt-finalization-controls` — Expose Cartesia's silence-based finalization controls

### To consider
- **ink-whisper is the older model** (high, since 2026-08-31) — Cartesia's model page marks `ink-2` stable and recommended and files `ink-whisper` under older models, but ink-2 is English-only (`language` accepts only `en`) and, on the manual endpoint this class uses, took 509 ms from speech end to the final transcript against ink-whisper's 102 ms; it did transcribe the whole clip where ink-whisper's single final dropped the tail. Cartesia positions ink-2 for the auto-finalizing turns endpoint, which Pipecat already exposes separately. No sunset date is announced. — *Needs a call: whether this service should follow ink-2 despite English-only support and the TTFS regression, or stay on ink-whisper and leave ink-2 to `CartesiaTurnsSTTService`.*
- **API version pin** (low, since 2026-08-31) — the STT websocket reference documents `cartesia_version` as `2026-08-14`; the service sends `Cartesia-Version: 2026-03-01`, which still connects and transcribes on both models. — *Needs a call: what 2026-08-14 changes for STT; the API-versioning page is behind a login, so the diff could not be read.*
