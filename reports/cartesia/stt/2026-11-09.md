# Cartesia STT — 2026-11-09

Current; no branch. PR #5531 merged on 2026-11-07, so `min_volume` and `max_silence_duration_secs` now reach the request; nothing else moved on either side.

## What's new for Pipecat

`CartesiaSTTSettings` carries `min_volume` and `max_silence_duration_secs`, scoped to ink-whisper with a warning on other models — the one gap this unit had a PR for is closed, and a probe with both set transcribes.

Cartesia published nothing new: the changelog's newest STT entry is still September's "Ink-2 is now multilingual", the STT models page still lists `ink-2` (Stable) and `ink-preview` (Preview) at 2026-09-17 with the same five languages, `ink-whisper` is still Stable on the older-models page (snapshot `ink-whisper-2025-06-04`, 100 languages, no sunset), and the `/stt/websocket` query schema is unchanged down to the per-model scoping and the single documented `cartesia_version`. The `cartesia` extra declares no SDK dependency, so there is no pin to move.

### PRs
Nothing.

### To consider
- **ink-whisper is the older model** (medium, since 2026-08-31) — Cartesia's flagship is `ink-2`, with `ink-whisper` filed under older models. The latency gap has not moved in five runs: TTFS 749 ms against 266 ms this run, after medians of 523/239, 516/250 and 506/205. Cartesia's own answer for ink-2 is the auto-finalizing `/stt/turns/websocket`, already shipped as `CartesiaTurnsSTTService`, and ink-whisper still covers 100+ languages with no announced sunset. — *Needs a call: whether this service should follow ink-2 and accept a 2-3x TTFS regression, or stay on ink-whisper and leave ink-2 to `CartesiaTurnsSTTService`.*
- **API version pin** (low, since 2026-08-31) — the service sends `Cartesia-Version: 2026-03-01`; the reference documents `2026-08-14` as the only value. Both transcribed on both models in earlier runs, and the changelog promises earlier pins keep working. — *Needs a call: what 2026-08-14 changes for STT; the API-versioning page still 307s to a login, so the diff could not be read.*
