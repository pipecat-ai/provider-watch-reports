# Cartesia STT — 2026-09-14

Cartesia released `ink-preview` on 2026-09-04; it works through this class untouched, but our keyterm model gate silently drops keyterms for it — branch ready.

## What's new for Pipecat

`ink-preview` (2026-09-04, preview) joins `ink-2` on the current STT models page: English, French, Hindi, Japanese and Spanish, against ink-2's English-only. `/stt/websocket` accepts it as a `model` value and this class passes the model straight through, so it transcribes today with no change. The API reference documents `keyterm` as "Used by `ink-2` and `ink-preview` only", but the service gates keyterms on the literal prefix `ink-2`, so an ink-preview connection loses them with a warning — that is the branch.

Nothing else moved: `ink-2` is still the only stable model, `ink-whisper` is still on the older-models page with no retirement date, and the changelog's newest entry is August's Sonic 3.6 / API version 2026-08-14 release with no STT content. The `cartesia` extra declares no SDK dependency, so there is no pin to move.

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5738 — Send Cartesia keyterms for ink-preview models
- https://github.com/pipecat-ai/pipecat/pull/5531 — Expose Cartesia's silence-based finalization controls (open since last run)

### To consider
- **ink-whisper is the older model** (high, since 2026-08-31) — Cartesia marks `ink-2` stable and recommended and files `ink-whisper` under older models, but ink-2 is English-only and, on the manual endpoint this class uses, took 516 ms from speech end to the final transcript against ink-whisper's 250 ms (single samples today, consistent with last run's medians of 506 and 205). `ink-preview` widens language coverage to five languages but is preview, so it is not a default candidate. Cartesia positions ink-2 for the auto-finalizing turns endpoint, already exposed as `CartesiaTurnsSTTService`; ink-whisper still covers 100+ languages and has no announced sunset. — *Needs a call: whether this service should follow ink-2 despite English-only support and the TTFS regression, or stay on ink-whisper and leave ink-2 to `CartesiaTurnsSTTService`.*
- **API version pin** (low, since 2026-08-31) — the STT websocket reference lists `2026-08-14` as the only `cartesia_version` value; the service sends `Cartesia-Version: 2026-03-01`, which still connects and transcribes on all three models. — *Needs a call: what 2026-08-14 changes for STT; the API-versioning page is still behind a login, so the diff could not be read.*
