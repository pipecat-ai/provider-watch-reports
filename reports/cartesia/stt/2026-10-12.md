# Cartesia STT — 2026-10-12

Current; no branch this run. The one change since last run is that ink-2 is multilingual, which answers half of the open default question and leaves the latency half.

## What's new for Pipecat

September's changelog entry makes `ink-2` multilingual — Spanish, French, Hindi and Japanese alongside English, with semantic endpointing — and the models page now dates both `ink-2` and `ink-preview` to 2026-09-17 with the same five languages. That retires the "ink-2 is English-only" objection to bumping this service's default, but not the latency one: re-measured with 5 interleaved runs, ink-2 takes 523 ms from end of speech to the final transcript against ink-whisper's 239 ms, the same 2x gap the last two runs saw. The announcement also scopes multilingual ink-2 to the Playground and the turns websocket, and the `/stt/websocket` reference still marks `language` as ink-whisper-only, so there is no documented way to ask for Spanish ink-2 through this class — the parameter is accepted and ignored rather than rejected.

Keyterms for ink-preview landed (#5738, merged 2026-09-14) and the code carries the fix. `ink-whisper` is still Stable on the older-models page with no sunset date. No new API version, no STT deprecations, and the `cartesia` extra still declares no SDK dependency, so there is no pin to move.

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5531 — Expose Cartesia's silence-based finalization controls (open since 2026-09-01)

### To consider
- **ink-whisper is the older model** (medium, since 2026-08-31) — Cartesia's flagship is `ink-2`, with `ink-whisper` filed under older models, and ink-2's September multilingual release removes the language gap. Latency does not follow: median TTFS 523 ms against 239 ms (median of 5 each, interleaved), consistent with 516/250 and 506/205 in the two previous runs. Cartesia's own answer for ink-2 is the auto-finalizing `/stt/turns/websocket`, already shipped as `CartesiaTurnsSTTService`, and ink-whisper still covers 100+ languages with no announced sunset — so the item is no longer `high`. — *Needs a call: whether this service should follow ink-2 and accept a 2x TTFS regression, or stay on ink-whisper and leave ink-2 to `CartesiaTurnsSTTService`.*
- **API version pin** (low, since 2026-08-31) — the service sends `Cartesia-Version: 2026-03-01`; the reference documents `2026-08-14` as the only value. Both transcribe on ink-whisper and ink-2 today, and the changelog promises earlier pins keep working. — *Needs a call: what 2026-08-14 changes for STT; the API-versioning page is still behind a login, so the diff could not be read.*
