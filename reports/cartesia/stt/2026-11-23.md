# Cartesia STT — 2026-11-23

Cartesia moved on ink-preview: 44 languages and a `language_hint` parameter, plus a keyterm limit five times ours. No branch — each needs a call first.

## What's new for Pipecat

The STT models page re-dated `ink-preview` to 2026-11-17 and raised it from five languages to 44; `ink-2` is re-dated 2026-10-13, still Stable, still en/es/fr/hi/ja and still the recommended production model. Two `/stt/websocket` schema changes came with it, neither reachable from this class:

- `language_hint` (repeatable, up to 6 base codes) steers ink-preview's multilingual transcription. Ad-hoc connections show ink-preview accepting it, and ink-2 closing the socket with 1008 "Language hints not supported" — so exposing it needs the same model gate `keyterm` and the finalization fields already have. `CartesiaTurnsSTTService` has the field; the helper that normalizes it lives in the turns module, not the shared one.
- Keyterm limits are now per model: 500 terms / 5000 characters for ink-preview against ink-2's 100 / 1200. `_prepare_keyterms` applies 100 / 1200 to everything, so a 300-term ink-preview connection — which the API accepts — loses 200 terms with a warning.

PR #5531 merged on 2026-11-07, so `min_volume` and `max_silence_duration_secs` reach the request; that gap stays closed. `ink-whisper` is unchanged on the older-models page (snapshot `ink-whisper-2025-06-04`, 100 languages, no sunset), the changelog has no October or November STT entries, and the `cartesia` extra declares no SDK dependency, so there is no pin to move.

### PRs
Nothing.

### To consider
- **ink-whisper is the older model** (medium, since 2026-08-31) — Cartesia's recommended production model is `ink-2`, with `ink-whisper` filed under older models. The latency gap has not moved in six runs: TTFS 759 ms against 218 ms this run, after medians of 523/239, 516/250 and 506/205. ink-2 also rejects the two parameters ink-preview gained, and ink-whisper still covers 100 languages with no announced sunset, while Cartesia's own answer for ink-2 is the auto-finalizing `/stt/turns/websocket`, already shipped as `CartesiaTurnsSTTService`. — *Needs a call: whether this service should follow ink-2 and accept a 2-3x TTFS regression, or stay on ink-whisper and leave ink-2 to `CartesiaTurnsSTTService`.*
- **`language_hint` is not exposed** (medium, since 2026-11-23) — ink-preview's 44 languages are only selectable through `language_hint`, which `CartesiaSTTSettings` has no field for; a `language_hints` field, a model gate and repeated query parameters would do it. — *Needs a call: whether to lift `_prepare_language_hints` out of `CartesiaTurnsSTTService` into the shared module, and whether this class should stop sending its always-set `language=en` on ink-preview, which the reference scopes to ink-whisper.*
- **Keyterm cap is ink-2's for every model** (medium, since 2026-11-23) — `_prepare_keyterms` truncates to 100 terms / 1200 characters, while ink-preview documents and accepts 500 / 5000. — *Needs a call: whether per-model caps are worth changing a helper shared with the turns service, given Cartesia's ~8 KB URL limit — 500 terms of 5000 characters can exceed it once URL-encoded, and an over-long URL fails the handshake with HTTP 414.*
- **API version pin** (low, since 2026-08-31) — the service sends `Cartesia-Version: 2026-03-01`; the reference documents `2026-08-14` as the only value, and as a `cartesia_version` query parameter rather than a header. Both forms are accepted and all three models transcribed this run. — *Needs a call: what 2026-08-14 changes for STT; the API-versioning page still 307s to a login, so the diff could not be read.*
