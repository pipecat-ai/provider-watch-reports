# Cartesia Turns STT — 2026-09-14

Two items closed in code since the last run; the one new thing from Cartesia is `ink-preview`, which works through the class today but has its transcripts labeled English.

## What's new for Pipecat

`ink-preview` (September 4, 2026, Preview) joined `ink-2` on `/stt/turns/websocket`: English, French, Hindi, Japanese and Spanish, language auto-detected. It is Preview, so it is not a default candidate, and nothing in the class blocks it — passing `settings=CartesiaTurnsSTTSettings(model="ink-preview")` connects and transcribes (probe below). What it exposes is the class's fixed `Language.EN`: the turn events carry no detected language, the service treats a `language` settings update as unhandled, and the docstrings on both the class and `CartesiaTurnsSTTSettings` still describe the family as English-only.

Nothing else moved. Cartesia's latest changelog entry is still August 2026 (Sonic 3.6 TTS, the 2026-08-14 API version, Managed Agents); no STT entry since. `ink-2` remains Stable, English-only and undeprecated, the turn event set the service handles still matches the spec, and the `cartesia` extra declares no SDK dependency, so there is no pin to move.

Two previous gaps are gone. Pipecat PR #5533 (merged 2026-09-03) landed the four `turn_*` threshold fields — they are in `CartesiaTurnsSTTSettings` on main and on our docs page. The `turn.eager_end` gap is closed by PR #5625: the class now mixes in `EagerEndOfTurnSTTServiceMixin`, takes `enable_eager_end_of_turn`, and pairs with `EagerUserTurnStrategies`, so the pipeline speculates on the prediction and drops the work on `turn.resume` — the framework design that item was waiting on.

### PRs
Nothing.

### To consider
- **`ink-preview` language labeling** (medium, since 2026-09-14) — Cartesia's multilingual Ink runs on this endpoint and through this class unchanged, but the constructor fixes `self._language = Language.EN` and refuses a `language` update, so non-English turns reach the LLM tagged English; the docstrings and our docs page still say English-only. — *Needs a call: the server reports no detected language, so either the user declares one or frames go out unlabeled when the model is not `ink-2`.*
- **Mid-session `config` command** (low, since 2026-08-31) — the endpoint takes `{"type": "config", "turn": {...}}` as a text message to retune turn detection on a live socket; the merged threshold support applies a change by reconnecting, mirroring how a changed keyterm list is handled. — *Needs a call: whether retuning mid-call justifies a second update path, and a probe that the config command is honored under the API version the service pins.*
- **API version** (low, since 2026-08-31) — the AsyncAPI spec makes `cartesia_version` a required query parameter whose only listed value is `2026-08-14`, while the service pins `Cartesia-Version: 2026-03-01` as a header and transcribes normally. The changelog now describes 2026-08-14 as a multilingual-voice cleanup that also drops already-deprecated fields, and says pinned integrations keep running unchanged. — *Needs a call: whether that cleanup touches STT at all, since the same header is pinned by the other Cartesia STT and TTS services.*
