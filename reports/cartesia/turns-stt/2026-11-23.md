# Cartesia Turns STT — 2026-11-23

A setting Pipecat shipped last week kills the service on its own default model; no other provider movement, and no branch, because the fix is a design call rather than a value.

## What's new for Pipecat

Cartesia revised the turns API reference, the languages page and the keyterms page since the last run, all of it after the September changelog entry and none of it announced in the changelog (which now has October entries, all TTS, Voice Agents and voices — nothing for STT, and still nothing for November). The substance: `language_hint`, the `languages` detection array on turn events, the `words` timing array, and mid-session `config` updates for keyterms and hints are now documented as **`ink-preview` only**. `ink-2` stays at en/fr/hi/ja/es with automatic detection and no hints; `ink-preview` moved to 44 languages on November 17. Neither model is deprecated and the page names no successor to `ink-2`, recommending it for production precisely because `ink-preview` can change without notice.

Pipecat added `language_hints` and detected-language reporting on 2026-11-17/18 (`00dc70100`, `0c18acf1c`). That closes last run's top gap — the constructor no longer pins `Language.EN`, final and eager frames carry the strongest detection from the event, and our docs page no longer calls the family English-only. It also opened the first gap below: hints go onto the connection URL for any model, and `ink-2` rejects them outright.

The 2.6 s TTFB first seen on 2026-10-28 held for a third run (2631 ms), so it remains the endpoint's behavior and not a regression. `ink-preview` is consistently faster (2340 ms) but is a preview model and never a default candidate. The `cartesia` extra still declares no SDK, so there is no pin to move.

### PRs
Nothing.

### To consider
- **`language_hints` breaks `ink-2`** (high, since 2026-11-23) — the docs state plainly that `ink-2` returns an `error` event for hints, and the probe reproduces it: the handshake is rejected with "Model does not support language hints", `_handle_server_error` raises before `connected`, the websocket service marks itself unusable rather than reconnecting, and the worker tears the processor down. A user following the new Settings field with the default model loses STT for the whole call. — *Needs a call: reject hints at construction for a model that can't take them, drop them with a warning, or settle for naming `ink-preview` in the docstring instead of "not every model accepts hints".*
- **Keyterm limits are `ink-2`'s for every model** (medium, since 2026-11-23) — `_prepare_keyterms` truncates at 100 terms / 1,200 characters, which is right for `ink-2` and well under `ink-preview`'s 500 / 5,000, so a preview session silently loses keyterms the server would have taken. — *Needs a call: the constants live in `cartesia/stt.py` and are shared with `CartesiaSTTService`, so a per-model table is a two-unit change.*
- **Mid-session `config` command** (low, since 2026-08-31) — the endpoint takes `{"type": "config", "turn": {...}}` to retune turn detection on a live socket, and a `keyterms` array on `ink-preview`; the service already sends `config` for `language_hints` but reconnects for thresholds and keyterms. The reconnect is the only option for `ink-2` keyterms, which cannot change mid-stream. — *Needs a call: whether retuning mid-call justifies a second update path, and a probe that the config command is honored under the API version the service pins.*
- **API version** (low, since 2026-08-31) — the spec makes `cartesia_version` a required query parameter whose only listed value is `2026-08-14`, while the service pins `Cartesia-Version: 2026-03-01` as a header and transcribes normally on both models. — *Needs a call: whether that cleanup touches STT at all, since the same header is pinned by the other Cartesia STT and TTS services.*
- **`ink-preview` word timestamps** (low, since 2026-11-23) — turn events now carry an optional `words` array with per-word `start`/`end` seconds on `ink-preview`; the raw event reaches `result` but nothing is surfaced. — *Needs a call: whether per-word timing belongs on STT frames when only a preview model produces it.*
