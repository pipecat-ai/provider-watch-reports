# Cartesia Turns STT — 2026-10-28

Nothing changed on Cartesia's side this cycle; the three open items are the same calls as last run, and last run's branch is merged.

## What's new for Pipecat

Cartesia's 2026 changelog has no October entry — the last STT item is still September's "Ink-2 is now multilingual". The STT model page lists the same two models (`ink-2` Stable, `ink-preview` Preview, both dated September 17, 2026, both covering en/fr/hi/ja/es), neither deprecated and no successor named; `ink-whisper` sits on the older-models page and the turns endpoint does not accept it. The AsyncAPI spec is unchanged in every respect the service touches: the `model` enum, the four `turn_*` ranges and defaults, the event set, the `close` and `config` commands, and `cartesia_version` with `2026-08-14` as its only value. The `cartesia` extra still declares no SDK dependency, so there is no pin to move, and `examples/voice/voice-cartesia-turns.py` pins no model or threshold string.

PR #6123 merged on 2026-10-12, so `CartesiaTurnsSTTSettings` and our docs page now quote the published ranges (0.3–0.8 default 0.6 for the eager end, default 0.3 for the end), and that gap is gone. The docs page still describes the family as English-only, which is the language item below and not a separate gap.

The probe's TTFB came in at 2618 ms against 858 ms on 2026-10-12, tight across three interleaved runs. The transcript is correct and nothing in the service or the API changed to explain it, so it is recorded rather than acted on; re-measure next run before reading anything into it.

### PRs
- https://github.com/pipecat-ai/pipecat/pull/6123 — Document Cartesia's current turn detection ranges (merged 2026-10-12)

### To consider
- **`ink-2` language labeling** (medium, since 2026-09-14) — the default model transcribes en/fr/hi/ja/es with auto-detection and the class handles all of it unchanged, but `self._language = Language.EN` is fixed and a `language` update is refused, so non-English turns go downstream tagged English; the class and Settings docstrings and our docs page still describe the family as English-only. — *Needs a call: the server reports no detected language on any event, so either the user declares one or frames go out unlabeled.*
- **Mid-session `config` command** (low, since 2026-08-31) — the endpoint takes `{"type": "config", "turn": {...}}` as a text message to retune turn detection on a live socket; the merged threshold support applies a change by reconnecting, mirroring how a changed keyterm list is handled. — *Needs a call: whether retuning mid-call justifies a second update path, and a probe that the config command is honored under the API version the service pins.*
- **API version** (low, since 2026-08-31) — the spec makes `cartesia_version` a required query parameter whose only listed value is `2026-08-14`, while the service pins `Cartesia-Version: 2026-03-01` as a header and transcribes normally. The changelog describes 2026-08-14 as a multilingual-voice cleanup that also drops already-deprecated fields, and says pinned integrations keep running unchanged. — *Needs a call: whether that cleanup touches STT at all, since the same header is pinned by the other Cartesia STT and TTS services.*
