# Google TTS — 2026-09-14

Nothing changed on either backend since the last run: both open PRs merged, `gemini-3.1-flash-tts-preview` is still Google's newest TTS model, and all three classes synthesize. The five carried-forward items are the same Cloud TTS request fields Settings cannot express.

## What's new for Pipecat

### PRs
Nothing.

Both PRs from the last run merged on 2026-09-03 and their gaps are closed: #5537 (`language` now reaches the Gemini API backend — `_run_genai_tts` sets `SpeechConfig.language_code`) and #5526 (the `GeminiTTSService` docstring names the model spellings each backend accepts).

### To consider
- **GenAI backend drops `prompt` and `multi_speaker`** (medium, since 2026-09-01) — `_warn_unsupported_genai_settings` warns that the Gemini API supports neither, and `_run_genai_tts` sets neither, while Google's speech-generation reference documents `multi_speaker_voice_config` and natural-language style prompts for all three of its TTS models. Style prompting is not unconditional, though: `Say cheerfully: …` returned 184320 bytes and `Say this in a slow, dramatic whisper: …` came back with no audio. — *Needs a call: map `speaker_configs` onto `SpeakerVoiceConfig` and prefix `prompt` to the content, or keep the warning because prompt-as-content-prefix is unreliable?*
- **Chirp voices never get SSML** (medium, since 2026-09-01) — `GoogleHttpTTSService.run_tts` takes the plain-text branch for any voice whose name contains "chirp", and the class default is `en-US-Chirp3-HD-Charon`, so `pitch`, `rate`, `volume`, `emphasis` and `gender` do nothing unless the user picks a non-Chirp voice. Chirp 3 HD accepts SSML on the synchronous endpoint (`<speak><prosody rate='slow'>…` synthesized 160416 bytes against 121004 plain). Streaming still has no SSML, so `GoogleTTSService` is unaffected. — *Needs a call: Chirp 3 HD rejects `interpret-as="expletive"`/`"bleep"` and Journey voices are untested, so removing the branch needs a stance on which voices keep the plain-text path.*
- **`custom_pronunciations`** (medium, since 2026-09-01) — Cloud TTS takes IPA/X-SAMPA pronunciation overrides on `SynthesisInput` (synchronous) and `StreamingSynthesizeConfig` (streaming); neither class exposes them, and they are the standard fix for brand and person names. — *Needs a call: the field is a nested proto (phrase, phonetic_encoding, pronunciation), so a Settings field needs a shape — a list of dicts converted in the request builder, or the proto exposed directly?*
- **`markup` input and `advanced_voice_options`** (low, since 2026-09-01) — both classes always send `SynthesisInput(text=...)`. `markup` carries Chirp 3 pause tags and Gemini structured markup, and `advanced_voice_options` carries `enable_textnorm`, `relax_safety_filters` and `safety_settings`. — *Needs a call: pause control and custom pronunciations are Preview on Chirp 3 HD and relaxed safety filters require a monthly-invoiced billing account — is a Settings field worth it for gated features?*
- **Preview model as the default** (low, since 2026-09-01) — `gemini-3.1-flash-tts-preview` is still Preview on Cloud Text-to-Speech and still the only 3.x TTS model; the Gemini API publishes no GA TTS model at all, so the GenAI backend has no GA alternative. A second unannounced catalogue entry, `sonic-bolt-tts`, joined `sonic-boom-tts` in the Gemini API list this run and synthesizes through the class, but neither is documented anywhere. — *Needs a call: is a preview default acceptable while it is the only 3.x TTS model, or should the Cloud TTS path fall back to GA `gemini-2.5-flash-tts`?*
