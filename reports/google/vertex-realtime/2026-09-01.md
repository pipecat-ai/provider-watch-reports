# Gemini Live Vertex (realtime) — 2026-09-01

The default model is current — `gemini-live-2.5-flash-native-audio` is the only GA live
native-audio model Vertex publishes — but `pipecat init` scaffolds this service with Python
that does not compile.

## What's new for Pipecat

### PRs
Nothing.

### To consider

- **`pipecat init` scaffold does not parse** (high, since 2026-09-01) — the
  `gemini_vertex_live_realtime` entry in `pipecat.cli.registry._configs.SERVICE_CONFIGS`
  (duplicated in `service_metadata.MANUAL_SERVICE_CONFIGS`) over-indents the constructor
  args and closes the call twice, so the generated bot file raises `SyntaxError: unmatched
  ')'`. It is the only one of the 100 entries that fails `compile()`. Dropping the stray
  `    ),` line and re-indenting to 4 spaces fixes it. — *Needs a call: whether to fix only
  the parens or also align the snippet's `GOOGLE_PROJECT_ID` / `GOOGLE_LOCATION` /
  `GOOGLE_APPLICATION_CREDENTIALS` with the `GOOGLE_CLOUD_*` names the examples and docs use
  and the registry's `GOOGLE_VERTEX` env prefix.*
- **Refused connections are silent** (medium, since 2026-09-01) — probing
  `google/gemini-3.1-flash-live-preview` made Vertex close the websocket with 1008
  ("Publisher model ... "), but the probe passed: `GeminiLiveLLMService._connection_task_handler`
  awaits `client.aio.live.connect()` outside any `try`, so the exception ends up as an
  unhandled-task log line instead of `push_error`, and the pipeline runs on with no session.
  A retired model string, an unavailable region, or `model=None` from an unset env var all
  land here. — *Needs a call: the fix belongs to the shared base class and needs a stance on
  which connection failures are fatal and whether to retry first.*
- **No Vertex GA for Gemini 3.1 Flash Live** (low, since 2026-09-01) — Google shipped
  `gemini-3.1-flash-live-preview` on the Gemini API on 2026-03-26 and users are asking for the
  Vertex equivalent; on Vertex the publisher entry exists but is EXPERIMENTAL and refuses
  sessions. The default stays on 2.5. — *Needs a call: nothing until it is GA on Vertex;
  re-check each run.*
- **`history_config` suppression may be obsolete** (low, since 2026-09-01) —
  `_get_history_config()` returns None for Vertex (added 2026-03-27, "unsupported"), but
  google-genai 2.18 serializes `history_config` for the Vertex backend and a Vertex session
  accepted `HistoryConfig(initial_history_in_client_content=True)` on the default model. Text-
  seeded history was recalled with and without it, so removing the override buys nothing
  demonstrable yet. — *Needs a call: whether the flag helps the 2.5 audio-input history-recall
  path the base class works around; the check seeded text, not audio.*
