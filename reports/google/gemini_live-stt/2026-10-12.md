# Google Gemini Live STT — 2026-10-12

`gemini-3.5-transcribe-live` is still the current default and works. The repo's google-genai floor rose to 2.25.0 since the last run, which removes the SDK blocker on the transcription `mode` setting — that item is now a branch. The 10-minute session cap and two smaller items carry forward.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/6129 — Add a transcription mode setting to GeminiSTTService

### To consider

- **10-minute session cap** (high, since 2026-09-01) — Google still caps live transcription at 10 minutes per session. `_receive_handler` sees the close as an exception: it logs a warning, pushes an ErrorFrame, and reopens, so any call longer than 10 minutes gets a spurious error and a transcript gap. `go_away` and `session_resumption_update` are both dropped by `_handle_server_message`, and `_build_live_config` sets no `session_resumption`. `GeminiLiveLLMService` already does all of this. — *Needs a call: reuse the LLM service's session-resumption handling, or just stop reporting an expected expiry as an error?*
- **`custom_vocabulary`** (medium, since 2026-09-01) — the documented Live API biasing field (up to 1000 terms) has no Settings field; the service sends `adaptation_phrases`, which google-genai 2.25.0 still marks deprecated. The version question behind this item is settled: the google extra now requires google-genai >= 2.25.0 (except on Python 3.13 + Linux, where the vonage/pydantic conflict keeps the 1.68.0 fallback), and the lock resolves 2.25.0, which carries `custom_vocabulary`. What remains is that Pipecat would then have two fields for one wire parameter. — *Needs a call: rename `adaptation_phrases` with a deprecation, or add `custom_vocabulary` alongside it?*
- **Deprecated language config** (low, since 2026-09-01) — `_build_live_config` sends `LanguageHints(...)` and `LanguageAuto()`, both of which google-genai documents as "will be removed in a future version" in favour of top-level `language_codes`. Removal would come in google-genai 3.x, outside the `<3` pin. — *Needs a call: `language_auto=False` (disable auto-detection without hints) has no equivalent under `language_codes`, so the migration drops a documented Settings behavior.*
