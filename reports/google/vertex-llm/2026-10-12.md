### To consider
- **gemini-3.8-flash as the default** (medium, since 2026-09-14) — now reachable on main (#5741 merged 2026-09-14), but still the slower model on Vertex: TTFAT 1165 ms vs 684 ms for `gemini-3.6-flash` (medians of 5, trivial prompt, `thinking_ms` 0 for both), with a 19.8 s outlier in 3.8's spread. aiewf-eval's medium-context leaderboard still has no 3.8 Flash row, while `gemini-3.6-flash (minimal)` scores 97.1% / 798 ms P50, so the benchmark condition is unmet regardless of latency. Nothing newer is GA on Vertex. — *Needs a call: should this unit follow `google/llm`'s default whenever that moves, or keep its own literal (`services/google/vertex/llm.py:136`) and its own latency bar?*
- **Express-mode API-key auth** (medium, since 2026-09-01) — Vertex express mode authenticates with an API key and needs no project or location, and `google-genai` builds exactly that client from `Client(vertexai=True, api_key=...)`. `GoogleVertexLLMService` raises `ValueError` on `api_key` and requires `project_id`, so express-mode users have no path in. Unchanged since the last run. — *Needs a call: is the `api_key` guard deliberate protection against confusing this class with `GoogleLLMService`, or should it fall through to express mode when no service-account credentials are supplied?*
- **Vertex AI → Gemini Enterprise Agent Platform** (low, since 2026-09-01) — the class's `Reference:` URL redirects into the Agent Platform docs and the old Vertex pages stay frozen behind their banner. Endpoint, model IDs and auth are unchanged. — *Needs a call: refresh the docstring link and docs wording, or leave the "Vertex" naming until Google retires the endpoint?*
- **`location` docstring overstates global** (low, since 2026-09-14) — the docstring calls global "the only location that serves the Gemini 3 series"; the default `gemini-3.6-flash` answers at `location="us"`, and Google's 2026-09-09 note treats us and eu as first-class alongside global. — *Needs a call: name the us and eu multi-regions in the docstring, or keep the simpler global-only guidance?*

Dropped from the previous report: the `gemini-3.8-flash` thinking-level 400, closed by PR #5741 (merged 2026-09-14); `_LOWEST_MODEL_THINKING_LEVELS` in `services/google/llm.py` now sends 3.7 and 3.8 Flash `low`, and the probe below confirms it on Vertex.
