# Moonshine STT — 2026-09-01

Moonshine's catalogue now publishes German and Tagalog; the service's language map
and docstrings still describe the eight-language, English-only-streaming catalogue.
Branch ready. `small-streaming` stays the right default.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5557 — Map German and Tagalog for MoonshineSTTService

### To consider
- **Keyterm biasing** (medium, since 2026-09-01) — `Transcriber.set_keyterms(["Kubernetes", ...])` and `set_context(passage, max_terms)` bias decoding toward domain terms and can be called between segments; the service calls neither. — *Needs a call: both raise `MoonshineError` on non-streaming architectures (`tiny`, `base`), so exposing them needs a stance on what happens when the configured model cannot bias.*
- **Alphanumeric spelling mode** (medium, since 2026-09-01) — `get_model_for_language` already downloads `spelling_cnn.ort` on every run, but `Transcriber` is constructed without `spelling_model_path` and transcribe calls pass `flags=0`, so the digit/letter fusion is dead weight. — *Needs a call: whether spelling fusion should be a Settings flag or on by default, and whether it costs latency on the CPU path.*
- **Streaming partials** (medium, since 2026-09-01) — `SegmentedSTTService` transcribes each VAD segment in one `transcribe_without_streaming` call; Moonshine's own `add_audio` plus listener path emits interim text every `update_interval` and would cut the wait after end-of-turn. — *Needs a call: whether Moonshine gets a second, streaming service class alongside the segmented one.*
- **Word timestamps** (low, since 2026-09-01) — `get_model_for_language(..., include_word_timestamps=True)` fetches an attention decoder that the `word_timestamps` transcriber option uses; neither is requested. — *Needs a call: `TranscriptionFrame` has nowhere to carry word timings, so this needs a frame-level decision first.*
- **No Moonshine TTS service** (low, since 2026-09-01) — the same package ships an on-device TTS with a voice catalog and a streaming synthesizer; Pipecat exposes only the STT half. — *Needs a call: whether a local Moonshine TTS service is wanted next to Kokoro.*

`Model.BASE_STREAMING` is in the enum but published for no language today; the
existing fallback to the language's best model covers it, so it is not a gap.
