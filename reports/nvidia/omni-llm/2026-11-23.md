# NVIDIA Omni LLM — 2026-11-23

Nothing to ship: NIM's catalogue shrank from 84 models to 32 since the last run, and `nemotron-3-nano-omni-30b-a3b-reasoning` is among the survivors — still the only audio-input model served, still carrying no deprecation or successor notice.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Omni reasons on every spoken turn, with no Settings field to stop it** (medium, since 2026-11-09) — the model card still says reasoning is on by default and recommends trying it both ways for omni tasks. Re-probed today: a trivial prompt spends 282 ms thinking before the first answer token (TTFAT 431 ms, 39 thought deltas), while `chat_template_kwargs.enable_thinking=false` answers in 191 ms with no `LLMThought*` frames at all. In audio input mode that thinking time lands between the user falling silent and TTS starting. `NvidiaLLMSettings` still adds no fields of its own, so the switch is reachable only through the nested `extra={"extra_body": {"chat_template_kwargs": {...}}}` form, and `examples/voice/voice-nvidia-omni.py` sets neither it nor `reasoning_budget`. — *Needs a call: a pass-through field has to define what happens when a user also sets `extra_body` directly (nvidia/llm tracks the same question), and nothing benchmarks what capping Omni's reasoning costs in quality.*
- **No TTFAT metric in audio input mode** (low, since 2026-11-09) — `service_metadata_frame()` reports the service as realtime so the user aggregator waits for the transcript; `LLMService.reports_ttfat` derives from that same flag, so `_push_llm_text` never closes the TTFAT measurement. Today's probe shows it unchanged: the default configuration reports TTFB 152 ms and no TTFAT despite 39 thought deltas and 7 text frames, while `audio_input=False` reports TTFAT 431 ms and thinking 282 ms. — *Needs a call: whether the realtime flag should keep gating TTFAT for a service that answers in text rather than audio.*

The default stays: no omni successor exists, and the Nemotron 3.5 wave is still vision-language (`nemotron-3.5-super-vl-120b-a12b`) or text-only (`nemotron-3.5-bolt-e4b`, `nemotron-3.5-lightning-30b-a3b`). The catalogue cull removed about fifty models — `nvidia/nemotron-3-super-120b-a12b`, `deepseek-ai/deepseek-v4.1-flash`, the Llama 2/3.x and Mistral back catalogue, `writer/palmyra-*`, `ibm/granite-*` among them — but nothing this service, its docstrings, or its example names. The sibling `NvidiaLLMService` default (`nvidia/nemotron-3.5-super-vl-120b-a12b`) is still served. Sampling defaults (temperature 0.6, top_p 0.95) still match the model card's thinking-mode row, and the WAV the service builds stays inside the documented audio limits (wav/mp3, 8 kHz or higher, up to 1 hour).
