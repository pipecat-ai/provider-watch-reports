# NVIDIA LLM — 2026-11-23

NVIDIA retired most of its hosted catalogue since the last run (84 models → 32); the shipped default survives and is healthy, but the previous default `nvidia/nemotron-3-super-120b-a12b` now answers HTTP 410 and is still pinned in `evals/turn-completion/manifest.yaml` — branch ready.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/6968 — Move the NVIDIA turn-completion entry to Nemotron 3.5 Super VL

### To consider
- **`/no_think` is inert in the NVIDIA examples** (medium, since 2026-09-01) — `examples/voice/voice-nvidia.py`, `examples/voice/voice-nvidia-segmented.py` and `examples/function-calling/function-calling-nvidia.py` still prefix their system instruction with `/no_think`; probed with that prompt verbatim, the default reasoned anyway (376 ms of thinking, `LLMThought*` frames emitted), while NVIDIA's documented switch suppressed reasoning entirely (686 ms TTFAT, no thought frames). `examples/update-settings/llm/llm-nvidia.py` and `examples/voice/voice-nvidia-sagemaker.py` carry no prefix, so the examples still disagree with each other. The eval manifest's NVIDIA entries carry the same `system_suffix: /no_think`. — *Needs a call: dropping the dead prefix and passing the documented switch are different fixes, and aiewf-eval still has no row for super-vl-120b, thinking on or off, to say what disabling reasoning costs in quality (it cost lightning 83.9% → 69.6%).*
- **No Settings field for NIM's reasoning controls** (medium, since 2026-09-01) — the super-vl-120b model page documents reasoning as configurable through the chat template (`enable_thinking=True/False`); `Settings.extra` is spread as top-level OpenAI kwargs, so the key is only reachable through the nested `extra={"extra_body": {...}}` form. — *Needs a call: a pass-through field has to define what happens when a user also sets `extra_body` directly.*

The default stays. `nvidia/nemotron-3.5-super-vl-120b-a12b` is GA (NVFP4 v1.0, released 2026-10-15) with no lifecycle notice, and the sweep left no candidate successor: the only other NVIDIA chat models served are `nemotron-3-ultra-550b-a55b` and `nemotron-3.5-lightning-30b-a3b` (both older) and `nemotron-3.5-bolt-e4b` (a post-training base, ruled out last run). aiewf-eval's medium-context leaderboard is unchanged from last run — ultra 91.8%, super-120b 90.9%, lightning 83.9% on / 69.6% off, nano-30b 71.9% — and still has no row for the default.

Catalogue churn is a retirement sweep rather than normal turnover: 53 models gone, including the Llama, Mistral, IBM Granite, Microsoft Phi, Writer Palmyra and legacy Nemotron families, plus `deepseek-ai/deepseek-v4.1-flash`, `moonshotai/kimi-k2.6` (replaced by `kimi-k3.1-pro`) and `nvidia/nemotron-3-embed-1b`; `fastino/gliner2-pii` is the only addition. The previous gap "catalogue lists `nvidia/nemotron-nano-3-30b-a3b` but the endpoint does not serve it" is dropped: the model is no longer listed. Of the removals, only `nvidia/nemotron-3-super-120b-a12b` is referenced by the repo, in the turn-completion manifest; the branch moves it. The service, its tests and all five NVIDIA examples pin no model at all, so they follow the default.
