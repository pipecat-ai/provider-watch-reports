# NVIDIA LLM — 2026-09-01

NVIDIA retired the service's default model at 09:00 UTC today, so `NvidiaLLMService()` fails out of the box; the branch moves the default to `nvidia/nemotron-3-super-120b-a12b` and fixes two examples that pin models NIM has also dropped.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5579 — Move NvidiaLLMService off NIM's retired default model and repair the examples that pin retired models

The branch carries two commits. The first swaps the default model constant and its docstring; the second replaces `meta/llama-3.1-405b-instruct` (404) and `meta/llama-3.3-70b-instruct` (410) in the two examples with the new default. The reviewable choice is the successor: `nemotron-3-super-120b-a12b` is the only Nemotron 3 chat model that is served, answers within a voice turn, and scores above the retired default on aiewf-eval (97.0% vs 90.6%). The same-size alternative, `nemotron-3.5-lightning-30b-a3b`, reasons by default and took 12–59 s to its first answer token on the cloud endpoint.

### To consider
- **`/no_think` is ineffective on lightning** (high, since 2026-09-01) — `examples/voice/voice-nvidia.py`, `examples/voice/voice-nvidia-segmented.py` and `examples/function-calling/function-calling-nvidia.py` prefix their system instruction with `/no_think`, but the model still reasoned for 9.8 s of an 11.9 s median TTFAT; `extra_body={"chat_template_kwargs": {"thinking": false}}` did suppress it (736 ms TTFAT). — *Needs a call: aiewf-eval scores lightning at 50.9% pass with thinking off against 93.6% with it on, so the fix is either a quality drop or a different model in those examples.*
- **No Settings field for NIM's reasoning switch** (medium, since 2026-09-01) — `Settings.extra` is spread as top-level OpenAI kwargs, so `chat_template_kwargs` is only reachable through the nested `extra={"extra_body": {...}}` form; passing it directly raises `unexpected keyword argument 'chat_template_kwargs'`. — *Needs a call: a pass-through field has to define what happens when a user also sets `extra_body` directly.*
- **`nemotron-nano-3-30b-a3b` listed but not served** (low, since 2026-09-01) — the catalogue lists it and the name reads like a rename of the retired default, but two probes returned 404 "Not found for account". — *Needs a call: nothing to do until it is served; re-probe next run before treating it as a default candidate.*
