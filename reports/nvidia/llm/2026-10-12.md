### To consider
- **`/no_think` is inert in the NVIDIA examples** (medium, since 2026-09-01) — `examples/voice/voice-nvidia.py`, `examples/voice/voice-nvidia-segmented.py` and `examples/function-calling/function-calling-nvidia.py` still prefix their system instruction with `/no_think`; probed with that prompt verbatim the default reasoned anyway (420 ms thinking inside a 752 ms TTFAT), while NVIDIA's documented switch suppressed reasoning entirely (318 ms TTFAT, no `LLMThought*` frames). The other two NVIDIA examples (`examples/update-settings/llm/llm-nvidia.py`, `examples/voice/voice-nvidia-sagemaker.py`) carry no prefix, so the examples disagree with each other. — *Needs a call: dropping the dead prefix and passing the documented switch are different fixes, and aiewf-eval still has no thinking-off row for super-120b to say what disabling reasoning costs in quality (it cost lightning 93.6% → 50.9%).*
- **No Settings field for NIM's reasoning controls** (medium, since 2026-09-01) — the super-120b model page documents `enable_thinking`, `low_effort` and `force_nonempty_content` under `chat_template_kwargs`; `Settings.extra` is spread as top-level OpenAI kwargs, so they are only reachable through the nested `extra={"extra_body": {...}}` form. — *Needs a call: a pass-through field has to define what happens when a user also sets `extra_body` directly.*
- **`nemotron-nano-3-30b-a3b` listed but not served** (low, since 2026-09-01) — still in the catalogue, still 404 "Not found for account" on the cloud endpoint. — *Needs a call: nothing to do until it is served; re-probe next run before treating it as a default candidate.*

The default stays. The aiewf-eval leaderboard is unchanged, so `nemotron-3-ultra-550b-a55b` still scores higher (98.3–100% vs 97.0%) while remaining the family's flagship size rather than a designated successor to super. Catalogue churn is `deepseek-ai/deepseek-v4.1-flash` and `z-ai/glm-5.3` added, `deepseek-v4-flash-0731`, `deepseek-v4-pro-0813`, `mistralai/mistral-nemotron` and `riva-translate-4b-instruct-v1.1` gone; none is referenced by the service or its examples. `reasoning_budget`, named in last run's report as a `chat_template_kwargs` key, is a client-side helper argument on the model page rather than a request parameter, so the Settings gap covers the three keys above instead.
