# NVIDIA LLM — 2026-09-14

Nothing to ship: `nemotron-3-super-120b-a12b` shipped as the default in #5579 and answers in 1191 ms TTFAT trivial / 2421 ms on a reasoning prompt, and NIM added no Nemotron chat model since the last run.

## What's new for Pipecat

### PRs
Nothing.

Last run's branch became https://github.com/pipecat-ai/pipecat/pull/5579 and merged on 2026-09-02, so the retired-default and retired-example-model gaps are closed. The same merge dropped the `model=` pin from the three NVIDIA examples (`ab53451c9`), which is why the `/no_think` gap below is now measured against super-120b rather than lightning.

### To consider
- **`/no_think` is inert in the NVIDIA examples** (medium, since 2026-09-01) — `examples/voice/voice-nvidia.py`, `examples/voice/voice-nvidia-segmented.py` and `examples/function-calling/function-calling-nvidia.py` still prefix their system instruction with `/no_think`; with the default model the probe reasoned in 3 of 3 runs (407 ms thinking of an 876 ms median TTFAT), while the switch NVIDIA documents for super-120b suppressed it entirely (473 ms median, no `LLMThought*` frames). The penalty shrank from the 11.9 s seen on lightning to roughly 400 ms. — *Needs a call: dropping the dead prefix and passing the documented switch are different fixes, and aiewf-eval has no thinking-off row for super-120b to say what disabling reasoning costs in quality (it cost lightning 93.6% → 50.9%).*
- **No Settings field for NIM's reasoning controls** (medium, since 2026-09-01) — the super-120b model page documents `enable_thinking`, `low_effort` and `reasoning_budget` under `chat_template_kwargs`; `Settings.extra` is spread as top-level OpenAI kwargs, so they are only reachable through the nested `extra={"extra_body": {...}}` form. — *Needs a call: a pass-through field has to define what happens when a user also sets `extra_body` directly.*
- **`nemotron-nano-3-30b-a3b` listed but not served** (low, since 2026-09-01) — still in the catalogue, still 404 "Not found for account" on the cloud endpoint. — *Needs a call: nothing to do until it is served; re-probe next run before treating it as a default candidate.*

The default stays. `nemotron-3-ultra-550b-a55b` scores higher on aiewf-eval (98.3–100% vs 97.0%) but is the family's flagship size rather than a designated successor to super, and NVIDIA's docs carry no lifecycle notice on super-120b (v1.0 GA). Catalogue churn this fortnight is `nemotron-parse-2.0` and `z-ai/glm-5.3-flash` added, `openai/gpt-oss-120b` and `minimaxai/minimax-m3` gone; none is referenced by the service or its examples.
