# NVIDIA LLM — 2026-11-09

Nothing to ship: the default is now `nemotron-3.5-super-vl-120b-a12b` (bumped in main on 2026-10-23), it is v1.0 GA with no lifecycle notice and answers in 967 ms TTFAT, and no catalogue model is positioned as its successor.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **`/no_think` is inert in the NVIDIA examples** (medium, since 2026-09-01) — `examples/voice/voice-nvidia.py`, `examples/voice/voice-nvidia-segmented.py` and `examples/function-calling/function-calling-nvidia.py` still prefix their system instruction with `/no_think`; probed with that prompt verbatim against the new default, the model reasoned anyway (479 ms thinking inside a 1034 ms TTFAT), while NVIDIA's documented switch suppressed reasoning entirely (328 ms TTFAT, no `LLMThought*` frames). `examples/update-settings/llm/llm-nvidia.py` and `examples/voice/voice-nvidia-sagemaker.py` carry no prefix, so the examples still disagree with each other. — *Needs a call: dropping the dead prefix and passing the documented switch are different fixes, and aiewf-eval has no row at all for super-vl-120b, thinking on or off, to say what disabling reasoning costs in quality (it cost lightning 83.9% → 69.6%).*
- **No Settings field for NIM's reasoning controls** (medium, since 2026-09-01) — the super-vl-120b model page documents reasoning as configurable through the chat template (`enable_thinking`); `Settings.extra` is spread as top-level OpenAI kwargs, so the key is only reachable through the nested `extra={"extra_body": {...}}` form. — *Needs a call: a pass-through field has to define what happens when a user also sets `extra_body` directly.*
- **`nemotron-nano-3-30b-a3b` listed but not served** (low, since 2026-09-01) — still in the catalogue, still 404 on the cloud endpoint. — *Needs a call: nothing to do until it is served; re-probe next run before treating it as a default candidate.*

The default stays. aiewf-eval has no row for `nemotron-3.5-super-vl-120b-a12b`, so there is no benchmarked candidate to move to: the leaderboard's Nemotron rows were re-measured since last run and now read ultra 91.8%, super-120b (thinking budget 512) 90.9%, lightning 83.9% thinking-on, nano-30b 71.9%, lightning 69.6% thinking-off — all of them older models than the default. `nemotron-3.5-bolt-e4b` is new and much faster (241 ms TTFAT, no reasoning) but its model page calls it an 8B/4B-effective model "intended primarily for customization and post-training" rather than production inference, so it is not a default candidate. Catalogue churn is `minimaxai/minimax-m3.1-flash`, `mistralai/mistral-large-4-1t-a52b`, `nvidia/nemotron-3.5-bolt-e4b`, `nvidia/nemotron-3.5-embed-1b`, `nvidia/nemotron-3.5-embed-8b`, `nvidia/nemotron-3.5-super-vl-120b-a12b` and `stepfun-ai/step-5-preview` added, `meta/llama-3.2-11b-vision-instruct`, `moonshotai/kimi-k3` and `z-ai/glm-5.3` gone; none of the removals is referenced by the service, its tests or its examples. The previous default `nvidia/nemotron-3-super-120b-a12b` is still listed and is no longer referenced by any code.
