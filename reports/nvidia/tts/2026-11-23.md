# NVIDIA TTS — 2026-11-23

No provider movement: Speech NIM is still 26.10.0 with the same three TTS models, the default synthesizes at TTFB 138 ms, and the two open gaps are unchanged.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Word timestamps** (medium, since 2026-09-01) — `enable_word_time_offsets` returns per-word start/end times in `SynthesizeSpeechResponse.meta.words` for Magpie models, with streaming delivering one consolidated timeline on the final response. `_build_base_request` never sets the flag and both the stitched and per-sentence response loops read only `item.audio`, so the service cannot emit word timestamps. — *Needs a call: wiring Riva's streaming response metadata into `TTSService`'s word-timestamp API is more than a request-field pass-through.*
- **Zero-shot prompt transcript** (low, since 2026-09-01) — `ZeroShotData.transcript` and `ZeroShotData.sample_rate_hz` are accepted next to the prompt audio, but the service only sets `audio_prompt`, `encoding` and `quality`. — *Needs a call: the transcript belongs with the constructor's `zero_shot_audio_prompt_file`, so exposing it means a new constructor parameter; hosted zero-shot models also need NVIDIA approval, so the change could not be probed.*

## Checked and current

- Provider: Speech NIM release notes are still at 26.10.0 (page refreshed 2026-11-06) with ASR-only containers (Nemotron ASR Streaming 1.4.0, Nemotron Transcribe 1.0.0) — no TTS container, feature, parameter or deprecation this cycle. No 26.11 notes exist yet.
- Lineup: the TTS support matrix (updated 2026-11-06) lists exactly Magpie Multilingual, Magpie Zeroshot and Chatterbox Multilingual, none marked end-of-life or new. Model, voice and language stay pass-through strings in our code, so new voices and languages need no change.
- Request schema: the customization docs list `flush`, `chunk_len_threshold`, `max_chunk_threshold`, `exaggeration_factor` (all reachable through the merged `custom_configuration` setting), SSML `<phoneme>`/`<say-as>` and the pronunciation dictionary (reachable), plus `enable_word_time_offsets` — the gap above. Nothing new appeared.
- Default: no successor is positioned for Magpie Multilingual; the model card names none and no deprecation notice exists.
- SDKs: `nvidia-riva-client` 2.28.0 (2026-11-06) is still the latest and sits inside the `>=2.25.1,<3` pin; `protobuf` 7.36.2 stays outside the deliberate `>=6.31.1,<7` pin because riva-client requires protobuf 6.x. `aws_sdk_sagemaker_runtime_http2` 0.13.1 (above the shared `<0.10` cap) and `aiobotocore` 3.10.0 belong to the SageMaker/AWS units.
- Pipecat side since 2026-11-09: `nvidia/tts.py` changed only by a docstring addition pointing pronunciation users at `replace_text` text transforms (4a26fd643); the rest of the NVIDIA commits are STT diarization work. Examples construct the service with its defaults, so no model string can go stale.
- SageMaker classes still ship `model="magpie"` as an endpoint label over a deployed NIM wrapper — no provider schema to fall behind.
- PR #5580 (`custom_configuration`) merged on 2026-10-28; the code carries it, so it drops off this report.
