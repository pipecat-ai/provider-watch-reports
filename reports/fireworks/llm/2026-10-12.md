# Fireworks LLM — 2026-10-12

Nothing to do: `nemotron-3-ultra-nvfp4` is served, probes clean, and remains the best Fireworks-served row on aiewf-eval.

## What's new for Pipecat

### PRs
Nothing.

No default bump. `nemotron-3-ultra (128)` still leads `leaderboard-medium-context.md` at 100.0% pass / 541 ms TTFAT P50, and nothing newer in the catalogue has a row: `kimi-k3`, `deepseek-v4p1-flash`, `glm-5p3-flash`, `minimax-m3`, `qwen3p8-max` are all unbenchmarked, and `ember-1` (new on 2026-09-23) is a time-limited research preview, so not a default candidate either way.

Fireworks' 2026-09-26 serverless retirements (DeepSeek V4 Pro 0813 / V4 Flash 0731 / V4 Flash Vision Exp, Muse Glimmer 30B, Kimi K2.6, Kimi K2.7 Code, GLM 5.2 Fast/US) have taken effect in the catalogue and touch nothing Pipecat hard-codes — both Fireworks examples now pin the service default, following merged PRs #5524 and #5747. The October changes are pricing, raised small-model rate limits, and paused managed RFT; none reach the service.

### To consider
- **Dropped OpenAI parameters** (medium, since 2026-09-01) — `build_chat_completion_params` omits `seed`, `max_completion_tokens` and `service_tier` on the grounds that Fireworks does not support them; the chat-completions spec documents all three and a probe passing them through `extra` succeeds. A user who sets `Settings(seed=...)` or `Settings(max_completion_tokens=...)` gets silence. The docstring's `stream_options` rationale is also stale, but harmless: Fireworks emits usage in the stream by default, so token-usage metrics already work. — *Needs a call: removing the override makes two ignored Settings fields start taking effect for every Fireworks user, not just a value change.*

The previous report's PR item (update-settings example pinning `gpt-oss-20b`) is closed by merged PR #5747 and dropped.
