# Fireworks LLM — 2026-11-23

Sixteen days past the announced retirement, Fireworks' catalogue pages treat the default as off Serverless while the API keeps serving it; nothing to ship until a maintainer picks the serverless successor.

## What's new for Pipecat

### PRs
Nothing. No branch: Fireworks designates no serverless successor for the retiring default, so picking one is a maintainer's call, not a value swap.

### To consider
- **Retiring default** (high, since 2026-11-09) — Fireworks' 2026-10-19 notice decommissioned the Serverless endpoints for Nemotron 3 Ultra (`nemotron-3-ultra-nvfp4`) and three peers on 2026-11-07, pointing Nemotron users at "a dedicated deployment of Nemotron Super VL". The provider's pages now read as though that executed: the model page says "Serverless — Not Supported", the library's serverless filter omits it, and the recommended-models guide lists `deepseek-v4p1-flash-1017`, `minimax-m3`, `step-3p7-flash-nvfp4` and `kimi-k3p1-pro` for low-latency user-facing apps with no Nemotron among them. The API disagrees: 5/5 probes answered at median TTFAT 363 ms, and `/v1/models` still returns the ID, as it does for the retired peers (`nemotron-lightning-3p5-30b-a3b` answered too). The default is still the fastest model measured, on the trivial prompt (363 ms vs 811 ms for `deepseek-v4p1-flash-1017`) and on a reasoning-triggering one (1862 ms vs 2993 ms; `glm-5p3` 6886 ms). — *Needs a call: which serverless model becomes the default — Fireworks designates none, `deepseek-v4p1-flash-1017` and `ember-1` have no aiewf-eval row, and glm-5.3's 97.7% row ran at `low` reasoning rather than the Fireworks defaults this service sends.*
- **Dropped OpenAI parameters** (medium, since 2026-09-01) — `build_chat_completion_params` omits `seed`, `max_completion_tokens` and `service_tier` on the grounds that Fireworks does not support them; the chat-completions reference documents all three and a probe passing them through `extra` succeeds. A user who sets `Settings(seed=...)` or `Settings(max_completion_tokens=...)` gets silence. — *Needs a call: removing the override makes two ignored Settings fields start taking effect for every Fireworks user, not just a value change.*
- **Examples and eval manifest pin retiring models** (low, since 2026-11-09) — two examples and both Fireworks entries in `evals/turn-completion/manifest.yaml` name models on the 2026-11-07 list. — *Needs a call: the replacements follow from the default decision, so this waits on it.*

Benchmark position is unchanged from the last run: `leaderboard-medium-context.md` still has `nemotron-3-ultra (thinking on)` at 91.8% / 926 ms on Baseten, `glm-5.3 (low reasoning)` 97.7% / 2376 ms on Z.AI and `muse-spark-open (low, NVFP4)` 96.7% / 626 ms on Baseten, with no Fireworks-served rows and no row for `deepseek-v4p1-flash-1017`, `ember-1`, `kimi-k3p1-pro` or `minimax-m3p1-flash`. `muse-spark-open` reasons heavily even when asked for `low` effort (TTFAT 3223 ms, 1549 ms thinking), so its leaderboard standing does not transfer to this service's request shape. `rune` answers through the Decisions API, not Chat Completions, so it is not a candidate.

The catalogue is byte-identical to the 2026-11-09 run: no new models, no new routers.
