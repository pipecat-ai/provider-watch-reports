# Fireworks LLM — 2026-09-14

The default `nemotron-3-ultra-nvfp4` is served and still tops the benchmark; the one loose end is a second example that PR #5524 missed, which pins the retired `gpt-oss-20b`.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5747 — Use nemotron-3-ultra-nvfp4 in the Fireworks update-settings example

`examples/update-settings/llm/llm-fireworks.py` still asks for `accounts/fireworks/models/gpt-oss-20b`, which Fireworks removed from serverless on 2026-08-27; a probe confirms it 404s. The branch moves it to the service's default, which probes clean.

No default bump this run. `nemotron-3-ultra-nvfp4` remains the best Fireworks-served model on aiewf-eval's `aiwf_medium_context` (nemotron-3-ultra 128k: 100.0% pass, 541 ms TTFAT P50); the models new to the catalogue since the last run (`deepseek-v4p1-flash`, `deepseek-v4-flash-vision-exp`, the `glm-5p3-fast` router) have no leaderboard row, and `glm-5.3 (low reasoning)` is benchmarked below it at 98.7% / 2376 ms. Fireworks' 2026-09-25 serverless retirements (DeepSeek V4 Flash 0731 / V4 Pro 0813 / V4 Flash Vision Exp, GLM 5.2, Muse Glimmer 30B, Kimi K2.6, Kimi K2.7 Code) touch nothing Pipecat hard-codes.

### To consider
- **Dropped OpenAI parameters** (medium, since 2026-09-01) — `build_chat_completion_params` omits `stream_options`, `seed` and `max_completion_tokens` on the grounds that Fireworks does not support them, but Fireworks' chat-completions spec documents all three and passing them through `extra` succeeds. The visible cost is token-usage metrics, which the base service gets from `stream_options={"include_usage": true}`. — *Needs a call: removing the override changes behavior for every Fireworks user, not just a value.*

Two items from the previous report are resolved and dropped: the `openai` pin is now `>=1.74.0,<4`, which admits PyPI's current 3.13.0; and the docs.pipecat.ai Fireworks page now shows `nemotron-3-ultra-nvfp4` in its samples instead of `firefunction-v2`. The two `pr` items are closed by merged PR #5524.
