# Fireworks LLM — 2026-09-01

Pipecat's shipped Fireworks default 404s: Fireworks no longer serves `firefunction-v2` (or the example's `gpt-oss-20b`) on serverless. The branch moves both to `nemotron-3-ultra-nvfp4`.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5524 — Replace the retired firefunction-v2 default and gpt-oss-20b example model with nemotron-3-ultra-nvfp4

`nemotron-3-ultra-nvfp4` is the pick because it is the fastest Fireworks-served model that aiewf-eval has benchmarked at the top of `aiwf_medium_context` (nemotron-3-ultra 128k: 100.0% pass, 541 ms TTFAT P50 — the leaderboard row ran on Baseten, so the score is for the weights, not for Fireworks' deployment). The retired default has no benchmark row at all. Of the other Fireworks-served candidates with rows, `glm-5p2` (99.7%) thinks by default and is ~7x slower to first answer token here, and `deepseek-v4-flash-0731` (96.7%) is slower on both prompts. Tool calling works: a probe with a weather tool produced `FunctionCallsStartedFrame`.

### To consider
- **Dropped OpenAI parameters** (medium, since 2026-09-01) — `build_chat_completion_params` omits `stream_options`, `seed` and `max_completion_tokens` on the grounds that Fireworks does not support them, but Fireworks' chat-completions spec documents all three and a probe passing them through `extra` succeeds. The visible cost is token-usage metrics, which the base service gets from `stream_options={"include_usage": true}`. — *Needs a call: removing the override changes behavior for every Fireworks user, not just a value.*
- **openai SDK pin** (medium, since 2026-09-01) — `pyproject.toml` pins `openai>=1.74.0,<3` while PyPI is at 3.6.0. — *Needs a call: the pin is shared by every OpenAI-compatible service, so moving it is a repo-wide decision.*
- **Docs page samples** (low, since 2026-09-01) — the Fireworks page on docs.pipecat.ai still shows `firefunction-v2` in its code samples, a model Fireworks no longer serves. — *Needs a call: the page lives in the docs repo, so someone with access there has to make the edit.*
