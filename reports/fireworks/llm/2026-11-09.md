# Fireworks LLM — 2026-11-09

The default is living on borrowed time: Fireworks announced `nemotron-3-ultra-nvfp4`'s Serverless decommissioning for 2026-11-07 and it still answers two days later, but the only replacement Fireworks names is a dedicated deployment.

## What's new for Pipecat

### PRs
Nothing. No branch: Fireworks designates no serverless successor for the retiring default, so picking one is a maintainer's call, not a value swap.

### To consider
- **Retiring default** (high, since 2026-11-09) — Fireworks' 2026-10-19 notice decommissions the Serverless endpoints for Nemotron 3 Ultra (`nemotron-3-ultra-nvfp4`), Nemotron 3.5 Lightning 30B A3B, Inkling and GPT OSS 120B on 2026-11-07, pointing Nemotron users at "a dedicated deployment of Nemotron Super VL". All four still serve today — each answered a probe — so the retirement has not executed, and the default remains the fastest model measured (median TTFAT 257 ms over 5 runs). Serverless candidates all work through the class: `deepseek-v4p1-flash-1017` (653 ms), `glm-5p3` (706 ms), `muse-spark-open` (5323 ms, reasoning on by default, so unsuitable for voice as-is). — *Needs a call: which serverless model becomes the default — Fireworks designates none, `deepseek-v4p1-flash-1017` has no aiewf-eval row, and glm-5.3's 97.7% row ran at `low` reasoning rather than the Fireworks defaults this service sends.*
- **Dropped OpenAI parameters** (medium, since 2026-09-01) — `build_chat_completion_params` omits `seed`, `max_completion_tokens` and `service_tier` on the grounds that Fireworks does not support them; the chat-completions spec documents all three and a probe passing them through `extra` succeeds. A user who sets `Settings(seed=...)` or `Settings(max_completion_tokens=...)` gets silence. — *Needs a call: removing the override makes two ignored Settings fields start taking effect for every Fireworks user, not just a value change.*
- **Eval manifest pins retiring models** (low, since 2026-11-09) — `evals/turn-completion/manifest.yaml` runs `fireworks/nemotron-3-ultra` and `fireworks/nemotron-3.5-lightning-30b`, both on the 2026-11-07 list. — *Needs a call: the replacements follow from the default decision, so this waits on it.*

Note on the benchmark: `leaderboard-medium-context.md` has been re-run since the last report. The `nemotron-3-ultra (128)` row quoted there (100.0% / 541 ms) is gone; the current Nemotron 3 Ultra row is `nemotron-3-ultra (thinking on)` at 91.8% / 926 ms on Baseten, and the board now carries no Fireworks-served rows at all. Of the catalogue's serverless models, `muse-spark-open (low, NVFP4)` 96.7% / 626 ms and `glm-5.3 (low reasoning)` 97.7% / 2376 ms are the relevant rows; `deepseek-v4p1-flash-1017`, `kimi-k3`, `kimi-k3p1-pro`, `minimax-m3p1-flash`, `qwen3p8-max`, `ember-1` and `rune` have none. `rune` is a decision model answering through the Decisions API, not Chat Completions, so it is not a candidate for this service.

The previous report's only other content — the token-usage half of the `build_chat_completion_params` item, settled as already working — is unchanged and stays out of the gap list.
