# Resemble AI TTS — 2026-09-01

No model work to do — Resemble selects the model from the `voice_uuid` and documents that
requests must not carry a `model` field — but one documented request parameter is missing and
is on a branch.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5563 — Expose Resemble AI custom pronunciations

### To consider
- **`project_uuid`** (medium, since 2026-09-01) — Resemble's WebSocket reference marks
  `project_uuid` required; `_build_msg` never sends it. Synthesis still succeeds (probe below),
  so clips go to the account's default project and users cannot pick one — but the request is
  out of spec if Resemble starts enforcing it. — *Needs a call: whether to expose the project at
  all, and a project UUID to probe with, since none is available in the probe environment.*
- **First-audio latency** (medium, since 2026-09-01) — `_jitter_buffer_bytes = 44100` holds back
  audio until roughly a second of it has accumulated, so measured TTFB is 561-687 ms while
  Resemble advertises ~200 ms time-to-first-sound for this WebSocket. — *Needs a call: whether
  the buffer can shrink without gaps in playback; the 300-450 ms burst gaps the code comments
  cite have not been re-measured.*
- **Non-PCM16 audio formats** (low, since 2026-09-01) — the constructor documents
  `precision` values PCM_32/PCM_24/MULAW and `output_format` `mp3`, but the receive path aligns
  chunks to 2 bytes and hands them downstream as raw PCM at `self.sample_rate`. — *Needs a call:
  confirm what a MULAW or mp3 session produces, then either carry the format through to the
  frames or narrow the documented values.*

## Sources
- https://docs.resemble.ai/getting-started/model-versions.md — Resemble Ultra (`resemble-ultra`)
  is the current and only supported TTS model, chosen by `voice_uuid`; the page says explicitly
  not to pass a `model` field. Every earlier model (`tts-v4`, `tts-v4-turbo`, `tts-v3`, `tts-v2`,
  `tts-v1`, `tts-legacy`) is end of life and those voices must be upgraded in the Resemble app.
- https://docs.resemble.ai/voice-generation/text-to-speech/streaming-websocket.md — full
  WebSocket request schema: `voice_uuid`, `project_uuid`, `data`, `request_id`,
  `binary_response`, `output_format`, `sample_rate`, `precision`, `no_audio_header`,
  `apply_custom_pronunciations`; response types `audio` / `audio_end` / `error`; Business plan
  only; 20 concurrent sessions per key.
- https://docs.resemble.ai/guides/creating-clips/websocket-streaming/getting-started.md — the
  WebSocket is positioned for conversational agents; Bearer token auth.
- https://docs.resemble.ai/llms.txt — documentation index; there is no changelog or deprecations
  page, so Model Versions is the retirement source.
- https://www.resemble.ai/resources/chatterbox-multilingual-v3-tts-with-embedded-watermarking-for-25-languages
  — Chatterbox v3 is the open-source/self-hosted line, separate from the hosted API's Ultra model.
- probe.py sdk-versions — the `resembleai` extra has no dependencies, so there is no SDK pin to
  track; probe.py list-models exits 3 (no catalogue endpoint).
