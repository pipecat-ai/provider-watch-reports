# Resemble AI TTS — 2026-09-14

Service is current — Resemble Ultra is still the only hosted model and it is picked from the
voice, so there is no default to bump; the open pronunciations PR is the only pending code, and
one new request parameter is worth a maintainer's call.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5563 — Expose Resemble AI custom pronunciations (open since last run)

### To consider
- **`voice_settings_preset_uuid`** (medium, since 2026-09-14) — Resemble's Voice Settings
  Presets save a pace/pitch/temperature/emotion/style-description combination and are applied
  per request. The WebSocket reference table does not list the field, but the endpoint reads it:
  a well-formed UUID the account does not own comes back as `Unauthorized ... invalid voice
  settings preset` rather than being ignored. Without it, prosody and emotion can only be
  reached by writing SSML into the text. — *Needs a call: a preset UUID in the probe account to
  confirm a valid one synthesizes, and a stance on presets silently overriding equivalent SSML
  in `data`.*
- **`project_uuid`** (medium, since 2026-09-01) — Resemble's WebSocket reference marks
  `project_uuid` required; `_build_msg` never sends it. Synthesis still succeeds (probe below),
  so clips go to the account's default project and users cannot pick one. — *Needs a call:
  whether to expose the project at all, and a project UUID to probe with, since none is
  available in the probe environment.*
- **First-audio latency** (medium, since 2026-09-01) — `_jitter_buffer_bytes = 44100` holds back
  audio until roughly a second of it has accumulated, so measured TTFB is 551 ms today (561-687 ms
  last run) while Resemble advertises ~200 ms time-to-first-sound for this WebSocket. — *Needs a
  call: whether the buffer can shrink without gaps in playback; the 300-450 ms burst gaps the
  code comments cite have not been re-measured.*
- **Non-PCM16 audio formats** (low, since 2026-09-01) — the constructor documents `precision`
  values PCM_32/PCM_24/MULAW and `output_format` `mp3`, but the receive path aligns chunks to
  2 bytes and hands them downstream as raw PCM at `self.sample_rate`. — *Needs a call: confirm
  what a MULAW or mp3 session produces, then either carry the format through to the frames or
  narrow the documented values.*

`probe.py run --service ResembleAITTSService` fails unless the voice is passed explicitly:
`voice` is a settings param here, and the harness fills settings only from `--setting` and
registry `param_defaults`, never from `RESEMBLE_VOICE_UUID`. With `voice_uuid` null Resemble
drops the socket without an error message and the turn ends with no audio. The service itself is
fine — pass `--setting voice=$RESEMBLE_VOICE_UUID`.

The preset check was one ad-hoc WebSocket call sending the documented payload plus a syntactically
valid UUID belonging to no account; it exists only to tell "the endpoint ignores the field" apart
from "the endpoint reads it", and no preset was created.

  (`resemble-ultra`) is the current and only supported TTS model, chosen by `voice_uuid`, and the
  page says not to pass a `model` field. `tts-v4`/`tts-v4-turbo` (Chatterbox), `tts-v3`, `tts-v2`,
  `tts-v1` and `tts-legacy` remain end of life.
- https://docs.resemble.ai/voice-generation/text-to-speech/streaming-websocket.md — request schema
  unchanged since last run: `voice_uuid`, `project_uuid` (both required), `data`, `request_id`,
  `binary_response`, `output_format`, `sample_rate`, `precision`, `no_audio_header`,
  `apply_custom_pronunciations`. Business plan, 20 concurrent sessions per key, 3,000 characters.
- https://docs.resemble.ai/platform-management/voice-settings-presets.md — `voice_settings_preset_uuid`
  carries saved pace/pitch/temperature/emotion/description settings into a synthesis request and
  overrides equivalent SSML in `data`.
- https://docs.resemble.ai/voice-generation/text-to-speech/streaming-http.md — the HTTP streaming
  sibling adds `use_hd` and a 48000 Hz sample rate that the WebSocket does not offer; nothing this
  class can use.
- https://docs.resemble.ai/llms.txt — documentation index; still no changelog, release-notes or
  deprecations page, so Model Versions remains the retirement source.
