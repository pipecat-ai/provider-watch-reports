# xAI STT — 2026-11-23

Nothing changed on either side since 2026-11-09: `XAISTTService` still fails the standard probe end to end because it throws away audio that arrives before `transcript.created`, and that blocks every other item from reaching a PR. xAI's one new affordance is `redact`.

## What's new for Pipecat

### PRs
Nothing. No item can clear the probe bar while the pre-ready audio drop stands, so no branch this run. No open provider-watch PR touches this unit (#5561 merged 2026-11-07 and was accounted for last run).

### To consider
- **Pre-ready audio is discarded** (high, since 2026-11-09) — `run_stt` sends audio only while `_session_ready` is set and drops it silently otherwise; the window is the ~250ms between the WebSocket handshake and `transcript.created`, and it reopens on every automatic reconnect. `probe.py run --service XAISTTService` fails again with "no TranscriptionFrame within 30s" after discarding all 354 audio frames. A raw socket that bursts the identical clip (no pacing at all) *after* `transcript.created` returns the correct `speech_final` transcript, so the failure is the drop, not the send rate. Real-time transports are mostly unaffected at startup, but any faster-than-real-time source loses its audio and a mid-call reconnect loses a quarter second of live speech. — *Needs a call: buffer the pre-ready audio and flush it on `transcript.created`, or hold the service's start until the session is ready. Either is a startup behavior change, not a value swap.*
- **`format` (inverse text normalization) is not exposed** (medium, since 2026-11-09) — documented boolean query parameter of the streaming endpoint; `XAISTTSettings` has no field and `_build_ws_url` never sends it. A live session with `format=true` connects and transcribes normally. The change is one optional field plus one `optional_fields` entry, with the stale "when set, the server applies Inverse Text Normalization" line in the `language_to_xai_stt_language` docstring corrected in the same edit. — *Needs a call: `probe.py run` cannot pass against this class at all while pre-ready audio is dropped, so a new Settings field cannot be verified the way a PR requires; this follows the drop fix.*
- **`redact` is not exposed** (medium, since 2026-11-23) — new in xAI's docs this run: a repeatable query parameter taking `pii`, `pci`, `phi` or an individual type, priced at $0.05/hour on top of transcription and tuned for en/es/fr/de/pt. A live session with `redact=pii` returns `[NAME_GIVEN_1]`-style placeholders in place of the entity text, and — as documented — emits no interim results at all. Shape is the same pass-through as `keyterm`. — *Needs a call: the same probe blocker as `format`, and whether `interim_results=True` quietly doing nothing under `redact` should be warned about or left to the docs.*
- **`finalize` is never sent** (medium, since 2026-09-01) — xAI accepts `{"type": "finalize"}` to finalize the current utterance immediately, confirmed live again this run; `XAISTTService` only sends `audio.done` at disconnect, so every end-of-turn final waits out the `endpointing` silence timer. — *Needs a call: what triggers it. Wiring it to the user turn-stop path is a behavior change that interacts with the turn strategies and with server-side `smart_turn`.*
- **Language map lags the docs** (low, since 2026-09-01) — `language_to_xai_stt_language` verifies 16 codes against the 38 base codes and 7 regional variants xAI publishes; the rest fall through to the base-code path and log a "not verified" warning each session. — *Needs a call: whether the regional codes map through as-is, since `Language.ES_ES` sends `es` today and would start sending `es-ES`; plus the same probe blocker as `format`.*

`grok-voice-transcribe-2.0` is still xAI's only STT model and its server-side default, which is what the service sends — no bump to make, and no STT deprecations in the October or November release notes. `grok-voice-transcribe-1.0` (end of life 2026-10-02) survives only in `tests/test_xai_stt.py` as the "model override" example and in historical CHANGELOG entries; the shipped code and the examples name no retired string.
