# xAI STT — 2026-09-01

The endpoint is stable and takes no model, but five documented query parameters — keyword biasing, filler words, the VAD gate and server-side smart turn — had no `Settings` field; branch ready.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5561 — Expose xAI STT's remaining streaming parameters and correct its documented defaults

### To consider
- **`finalize` is never sent** (medium, since 2026-09-01) — xAI accepts `{"type": "finalize"}` on the socket to finalize the current utterance immediately; `XAISTTService` only sends `audio.done` at disconnect, so every end-of-turn final waits out the `endpointing` silence timer. — *Needs a call: what triggers it. Wiring it to the user turn-stop path is a behavior change that interacts with the turn strategies and with server-side `smart_turn`.*
- **Language map lags the docs** (low, since 2026-09-01) — `language_to_xai_stt_language` verifies 16 codes against the 25 xAI documents; cs, da, fa, fil, mk, ms, nl, pl, ro, sv and th fall through to the base-code path and log a "not verified" warning each session. — *Needs a call: the map also carries BN and ZH, which xAI's language list no longer names, and a probe with `language=zh` connects and transcribes, so it is unclear whether they should be dropped or the list is simply incomplete.*
