# xAI LLM — 2026-09-28

xAI shipped `grok-4.7` as its new flagship, but it reasons unconditionally, so
`grok-4.20-non-reasoning` stays the default and PR 5559 remains the one open item.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5559 — Expose Grok's reasoning effort control (open since 2026-09-01)

### To consider
- **grok-4.7 as the default** (low, since 2026-09-01) — grok-4.7 went GA in September as xAI's frontier model and supersedes grok-4.6 in the flagship slot, but it carries the same disqualifier: reasoning cannot be disabled, `reasoning_effort` defaults to `high`, and it measures 1510 ms median TTFAT against 1163 ms for the current default on a trivial prompt and 21496 ms against 605 ms on a planning prompt, where two of five runs exceeded the probe timeout. Pinning `reasoning_effort=low` only brings the planning prompt to 7766 ms. xAI documents no deprecation for the grok-4.20 line. — *Needs a call: aiewf-eval's medium-context leaderboard still carries no Grok row at all (43 rows), so neither model has a benchmarked pass rate; the leaderboard gets re-read next run.*
