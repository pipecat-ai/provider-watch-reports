# xAI LLM — 2026-11-23

Nothing to merge: the `guidelines` branch landed, no new text model, no retirement
touching this service. The one new finding is that xAI's live search no longer
answers on chat completions.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Live search is out of reach** (medium, since 2026-11-23) — the chat-completions reference still documents `search_parameters` (mode / sources / dates / citations) and an OpenAI-compatible `web_search_options`, but both come back 410 from the live API, and passing xAI's server-side `{"type": "web_search"}` tool on chat completions comes back 422. Grounded search now lives on the Responses API together with the rest of the agent tools, and xAI labels chat completions "a legacy endpoint" where "new features will come to [Responses] first" — no sunset date. So there is no pass-through field to add here. — *Needs a call: reaching live search means giving Grok a Responses-API path (a new service or an endpoint switch), not a `Settings` field; is that worth building for this provider?*
- **grok-4.7 as the default** (low, since 2026-09-01) — grok-4.7 is still the model xAI recommends for chat and the grok-4.20 line is still listed and priced with no deprecation marker, so the item stays open. The disqualifiers are unchanged: the reasoning page states outright that reasoning cannot be disabled on grok-4.5/4.6/4.7 (effort low/medium/high (default)/xhigh, no `none`), and this run's health samples show the cost — 2052 ms TTFAT with 1056 ms of thinking against 620 ms for the default on a trivial prompt. Medians were not re-measured because neither model changed and the benchmark question below settles nothing either way. — *Needs a call: aiewf-eval's medium-context leaderboard still has no Grok row (50 rows; the grok-4.6 row was archived on 2026-10-17), so neither model has a benchmarked pass rate; the leaderboard gets re-read next run.*

### Closed since last run
- PR #6663 merged on 2026-11-09, so `guidelines` is now a `GrokLLMSettings` field and that gap is gone.
- `grok-build-0.1` reached end of life on 2026-11-19 and left the catalogue; Pipecat never referenced it.
