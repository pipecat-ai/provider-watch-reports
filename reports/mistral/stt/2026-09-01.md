# Mistral STT — 2026-09-01

`voxtral-mini-transcribe-realtime-2602` is Mistral's only active realtime transcription model and it works; nothing to change.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Inert `language` setting** (low, since 2026-09-01) — `MistralSTTSettings` documents `language` as a "Language hint for transcription", but Mistral's realtime session payload carries only `audio_format` and `target_streaming_delay_ms`, so the value is never sent; changing it still forces a disconnect/reconnect in `_update_settings`. — *Needs a call: drop the docstring claim (and the reconnect) or leave the inherited field until Mistral adds a language parameter.*
- **`target_streaming_delay_ms` not in Settings** (low, since 2026-09-01) — the provider's only accuracy/latency knob is a constructor argument, though the SDK supports changing it mid-session with `update_session`. — *Needs a call: adding it to Settings duplicates the constructor argument, so it needs a stance on deprecating that argument.*
