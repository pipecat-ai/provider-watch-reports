# Mistral LLM — 2026-11-23

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Reasoning mode on Mistral Small 4** (medium, since 2026-09-01) — Mistral Small 4 is a hybrid model whose reasoning is switched on with `reasoning_effort`. The field is not in `MistralLLMSettings`, and reaching it through `Settings.extra` breaks: Mistral then streams `delta.content` as a list of content-part dicts, which `BaseOpenAILLMService` hands to `LLMTextFrame(text=...)` unchanged, so the frame's `text` is a list. Reproduced again this run. The live API also narrows the enum for this model to `none` and `high` — `low` comes back as HTTP 400 — while the API reference still prints the full `none|minimal|low|medium|high|xhigh` range, so a typed field would have to be per-model-tolerant. — *Needs a call: exposing the field is trivial, but the content-part shape has to be flattened in the shared OpenAI streaming path, which affects every OpenAI-compatible service.*
- **`service_tier` is silently dropped** (medium, since 2026-09-01) — `MistralLLMService` inherits `service_tier` from `OpenAILLMService.__init__`, but its `build_chat_completion_params` override never puts it in the request, so a user who sets it gets no error and no effect. Mistral's API reference documents the parameter. — *Needs a call: Mistral accepts only `auto` and `standard_only`, not the OpenAI tiers the shared argument documents, so it needs deciding whether to wire the inherited argument through or add a Mistral-typed setting.*
- **Provider-specific request parameters** (low, since 2026-09-01) — `prompt_cache_key`, `safe_prompt`, `parallel_tool_calls`, `response_format`, `stop`, `guardrails` and `prompt_mode` have no typed home; the Mistral-only ones travel only as `extra={"extra_body": {...}}`. `prompt_cache_key` is the one with a real payoff, since Mistral bills cached prompt tokens at 10%. — *Needs a call: whether `extra["extra_body"]` is the intended home for these on OpenAI-compatible services.*

Closed since last run: `Settings.seed` raising on every completion — https://github.com/pipecat-ai/pipecat/pull/6656 merged 2026-11-09, and `seed=42` now probes green on main.
