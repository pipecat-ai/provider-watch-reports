# Mistral TTS — 2026-09-01

Current: `voxtral-mini-tts-2603` is the only TTS model Mistral's API serves, it works, and nothing is retiring. No branch.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Reference-audio voice cloning** (medium, since 2026-09-01) — the speech request accepts `ref_audio`, a base64 clip that clones a voice zero-shot without first creating a saved voice; `MistralTTSSettings` has no field for it, so Pipecat users must pre-register a voice through `audio.voices.create`. A field plus a pass-through in `run_tts` is the shape. — *Needs a call: `run_tts` requires a voice (`assert_given(self._settings.voice)`), so exposing `ref_audio` means making voice optional and deciding precedence when both are set.*
- **`language` is a no-op** (low, since 2026-09-01) — Mistral's speech endpoint has no language parameter, so the field inherited from `TTSSettings` is stored and never sent; a probe with `language=fr` succeeded and changed nothing. The `MistralTTSSettings` docstring still lists it as "Language for speech synthesis". — *Needs a call: whether to document the field as unsupported here or drop it from the docstring.*
