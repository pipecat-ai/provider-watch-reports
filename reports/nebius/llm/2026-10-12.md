# Nebius LLM — 2026-10-12

`NebiusLLMService` is current: the default model is still served, probes clean, the Token Factory chat-completions schema is unchanged and the `openai` pin still covers PyPI's latest. No branch.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default model has no voice benchmark** (medium, since 2026-09-01) — `Qwen/Qwen3-30B-A3B-Instruct-2507` is still absent from aiewf-eval's `aiwf_medium_context` leaderboard. Two things changed in the candidate picture since the last run. The leaderboard's README now marks the four Nemotron rows as legacy Baseten deployments whose latencies "cannot be converted reliably" to the current TTFAT measure, so last run's `nvidia/Nemotron-3-Ultra-550b-a55b` headline (100% / 541 ms) keeps its pass rate but loses its latency claim. And Nebius now serves `Qwen/Qwen3.8-27B`, which does have a current production row (98.2% pass / 649 ms, "thinking off, FP8"). Probed through our class, Qwen3.8-27B reasons by default on Nebius (thinking 540 ms on a reasoning prompt); with reasoning disabled via the inherited `extra` dict it still answers slower than the current default (917 ms vs 671 ms on the same prompt). So the leaderboard gives no model that is both benchmarked and faster here. — *Needs a call: Nebius designates no successor to the default, so choosing a new one is a Pipecat quality/cost decision with no latency case behind it.*
