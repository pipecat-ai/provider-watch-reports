# Nebius LLM — 2026-09-01

`NebiusLLMService` is current: its default model survived Nebius's August 31 retirement wave, probes clean, and everything the Token Factory chat-completions schema accepts is already reachable. No branch.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default model has no voice benchmark** (medium, since 2026-09-01) — `Qwen/Qwen3-30B-A3B-Instruct-2507` is absent from aiewf-eval's `aiwf_medium_context` leaderboard, so there is no evidence for how it holds up in multi-turn voice. Nebius serves two models that are on the leaderboard: `zai-org/GLM-5.2` (99.7% pass, 936 ms TTFAT P50) and `deepseek-ai/DeepSeek-V4-Flash-0731` (96.7% pass, 677 ms). A probe of the DeepSeek candidate through our class succeeded but was slower than the default on a trivial prompt and turned reasoning on by itself. — *Needs a call: Nebius designates no successor to the default, so choosing a new one is a Pipecat quality/cost decision rather than a provider migration.*
- **openai SDK pin behind the current major** (low, since 2026-09-01) — `pyproject.toml` pins `openai>=1.74.0,<3`; PyPI's latest is 3.6.0 (2026-08-28). Nebius's endpoint is plain OpenAI-compatible chat completions and needs nothing from 3.x. — *Needs a call: the pin lives in the base `openai` dependency shared by every OpenAI-compatible service, so raising it is an openai/llm decision.*
