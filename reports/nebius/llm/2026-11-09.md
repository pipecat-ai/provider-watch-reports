# Nebius LLM — 2026-11-09

`NebiusLLMService` itself is current — the default survives Nebius's November retirement wave and is in fact the wave's recommended replacement for `Qwen/Qwen3-235B-A22B-Instruct-2507` — but the wave retires a model the turn-completion suite runs through this class; branch ready.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/6640 — Move the Nebius Nemotron turn-completion entry to Nemotron 3.5 Lightning

### To consider
- **Default model has no voice benchmark** (medium, since 2026-09-01) — `Qwen/Qwen3-30B-A3B-Instruct-2507` is still absent from aiewf-eval's `aiwf_medium_context` leaderboard. The candidate picture moved again: `Qwen/Qwen3.8-27B`, last run's best benchmarked Nebius option, fell from 98.2% to 96.0% on the current leaderboard, and Nebius now serves `meta-models/muse-spark-open`, which rows at 96.7% / 626 ms — the highest pass rate of any Nebius-hosted model with a row. Probed through our class, muse-spark-open reasons by default on Nebius (thinking 752 ms, TTFAT 1291 ms); pinned to the `low` reasoning its leaderboard row used, it still answers at 625 ms against the default's 445 ms on the same prompt. Its row is a Baseten NVFP4 deployment, so the 626 ms is not a claim about Nebius's hosting of it either way. The leaderboard still offers no model that is both benchmarked and at least as fast here. — *Needs a call: Nebius designates no successor to the default, so choosing a new one is a Pipecat quality/cost decision with no latency case behind it.*
