# Speechify TTS — 2026-09-01

Current: no provider changes since 2026-08-31. `simba-3.2` is still the
recommended model, the whole `/v1/audio/stream/with-timestamps` request schema
is reachable from `Settings`, and the single open item is unchanged.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **No pinned API version** (medium, since 2026-08-31) — the class posts to `/v1/audio/stream/with-timestamps` without a `Speechify-Version` header, which the versioning guide asks raw HTTP integrations to send; the server then uses the workspace's stored default, or the oldest supported version if the workspace has none, so two users on the same Pipecat version can get different shapes. The OpenAPI spec lists `Speechify-Version` as an optional header parameter on this endpoint. The one retirement on the calendar (Simba 1.6 at version `2026-09-21`, switch-off 2026-11-21) does not affect this class — `simba-english` and `simba-multilingual` list only `/v1/audio/speech` and `/v1/audio/stream` in their `endpoints`. — *Needs a call: which date to pin, whether to let users override it, and who bumps it as Speechify mints new versions.*

that reuses `probe.py`'s pipeline harness.
