# Perplexity LLM — 2026-11-09

The Agent API migration landed since last run and both high gaps are closed; the service now trails Perplexity on two smaller things — it sends the deprecated `preset` field name, and its default model is the fallback of the effort level it ships.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Deprecated `preset` field name** (medium, since 2026-11-09) — Perplexity renamed the Agent API's `preset` to `effort` in October, "a naming change only", keeping `preset` as a deprecated alias with no removal date; the request schema in the API reference now lists only `effort`. Pipecat sends `preset` from two places, the `Settings.preset` field and `_THINKING_DEFAULT`, so every default request carries the old name. Probed today, `effort` is accepted and genuinely parsed — `effort="pw-not-a-level"` comes back HTTP 400 "the effort name or version does not exist" — so swapping the wire field is safe. While in there, the `Settings.preset` docstring lists `fast`/`low`/`medium`/`high`/`xhigh` and misses `ultra`, added 2026-11-05. — *Needs a call: the complete fix renames the public `preset` Settings field to `effort` behind a deprecation; the cheap fix changes only the wire field and leaves ours named after an alias. Nothing forces the breaking half, since Perplexity published no removal date.*
- **Default model is the `fast` effort's fallback** (medium, since 2026-11-09) — `fast@2026-10-16.0` runs `openai/gpt-6-luna` and names our default, `openai/gpt-5.6-luna`, only as the fallback when gpt-6-luna is unavailable. Latency is on the newer model's side: median TTFAT 1098 ms vs 1205 ms over five interleaved runs, and 1050 ms vs 1364 ms on a reasoning-triggering prompt. The aiewf-eval condition rules out a straight bump, though: our default configuration sets reasoning off, and `gpt-6-luna (none)` is unranked on `aiwf_medium_context`, completing 0 of 30 conversations for a fixed-900 pass of 25.0%, where `gpt-5.6-luna (none)` scores 84.4% / 708 ms P50. `gpt-6-luna (low)` does clear it, at 91.8% / 917 ms P50. — *Needs a call: the bump only pays off bundled with a reasoning default of `low` instead of the `fast` effort, which is no longer a value swap — it trades about 200 ms of leaderboard TTFAT for the pass rate, on a service whose whole default posture is lowest latency.*
- **`web_search` is a bool** (medium, since 2026-09-01) — the successor to last run's "search and reasoning controls unexposed" item. Reasoning is now reachable through the inherited `reasoning` setting, but search is not: the service appends a bare `{"type": "web_search"}`, and the tool's `search_type`, `max_results`, token caps, `filters` (domain, recency, date windows) and `user_location` have no names in `Settings`. `search_type` is the live one — Fast Search cut `low` through `xhigh` from $2.50 to $1.00 per 1,000 invocations and the changelog does not list `fast` in that set, so the default voice configuration may be searching on the slower, dearer path. Users are not stuck: `extra={"tools": [...]}` is merged before the append and a `web_search` entry already present is left alone. — *Needs a call: whether `web_search` grows into bool-or-dict or gains a sibling, and first whether the `fast` effort already applies Fast Search — if it does, the default costs nothing extra and this is low.*

Both of last run's high gaps are gone, closed by code rather than by the provider. `PerplexityAgentHttpLLMService` now carries the Agent API (`42c8cb2ed`, `169f4365c`, `5790151fe`) and `PerplexityLLMService` is deprecated since 1.13.0 for removal in 2.0.0 (`b6921ba61`), which is the team's answer to "how long to sit on an unsupported endpoint". The Sonar path still answers through Perplexity's reformulation shim, so the deprecation window is not at risk today. The registry, `examples/function-calling/function-calling-perplexity.py` and the docs page all point at the new class, and the `perplexity` extra is now empty — the service rides the base `openai>=1.74.0,<4` pin. Frontmatter `default_model` is the Agent class's `openai/gpt-5.6-luna`, not the inventory's `sonar`, which is the deprecated class's.
