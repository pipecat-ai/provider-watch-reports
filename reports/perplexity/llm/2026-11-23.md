# Perplexity LLM — 2026-11-23

Nothing in the service is broken or blocked; the two carried medium gaps stand unchanged, the `web_search` gap drops to low now that the docs confirm the shipped default already uses Fast Search, and one docstring line went stale.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Deprecated `preset` field name** (medium, since 2026-11-09) — Perplexity's October rename of `preset` to `effort` still stands, and the API reference's request schema still lists only `effort`. Pipecat sends `preset` from both the `Settings.preset` field and `_THINKING_DEFAULT`, so every default request carries the old name. Probed today, that is safe: the alias is live and genuinely parsed, since `preset="pw-not-a-level"` comes back HTTP 400 "the preset name or version does not exist". A second run of the changelog finds no removal date. While in there, the `Settings.preset` docstring lists `fast`/`low`/`medium`/`high`/`xhigh` and misses `ultra`, added 2026-11-05 on `anthropic/claude-opus-5-5`. — *Needs a call: the complete fix renames the public `preset` Settings field to `effort` behind a deprecation; the cheap fix changes only the wire field and leaves ours named after an alias. Nothing forces the breaking half while Perplexity publishes no removal date.*
- **Default model is the `fast` effort's fallback** (medium, since 2026-11-09) — the `fast` effort runs `openai/gpt-6-luna` and names our default, `openai/gpt-5.6-luna`, only as its fallback. The aiewf-eval condition still rules out a straight bump: re-read today, `gpt-6-luna (none)` — reasoning off, which is what `fast` sets — remains unranked on `aiwf_medium_context`, completing 0 of 30 conversations for a fixed-900 pass of 25.0%, where `gpt-5.6-luna (none)` scores 84.4% / 708 ms P50. Only `gpt-6-luna (low)` clears it, at 91.8% / 917 ms P50. Latency, measured two weeks ago, favours gpt-6-luna (median TTFAT 1098 ms vs 1205 ms over five interleaved runs). — *Needs a call: the bump only pays off bundled with a reasoning default of `low` instead of the `fast` effort, which is no longer a value swap — it trades about 200 ms of leaderboard TTFAT for the pass rate, on a service whose whole default posture is lowest latency.*
- **`web_search` is a bool** (low, since 2026-09-01) — demoted from medium. Last run's open question was whether the shipped default searches on the dearer path; the web-search tool page now states outright that `fast`, `low`, `medium`, `high` and `xhigh` set `search_type: "fast"` themselves, so Pipecat's default configuration already gets the $1.00-per-1k search rather than `web`'s $2.50. The tool's `max_results`, token caps, `filters` (domain, recency, date windows) and `user_location` still have no names in `Settings`, and users reach them through `extra={"tools": [...]}`, which is merged before the service's append. — *Needs a call: whether `web_search` grows into bool-or-dict or gains a sibling at all, now that the one setting with a price attached is already right by default.*
- **Stale Anthropic token-budget line** (low, since 2026-11-23) — the class docstring closes with "Anthropic models need `max_completion_tokens` set", a requirement Perplexity lifted in November: `max_output_tokens` is optional, each generation may produce up to 128,000 tokens, and `input` is the API reference's only required field. Probed today, `anthropic/claude-haiku-5-5` answers through the service with no budget set. — *Needs a call: delete the sentence or qualify it, since the changelog ties the relaxation to the `2026-11-11.0` effort versions and a user who pins an older one may still need the budget.*

No code changed under `src/pipecat/services/perplexity/` since the last report beyond the repo-wide adapter move (`db4060213`), so the Agent API migration, the `PerplexityLLMService` deprecation (1.13.0, removal 2.0.0) and the docs page all stand as last described. The catalogue moved: `openai/gpt-6.2-sol`, `openai/gpt-6.2-astra`, `google/gemini-4-carbon`, `google/gemini-4-hydrogen` and `anthropic/claude-fable-5-2` arrived, and the older `claude-fable-5`, `claude-fable-5-1`, `claude-opus-5` and `claude-sonnet-5` left the model docs. None of that reaches the service, which has no allowlist and no per-model table, and none of the departed ids is hard-coded here or in `examples/function-calling/function-calling-perplexity.py`. Frontmatter `default_model` is the Agent class's `openai/gpt-5.6-luna`, not the inventory's `sonar`, which belongs to the deprecated class.
