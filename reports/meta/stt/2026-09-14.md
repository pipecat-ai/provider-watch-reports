# Meta STT — 2026-09-14

Nothing to change for the default: `muse-voice-transcribe-1.0` is the only model Meta ships (launched 2026-09-01). The three open items are all about DIARIZATION mode, and none could be probed — `META_API_KEY` is not set in this environment.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Duplicate finals in DIARIZATION** (medium, since 2026-09-14) — Meta's "Speech to text" page gives the per-turn final as `speechComplete` for *both* ENDPOINTING and DIARIZATION, and a `transcript` with `final: true` only for PUSH_TO_TALK. `_handle_transcript` treats any final-flagged transcript as final when `mode != "ENDPOINTING"`, which includes DIARIZATION, while `speechComplete` pushes its own final — two `TranscriptionFrame`s for one turn. The condition would become `mode == "PUSH_TO_TALK"`; `tests/test_meta_stt.py` covers ENDPOINTING and PUSH_TO_TALK only. — *Needs a call: confirm against a live DIARIZATION session whether the server emits final-flagged transcripts there; no credential was available to check.*
- **Speaker labels do not leave the service** (medium, since 2026-09-14) — `speaker` events carry a session-scoped `label` and arrive once per turn, but `_handle_message` only trace-logs them, and the `speechComplete` message that becomes the final frame has no label of its own, so diarized output reaches the pipeline unattributed. — *Needs a call: which surface to use — Speechmatics formats the speaker into the transcript text (`speaker_active_format`), Soniox annotates tokens; picking one is a design decision, not a pass-through.*
- **No batch transcription service** (low, since 2026-09-14) — Meta also exposes `POST /v1/asr/transcribe` for recordings (RIFF/WAVE, 10 min / 32 MB), sharing models, modes, `languageBias` and `keywords` with the socket. — *Needs a call: whether a `SegmentedSTTService` subclass is wanted, since it is a new class rather than a settings change.*

Everything else in the handshake schema is already reachable: `model`, `mode`, `audioEncoding`, `languageBias`, `keywords`, `emitAudioProgress` and `zdrOverride` all map to `MetaSTTSettings` fields, and `partialMode` is deliberately pinned to `CUMULATIVE` with the interim-replacement behavior the class relies on. The 25 language names Meta validates match `_LANGUAGE_MAP` exactly.
