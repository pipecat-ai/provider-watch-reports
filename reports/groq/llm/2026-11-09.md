# Groq LLM — 2026-11-09

Nothing to do: `openai/gpt-oss-120b` is unchanged as Groq's production flagship, it is not on the deprecations page, and the API catalogue matches the 2026-10-12 and 2026-10-28 runs exactly.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Groq's reasoning default** (low, since 2026-09-01) — a third measurement, and this one favors `reasoning_effort="low"` on both prompts: 319 ms TTFAT against 412 ms shipped on a trivial prompt (median of 5 each) and 448 ms against 736 ms on a reasoning-triggering one (median of 3 each, with non-overlapping ranges). Over three runs `low` leads four of six comparisons, so the latency case is now better than the last run suggested, though still noisy on the trivial prompt. — *Needs a call: shipping `reasoning_effort="low"` changes what the service does by default, so it is a maintainer's decision, not an automatic bump.*
- **`reasoning_format` and `include_reasoning`** (low, since 2026-09-14) — Groq's own parameters, reachable only through `Settings.extra` today; a field pair would travel in `extra_body`. Groq still documents `reasoning_format` as unsupported on GPT-OSS, and no catalogue model streams reasoning inline. — *Needs a call: Groq documents the two as mutually exclusive, so exposing both needs a stance on a user setting both.*
- **qwen/qwen3.8-27b** (low, since 2026-09-01) — still Groq *preview*, so it cannot be a default, and its two aiewf-eval rows (96.0% Baseten FP8, 95.1% local RTX 5090) are both off-Groq and unchanged this run. — *Needs a call: nothing to do until Groq promotes it and a Groq-hosted row appears.*
- **`xhigh` reasoning effort** (low, since 2026-10-28) — `meta-models/muse-spark-open` reasons always-on and defaults to `reasoning_effort="xhigh"`, a value our `Literal` does not list; the gate is typing and docstring only. — *Needs a call: the model is Enterprise-gated, so `xhigh` cannot be probed from this account.*

Groq's models page gained one preview entry since last run, `minimaxai/minimax-m2.7` (196k context, interleaved reasoning), and like `meta-models/muse-spark-open` it is Enterprise/contact-sales and absent from the `/models` API response this account sees. Its page documents no `reasoning_effort` values, so it adds nothing to the `Literal` question; preview status rules it out as a default either way.

No string Pipecat ships names a retired model: `examples/voice/voice-groq.py` is the only Groq example pinning one (`openai/gpt-oss-120b`), the service's docstring default matches, and the deprecations page has gained no entries since 2026-09-21. The changelog's newest entry is still 2026-04-18. aiewf-eval still has no Groq-hosted row, so a future Groq default bump has no same-host baseline.
