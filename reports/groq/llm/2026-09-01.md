# Groq LLM — 2026-09-01

`openai/gpt-oss-120b` is current and nothing is retiring; the open question is reasoning control, where Groq's `raw` default sends chain-of-thought to the TTS.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **`<think>` leaks into spoken text** (high, since 2026-09-01) — Groq defaults `reasoning_format` to `raw`, so a reasoning model's chain-of-thought arrives as ordinary `LLMTextFrame`s: `qwen/qwen3.6-27b` answered "Say hello in five words" with 1962 text frames beginning `\n<think>\n`. Setting `reasoning_format=parsed` restores 7 frames beginning `Hello`, and `openai/gpt-oss-120b` accepts the same value. This is reachable today only as `extra={"extra_body": {"reasoning_format": "parsed"}}` — `Settings.extra` is spread as OpenAI SDK kwargs, so the flat form fails client-side with `unexpected keyword argument 'reasoning_format'`. Groq points llama-3.3-70b-versatile users (retired 2026-08-16) at qwen/qwen3.6-27b, so this is on a live migration path. — *Needs a call: default `reasoning_format` to `parsed` in GroqLLMService (a behavior change), or only add the Settings field and leave the default as Groq ships it?*
- **No typed reasoning controls** (medium, since 2026-09-01) — `reasoning_effort` and `reasoning_format` have no `Settings` fields. Reasoning is on by default for the shipped default model: median TTFAT 486 ms (227 ms thinking) versus 311 ms (36 ms thinking) with `reasoning_effort=low`, and 1638 ms with 1128 ms thinking on a reasoning-triggering prompt. — *Needs a call: allowed values differ per model and Groq documents the two parameters as mutually exclusive on gpt-oss, so a typed field needs a validation stance and a decision on whether it lives on `GroqLLMSettings` or the shared OpenAI base.*
- **Qwen 3.6/3.8-27B** (low, since 2026-09-01) — both are Groq *preview* models, so neither can be a default; aiewf-eval scores them well above gpt-oss-120b (97.3%/97.8% vs 86.3%) but only on Baseten and local GPUs, never on Groq. — *Needs a call: nothing to do until Groq promotes one to production and a Groq-hosted row appears on the leaderboard.*
