# Groq STT — 2026-10-28

Nothing changed on Groq's side — same two Whisper models, same request schema, no STT deprecation — and nothing changed in the service. The three carried gaps all reproduce; the only movement is that docs.pipecat.ai now documents the `language=None` failure, which drops that item from high to medium.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **`language=None` errors instead of auto-detecting** (medium, since 2026-09-01) — `GroqSTTService._transcribe` still opens with `assert self._settings.language is not None`; today's probe with `language=None` yielded zero `TranscriptionFrame`s and one `ErrorFrame` reading `Unknown error occurred: ` (the AssertionError carries no message). Groq's speech-to-text reference still lists `language` as optional and Whisper detects the language when it is absent, so auto-detection is a capability the service cannot express. Dropping the assert and omitting the key when it is None is the shape of the fix. The docs page that previously told users to set `language=None` for auto-detection has been rewritten to state that it fails, so users are no longer walked into it — hence medium rather than high. — *Needs a call: `openai/stt.py` has the identical assert, so this is either a Groq-only fix or a whisper-family one, and the gpt-4o transcribe models OpenAISTTService defaults to may not tolerate an omitted language the way Whisper does.*
- **`Settings.extra` never reaches the request** (medium, since 2026-09-01) — the kwargs dict in `_transcribe` covers `file`, `model`, `response_format`, `language`, `prompt` and `temperature` and nothing else, while `ServiceSettings.extra` exists on every settings object. A probe setting `extra={"timestamp_granularities":["word"]}` transcribed normally instead of failing, which is how the API answers that combination when `response_format` is `json` — so `extra` was silently discarded. Groq's `timestamp_granularities[]`, an explicit `response_format`, and the `url` upload form have no path through the service; `response_format` is chosen solely by `include_prob_metrics`. — *Needs a call: whether `extra` should be spread into the whisper services' transcription requests at all, and whether word timestamps are worth exposing before `TranscriptionFrame` can carry them.*
- **10-second minimum billed length** (low, since 2026-09-01) — Groq bills every transcription request as at least 10 seconds, and `SegmentedSTTService` issues one request per utterance, so a bot with 1–3 s turns pays multiples of its audio duration. Nothing in the service docstring or the docs page says so. — *Needs a call: the note belongs in the docs repo; confirm the docs team wants it.*

No default bump: Groq positions `whisper-large-v3-turbo` as the price/performance pick and `whisper-large-v3` as the accuracy pick, not as a successor, and v3 probed slower (TTFB 369 ms vs 330 ms median of 3) at 2.8x the hourly price.
