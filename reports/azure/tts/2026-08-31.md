# Azure TTS — 2026-08-31

Nothing in this service is deprecated and the default `en-US-SaraNeural` is GA; the work is reaching Azure's newer voice families — their model parameters are on a branch, and the streaming class goes text-silent on MAI voices.

## What's new for Pipecat

Azure's catalogue in `eastus` is now 763 voices: 561 standard neural plus four HD/MAI families (`DragonHDLatestNeural`, `DragonHDOmniLatestNeural`, `DragonHDFlashLatestNeural`, and the public-preview `MAI-Voice-2` / `MAI-Voice-2-Flash`). All of them are selected by voice name, so `Settings(voice=...)` already reaches them, and the SSML this service builds — including the `<mstts:silence>` element the HD families don't support — is accepted by every family probed.

### PRs
- `provider-watch/azure-tts-voice-parameters` — review: `git show provider-watch/azure-tts-voice-parameters` — Expose Azure's HD and MAI voice parameters

### To consider
- **No text frames on MAI voices** (medium, since 2026-08-31) — `AzureTTSService` derives its `TTSTextFrame`s from Azure word boundary events (`push_text_frames=False`); `en-US-Ethan:MAI-Voice-2-Flash` returned 0 word boundaries where standard, DragonHD and DragonHDOmni voices each returned 11, so bot transcripts and word-timed UI disappear for the whole MAI family while audio still plays. — *Needs a call: a "no word boundary arrived, push the sentence" fallback changes timing semantics for every voice, so it has to be either unconditional or keyed to the voice family.*
- **Custom voice deployments** (medium, since 2026-08-31) — `AzureSTTService` accepts `endpoint_id` and sets it on the `SpeechConfig`; the TTS classes offer only `private_endpoint`, so a fine-tuned (professional) voice deployment cannot be addressed. — *Needs a call: it is a constructor argument, not a runtime setting, so the shape is a maintainer's decision.*
- **Personal voice** (low, since 2026-08-31) — instant voice cloning is addressed with `<mstts:ttsembedding speakerProfileId='...'>` around the text; the SSML builder has no element for it. — *Needs a call: the feature is behind Azure's Limited Access Review, so it is worth deciding whether Pipecat carries SSML most users cannot use.*
- **Token-level text streaming** (low, since 2026-08-31) — Azure's websocket v2 `TextStream` request type consumes LLM tokens directly instead of waiting for Pipecat's sentence aggregation. — *Needs a call: that path takes no SSML at all (voice name and output format only), so every setting this class exposes would be dropped on it.*
- **Sentence-boundary silence** (low, since 2026-08-31) — the 20 ms `<mstts:silence>` is hard-coded; Azure's other silence types and values are unreachable. — *Needs a call: 20 ms is a deliberate low-latency default, so exposing it means fixing what stays default and which types earn a field.*
- **Unlisted sample rates** (low, since 2026-08-31) — `sample_rate_to_output_format` quietly falls back to 24 kHz while frames carry the pipeline's rate, so a pipeline at, say, 32 kHz plays distorted audio rather than erroring. — *Needs a call: raise, resample, or keep the silent fallback.*
- **SDK floor** (low, since 2026-08-31) — `azure-cognitiveservices-speech>=1.47.0` allows versions without the 1.50 TTS connection-race fix, the 1.51 REST token-credential fix, and the 1.48.2 CRL fix Microsoft required by 2026-07-01. Fresh installs resolve to 1.51.2. — *Needs a call: whether provider-watch may raise dependency floors (same item as azure/stt).*
