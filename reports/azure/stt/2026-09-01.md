# Azure STT — 2026-09-01

No provider movement since yesterday: the streaming Speech SDK still has no model selector, nothing the class uses is retiring, and PR #5511 carries the only ready change.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5511 — Add segmentation_silence_timeout_ms to AzureSTTService settings (open, unmerged)

### To consider
- **Semantic segmentation** (medium, since 2026-08-31) — `Speech_SegmentationStrategy="Semantic"` ends phrases at sentence-ending punctuation instead of on silence; one more `set_property` pass-through next to the field on #5511. — *Needs a call: Azure does not offer it in every locale and it disables confidence scores and NBest lists, so exposing it needs a stance on locales where it silently does nothing.*
- **Automatic language detection** (medium, since 2026-08-31) — the recognizer is always constructed with one locale; Azure's open-range `AutoDetectSourceLanguageConfig` (SDK 1.50+) would let a session switch language per utterance, and `_on_handle_recognized` already reads `result.language`. — *Needs a call: it takes a second recognizer construction path and a decision on what `Settings.language` means once detection is on.*
- **Phrase lists** (medium, since 2026-08-31) — `PhraseListGrammar` biasing for names and domain terms has no route into the service. — *Needs a call: it attaches to the recognizer rather than the config, so someone has to decide where re-application on reconnect lives.*
- **Post-stream refinement** (low, since 2026-08-31) — `SpeechServiceResponse_PostProcessingOption=PostRefinement` is GA for single-locale sessions and advertised as latency-neutral. — *Needs a call: Azure says short phrases often come back unchanged, so measure it on agent-length turns before exposing it.*
- **Azure's newest STT models** (low, since 2026-08-31) — `mai-transcribe-1.5` is only on the LLM Speech API (file transcription, public preview) and Voice Live; `mai-transcribe-1` was deprecated on 2026-08-20. Neither is reachable from the streaming Speech SDK this class uses. — *Needs a call: that would be a separate non-streaming service or a Voice Live integration, not a change here.*
- **SDK floor** (low, since 2026-08-31) — the `azure` extra allows 1.47.0, below the 1.48.2 that Microsoft required for Linux/Android CRL checking by 2026-07-01. Fresh resolves land on 1.51.x, so only installs pinned to old versions are exposed. — *Needs a call: whether provider-watch may raise dependency floors.*
