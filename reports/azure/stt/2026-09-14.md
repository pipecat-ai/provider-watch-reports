# Azure STT — 2026-09-14

Current: #5511 merged on 2026-09-03, the streaming Speech SDK still has no model selector, and nothing the class uses is deprecated or retiring.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/5511 — Add segmentation_silence_timeout_ms to AzureSTTService settings (merged 2026-09-03; the field, its test and the docs page are all live, so that gap is closed)

### To consider
- **Semantic segmentation** (medium, since 2026-08-31) — `Speech_SegmentationStrategy="Semantic"` ends phrases at sentence-ending punctuation instead of on silence; mechanically it is one more `set_property` next to the field #5511 landed, the SDK 1.41 floor is met, and the confidence-score/NBest loss Azure warns about is free here because the class reads only `result.text`. — *Needs a call: Azure scopes Semantic to dictation and captioning and says it is not for interactive scenarios — which is what Pipecat is — and it is locale-limited, so it needs a stance plus a latency measurement on agent-length turns.*
- **Automatic language detection** (medium, since 2026-08-31) — the recognizer is always constructed with one locale; Azure's open-range `AutoDetectSourceLanguageConfig` (25 languages) would let a session switch language per utterance, and `_on_handle_recognized` already reads `result.language`. — *Needs a call: it takes a second recognizer construction path and a decision on what `Settings.language` means once detection is on.*
- **Phrase lists** (medium, since 2026-08-31) — `PhraseListGrammar` biasing for names and domain terms has no route into the service; Azure documents it for real-time transcription with a 2,000-phrase cap and a `set_weight` range of 0.0–2.0. — *Needs a call: it attaches to the recognizer rather than the config, so someone has to decide where re-application on reconnect lives.*
- **Post-stream refinement** (low, since 2026-08-31) — `SpeechServiceResponse_PostProcessingOption=PostRefinement` is GA for monolingual sessions, widened to 29 locales in August, and advertised as latency-neutral. — *Needs a call: Azure says short phrases often come back unchanged, so measure it on agent-length turns before exposing it.*
- **Azure's newest STT models** (low, since 2026-08-31) — `mai-transcribe-2` arrived in public preview on 2026-09-05 (60 languages, diarization, word timestamps, keyword biasing), but like `mai-transcribe-1.5` it is reachable only through the file-upload LLM Speech / Fast Transcription REST API and Voice Live; `mai-transcribe-1` was deprecated on 2026-08-20. None of them is on the streaming Speech SDK this class uses. — *Needs a call: that would be a separate non-streaming service or a Voice Live integration, not a change here.*
- **SDK floor** (low, since 2026-08-31) — the `azure` extra allows 1.47.0, below the 1.48.2 that Microsoft required for Linux/Android CRL checking by 2026-07-01. Fresh resolves land on 1.51.x, so only installs pinned to old versions are exposed. — *Needs a call: whether provider-watch may raise dependency floors.*
