# Azure Image — 2026-10-12

`AzureImageGenServiceREST` remains non-functional against Azure — retired endpoint, retired api-version, retired models — and the fix is still a rewrite, so no branch.

## What's new for Pipecat

### PRs

Nothing.

### To consider

- **Retired endpoint and api-version** (high, since 2026-08-31) — `run_image_gen` posts to `{endpoint}openai/images/generations:submit?api-version=2023-06-01-preview` and polls `operation-location`. That api-version retired 2024-07-01, and the submit/poll flow belonged to DALL-E 2 (retired 2025-01-27); dall-e-3 retired 2026-03-04 with existing deployments non-functional. Azure serves every current image model synchronously from `POST {endpoint}openai/v1/images/generations`, which takes `model` in the body — the service never sends one, so `AzureImageGenSettings.model` is ignored — and returns `b64_json` for the whole gpt-image-* family, while the service reads `result.data[0].url`. — *Needs a call: the port changes request, response decoding and the polling loop together, and verifying it needs a live Azure image deployment; no AZURE_DALLE_API_KEY is configured here.*
- **Settings surface** (medium, since 2026-08-31) — Azure documents `quality`, `background`, `output_format`, `output_compression`, `moderation`, `n` (1-10), `style`, `response_format`, `user` and streaming (`stream`, `partial_images`) on `/images/generations`; `AzureImageGenSettings` adds only `image_size`, and `n` is hard-coded to 1. Domains are model-dependent (gpt-image-2/2.5 custom sizes to 3840px; `xhigh`/`max` quality on 2.5 only). — *Needs a call: the parameter set differs between the retired submit flow and the v1 endpoint, so adding fields before the rewrite would encode the dead schema.*
- **Unguarded header read** (medium, since 2026-08-31) — `submission.headers["operation-location"]` raises `KeyError` on any non-2xx response instead of yielding an `ErrorFrame`; against the retired endpoint that is now every call. — *Needs a call: whether to patch the error path standalone or only as part of the rewrite.*
