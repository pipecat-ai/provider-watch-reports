# Kokoro TTS — 2026-11-09

Current: no upstream movement at all since the last run — kokoro-onnx 0.6.1 (2026-08-19) is still the latest release, its newest commit is a 2026-09-01 example typo fix, and model-files-v1.1 (2025-03-01) is still the newest model drop. The same three gaps carry forward.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Model downloads point at the superseded release** (medium, since 2026-09-01) — `KOKORO_MODEL_URL`/`KOKORO_VOICES_URL` fetch from `model-files-v1.0`, while kokoro-onnx 0.6.x and its README publish the same two file names under `model-files-v1.1`, re-exported with a duration output (`create_timed()` timestamps, `continuous=True` synthesis) and an embedded vocab config. 0.6.1 loads the old export fine — it falls back to the packaged vocabulary and reports no timings — so this costs capability, not correctness. — *Needs a call: the v1.1 files have the same names as the cached v1.0 ones, so bumping the URLs leaves every existing install on the old graph unless the cache key changes too.*
- **Model variants are hand-rolled** (low, since 2026-09-01) — `Settings.model` is unused; the fp16 (164 MB) and int8 (114 MB) exports and the Chinese/English `kokoro-v1.1-zh` model with its 103-voice pack are reachable only by downloading them and passing `model_path`/`voices_path`. — *Needs a call: whether a `model` value should map to a download URL pair, and how the zh model's separate voice pack fits that mapping.*
- **Pause and trim controls** (low, since 2026-09-01) — `create_stream()` in 0.6.1 still takes `trim=True`, `sentence_pause=0.25` and `clause_pause=0.1`, which set the silence kokoro-onnx puts between synthesis batches; `run_tts` passes only `voice`, `lang` and `speed`. — *Needs a call: not a plain pass-through — pauses are only inserted when `trim` is on, so the three have to be exposed as a group with that interaction documented.*

Context for the next run, not a gap: community PR https://github.com/pipecat-ai/pipecat/pull/6473 (open since 2026-10-30) rewrites `run_tts` to phonemize once and stream phoneme chunks, because kokoro-onnx batches up to 510 phonemes per inference and a long reply therefore produces its first audio after a full-text synthesis. It touches the same `create_stream` call any pause/variant work would.
