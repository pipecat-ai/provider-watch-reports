# Inception LLM — 2026-11-09

`mercury-3` is Inception's flagship and already the service default; the repo's last `mercury-2` pin dies with the model on 2026-11-15, and a branch fixes it.

## What's new for Pipecat

### PRs
- https://github.com/pipecat-ai/pipecat/pull/6653 — Move the Inception turn-completion entry to Mercury 3

### To consider
- **No reasoning-defaults table** (medium, since 2026-09-01) — the service omits `reasoning_effort`, so Inception's server-side `medium` applies, while CONTRIBUTING asks LLM services to send each listed model the lowest setting its provider documents (`instant` for mercury-3). On mercury-3 that is worth about 200 ms of TTFAT on a reasoning-triggering turn (see Verification) — much less than the 1.6 s it was on mercury-2.5, so the pressure is convention rather than latency. — *Needs a call: `instant` also drops mercury-3's default token budget from 24,576 to 8,192, and the base `_apply_thinking_default()` helper merges dict-valued fields while `reasoning_effort` is a top-level string, so the value and the plumbing both need deciding.*
- **Reasoning summaries** (low, since 2026-09-01) — `reasoning_summary` and `reasoning_summary_wait` are not in `InceptionLLMSettings`; responses now include a `reasoning_summary` object with a `status`, but `BaseOpenAILLMService` never reads reasoning content out of the stream. — *Needs a call: whether Pipecat wants reasoning summaries surfaced at all is a base-class question, not an Inception one.*
- **Mercury Voice has no model ID** (low, since 2026-09-14) — a 128K chat model built for voice agents with sub-170 ms TTFT, now listed on the models page and in production at Inception's customers, but reachable only through sales and absent from the catalogue. — *Needs a call: nothing to decide until it has an ID; re-check next run.*
- **`mercury-decide` is not a chat model** (low, since 2026-11-09) — new in the `/models` catalogue, but it serves `v1/decisions` with no chat, streaming or tools, so it cannot be used through `InceptionLLMService`. — *Needs a call: wrapping a decisions endpoint would be a new service, not a change to this one.*

The previous report's top gap — `mercury-2` superseded by `mercury-2.5` — is closed: pipecat-ai/pipecat#6397 moved the default past both, to `mercury-3`.

## Verification

| model     | class               | ok | latency                                   | note                                                        |
| --------- | ------------------- | -- | ----------------------------------------- | ----------------------------------------------------------- |
| mercury-3 | InceptionLLMService | ✅ | TTFAT 337 ms (median of 5), thinking 0 ms | defaults, trivial prompt; spread 246–554 ms                  |
| mercury-3 | InceptionLLMService | ✅ | TTFAT 525 ms (median of 5), thinking 0 ms | defaults, reasoning-triggering prompt; spread 376–1307 ms    |
| mercury-3 | InceptionLLMService | ✅ | TTFAT 324 ms (median of 5), thinking 0 ms | `reasoning_effort=instant`, same prompt; spread 270–442 ms   |

As on earlier Mercury models, reasoning is never streamed as reasoning deltas (`thinking_ms` is 0 at every effort level); at the provider default the model writes its working into the answer text.
