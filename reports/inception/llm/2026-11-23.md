# Inception LLM — 2026-11-23

Inception is shutting the Mercury API down after 2026-12-28; `InceptionLLMService` is already deprecated (1.17.0) with no replacement, so the remaining work is retirement scheduling, not keeping up.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **`pipecat init` still offers Inception** (high, since 2026-11-23) — the CLI registry entry in `src/pipecat/cli/registry/service_metadata.py` puts Inception in the LLM picker for new projects, five weeks before the provider stops serving requests. `ServiceDefinition` carries no deprecation flag, so there is no way to list it with a caveat. — *Needs a call: pull the registry entry now, ahead of the service, or leave it until the service itself goes.*
- **Repo entry points die with the API** (medium, since 2026-11-23) — the function-calling example, the two eval-manifest entries (`evals/release/manifest.yaml`, `evals/turn-completion/manifest.yaml`), `env.example` and the README row all point at `api.inceptionlabs.ai`. After 2026-12-28 the example fails for users and the two suites fail for maintainers. — *Needs a call: a removal date of their own, or removal together with the service, which the deprecation notice permits before 2.0.0.*

Closed since the last run: the `mercury-2` eval pin (pipecat-ai/pipecat#6653, merged 2026-11-09 — the manifest now runs `mercury-3`). The previous report's four capability gaps — no reasoning-defaults table, `reasoning_summary`/`reasoning_summary_wait` not in `Settings`, Mercury Voice having no public model ID, and `mercury-decide` not being a chat model — are dropped rather than carried: all four are work that would extend a service deprecated for removal with no replacement, and the provider's facts behind them are unchanged.
