# Inception LLM — 2026-09-01

Current: `mercury-2` is the only model Inception exposes, it is GA, and it works through `InceptionLLMService`. No branch this run.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Unset `reasoning_effort`** (medium, since 2026-09-01) — the service omits the parameter, so Inception's server-side default `medium` applies. Inception's docs recommend `instant`/`low` for latency-sensitive work, and `examples/function-calling/function-calling-inception.py` already sets `"low"`. Measured: median TTFAT 475 ms unset vs 225 ms with `instant` on a reasoning-triggering prompt; 270 ms vs 261 ms on a trivial one. — *Needs a call: a default of `low` buys tail latency on hard turns at some answer-quality cost, so the choice is a product decision, not a mechanical bump.*
- **Reasoning summaries** (low, since 2026-09-01) — `reasoning_summary` and `reasoning_summary_wait` are not in `InceptionLLMSettings`; they would pass through via `extra_body` like `realtime` does, but `BaseOpenAILLMService` never reads reasoning content out of stream deltas, so the summary would be dropped. — *Needs a call: whether Pipecat wants reasoning summaries surfaced at all is a base-class question, not an Inception one.*
