# Novita LLM — 2026-11-23

Nothing to merge: both open items carry over unchanged, but the deprecated `kimi-k2.5` default is starting to misbehave on Novita (one failed run in five, a 9.7 s outlier in another repeat) while its successor is still unbenchmarked.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default kimi-k2.5 is retired upstream** (high, since 2026-09-01) — Moonshot's model page is unchanged from last run: `kimi-k3.1-pro` is the flagship, `kimi-k3` previous-generation, `kimi-k2.6` closed to new users and deprecating late December 2026, and `kimi-k2.5` marked "Deprecated" with no date and no named successor. Novita still promotes `kimi-k2.5` as its "latest flagship iteration" with no sunset notice, and its only changelog entry (Nov 29, 2026) retires two Fish Audio speech models, nothing on LLMs. What moved is the probe: `kimi-k3.1-pro` is now TTFAT 1899 ms (median of 5, thinking on by default) against 2997 ms last run, and 1498 ms with thinking disabled against 1453 ms — while `kimi-k2.5` medians 900 ms but failed one run of five and produced a 9730 ms first-token outlier in a separate three-run repeat. So the candidate is closing the gap and the incumbent is getting less reliable, but the candidate is still slower on the median and aiewf-eval's `aiwf_medium_context` leaderboard still carries rows only for `kimi-k2.6` (98.8% / 1560 ms thinking on, 88.7% / 481 ms thinking off, both Baseten) and none for `kimi-k2.5`, `kimi-k3` or `kimi-k3.1-pro`. — *Needs a call: which successor to adopt while aiewf-eval has benchmarked none of them, and whether the deprecated default's new failure and outlier behavior now outweighs the candidate's worse median latency.*
- **Thinking control is undiscoverable** (low, since 2026-09-01) — Novita's reasoning models accept `chat_template_kwargs: {"thinking": false}`, but `Settings.extra` keys are merged into the OpenAI SDK call as top-level kwargs (`base_llm.py`, `params.update(self._settings.extra)`), so users must write `extra={"extra_body": {"chat_template_kwargs": {"thinking": False}}}`. That idiom probes green and takes `kimi-k3.1-pro` from 1899 ms to 1498 ms, but neither the class docstring nor docs.pipecat.ai mentions it. — *Needs a call: whether this belongs in the class docstring here or only in the docs repo.*

Catalogue churn since last run: `qwen/qwen3-vl-plus`, `qwen/qwen4-max` and `tencent/hy4-flash` are new; every MiniMax entry (`minimax/minimax-m2.5` through `minimax-m3.1-flash`, `minimaxai/minimax-m1-80k`) has disappeared, along with `meta-llama/llama-4-maverick-17b-128e-instruct-fp8`, `deepseek_v3` and the serving-tier/internal ids (`*-p`, `nvrouter/*`, `dev/glm46`, `moonshotai/kimi-k3-p`). Nothing in Pipecat or its examples names any of the departed ids; `examples/function-calling/function-calling-novita.py` pins `openai/gpt-oss-120b`, still listed.
