# Novita LLM — 2026-11-09

Nothing to merge: Moonshot shipped a new flagship (`kimi-k3.1-pro`) and Novita carries it, but it is still slower to first answer token than our deprecated `kimi-k2.5` default and still unbenchmarked, so both open items carry over.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default kimi-k2.5 is retired upstream** (high, since 2026-09-01) — Moonshot's model page now heads its list with `kimi-k3.1-pro` ("most capable flagship to date", 1M context, native vision) and its `-highspeed` variant, demotes `kimi-k3` to "previous-generation flagship", gives `kimi-k2.6` and `kimi-k2.7-code` a concrete late-December 2026 deprecation, and leaves `kimi-k2.5` marked "Deprecated" with no date and no named successor. Novita's model page still promotes `kimi-k2.5` as its latest flagship Kimi with no sunset notice, and Novita's changelog carries no Kimi retirement. Our probe has `kimi-k2.5` answering at TTFAT 1266 ms (median of 5) against 2997 ms for `kimi-k3.1-pro` and 2932 ms for `kimi-k3.1-pro-highspeed`, both of which turn thinking on by default; disabling thinking brings them to 1453 ms and 1954 ms, so `kimi-k3.1-pro` is the first candidate within reach of the current default — but only in a configuration the service does not ship. aiewf-eval's `aiwf_medium_context` leaderboard still has rows for `kimi-k2.6` only (98.8% / 1560 ms thinking on, 88.7% / 481 ms thinking off, both Baseten) and none for `kimi-k2.5`, `kimi-k3` or `kimi-k3.1-pro`, so the pass-rate comparison a bump requires cannot be made this run. — *Needs a call: which successor to adopt while aiewf-eval has benchmarked none of them, and whether shipping it with thinking disabled — a behavior change rather than a value change — is acceptable.*
- **Thinking control is undiscoverable** (low, since 2026-09-01) — Novita's reasoning models accept `chat_template_kwargs: {"thinking": false}`, but `Settings.extra` keys are merged into the OpenAI SDK call as top-level kwargs (`base_llm.py`, `params.update(self._settings.extra)`), so users must write `extra={"extra_body": {"chat_template_kwargs": {"thinking": False}}}`. That idiom probes green and cuts TTFAT roughly in half on both K3.1 variants, but neither the class docstring nor docs.pipecat.ai mentions it. — *Needs a call: whether this belongs in the class docstring here or only in the docs repo.*

`moonshotai/kimi-k3.1-pro` and `moonshotai/kimi-k3.1-pro-highspeed` are new in the catalogue since last run, as are `minimax/minimax-m3.1-flash`, `stepfun/step-5-preview`, `tencent/hy4` and `zai-org/glm-5.3-flashX`; the catalogue also re-exposes older DeepSeek/Qwen/GLM generations that the previous run's listing did not include. `moonshotai/kimi-k3-p` remains a serving tier, not a distinct model.
