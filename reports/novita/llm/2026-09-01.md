# Novita LLM — 2026-09-01

`moonshotai/kimi-k2.5` is end-of-life at Moonshot but still works on Novita; every Kimi successor is 2–8x slower to first answer token there, so the default stays put and the successor question goes to a maintainer.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Default kimi-k2.5 is retired upstream** (high, since 2026-09-01) — Moonshot retired `kimi-k2.5` on 2026-08-31 (calls to its own platform now 404) and points users at `kimi-k3`; Baseten and Cloudflare retired it earlier in 2026. Novita still serves the open weights and our probe answers normally at TTFAT 675 ms (median of 5). The successors are not voice-usable as they ship on Novita: `kimi-k2.6` medians 2624 ms and `kimi-k3` 5289 ms with thinking on by default, and on a reasoning prompt `kimi-k2.6` spent 42 s thinking (probe timed out). Turning thinking off gets `kimi-k2.6` to 1363 ms — still 2x the incumbent. aiewf-eval scores `kimi-k2.6` at 98.3% (thinking on) / 93.9% (thinking off) and has no row for `kimi-k2.5` or `kimi-k3`, so the pass-rate comparison the default-bump rule needs cannot be made. — *Needs a call: which successor to adopt, and whether to ship it with thinking disabled — the only variant that is fast enough is a behavior change, not a value change.*
- **Thinking control is undiscoverable** (low, since 2026-09-01) — Novita's reasoning models accept `chat_template_kwargs: {"thinking": false}`, but `Settings.extra` keys go to the OpenAI SDK as top-level kwargs, so users have to write `extra={"extra_body": {"chat_template_kwargs": {"thinking": False}}}`. That idiom probes green and halves TTFAT on `kimi-k2.6`, but neither the class docstring nor docs.pipecat.ai mentions it. — *Needs a call: whether this belongs in the class docstring here or only in the docs repo.*
