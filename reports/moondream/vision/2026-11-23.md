## What's new for Pipecat

### PRs
Nothing.

### To consider

- **Moondream 3 is not reachable** (medium, since 2026-09-01) — `moondream/moondream3.1-9B-A2B` is still unchanged since 2026-07-08 and its Hugging Face repo holds only `config.json` and `model.safetensors` with no `auto_map`, so `trust_remote_code` loading cannot reach it; it targets the Photon runtime. `moondream/moondream3-preview` does carry `hf_moondream.HfMoondream`, but it is blocked twice over: moondream.ai/models still labels it "preview" against moondream2 "stable", and `load_model`'s `Transformers5Moondream` subclass is written to moondream2's layout — it copies a 2-D `tril(max_context, max_context)` into `module.attn_mask`, where moondream3 registers a 4-D mask and keeps `freqs_cis` on the text module. — *Needs a call: add a Photon-based backend, or wait for a transformers-loadable Moondream 3 release.*
- **`revision` is moondream2-specific** (medium, since 2026-09-01) — the constructor's `revision="2025-06-21"` default is applied to whatever repo `Settings(model=...)` names, and that tag exists only in `vikhyatk/moondream2`; pointing the service at any `moondream/*` repo fails to resolve unless the caller also passes `revision=None`. — *Needs a call: move `revision` into `Settings`, or default it to `None` when the model is not moondream2.*
- **`query` knobs are not exposed** (medium, since 2026-09-01) — at the pinned revision, `query(image, question, reasoning=False, spatial_refs=None, stream=False, settings=None)` offers grounded reasoning, streaming and `TextSamplingSettings`; `MoondreamSettings` inherits only `model`, and `run_vision` calls `query(image_embeds, text)` positionally, then yields a single `VisionTextFrame` once the whole answer is generated. On moondream3-preview `reasoning` defaults to `True`, so the flag becomes load-bearing if that model is ever supported. — *Needs a call: whether reasoning and sampling belong in `Settings`, and whether streaming should change the emitted frame shape.*

Context, no action: Moondream Cloud's shutdown date (2026-11-13, announced with the Prime Intellect acquisition on 2026-10-14) has passed. `MoondreamService` runs the model locally through transformers and neither it nor the two examples touches a Moondream cloud endpoint, so nothing broke; the open weights remain on Hugging Face. Every `moondream` extra pin still admits the latest PyPI release, including transformers 5.24.0 (2026-11-21) and accelerate 1.16.0 (2026-11-16).
