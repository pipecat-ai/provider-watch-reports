# Qwen LLM — 2026-09-01

`qwen-plus` is current enough to keep — it serves, it is not on any retirement list, and it is the
only Qwen chat model probed that does not reason by default — but the alias is frozen on a
July-2025 snapshot, so the default deserves a maintainer's look. No branch.

## What's new for Pipecat

### PRs
Nothing.

### To consider

- **Default `qwen-plus` is four generations behind** (medium, since 2026-09-01) — the alias resolves
  to `qwen-plus-2025-07-28`, a Qwen3-generation snapshot, while DashScope now serves
  `qwen3.5-plus`, `qwen3.6-plus`, `qwen3.7-plus` (GA 2026-06-01) and the `qwen3.8-max`/`qwen3.8-flash`
  flagships. Alibaba has not deprecated `qwen-plus` and still describes it as the recommended
  balanced model, and aiewf-eval's medium-context leaderboard has no row for `qwen-plus` or for any
  DashScope-hosted successor — its only Qwen rows are self-hosted quantized dense models. — *Needs a
  call: which successor to adopt, and whether a hosted model with no aiewf-eval row can replace a
  default that has no row either.*
- **Thinking is on by default on every Qwen3.5+ model** (medium, since 2026-09-01) — `qwen3.7-plus`
  spent 1897 ms thinking on "What is the capital of France?" and `qwen3.8-27b` 4981 ms on a
  one-step arithmetic prompt, seconds a voice pipeline pays before the first answer token. DashScope
  takes `enable_thinking` in `extra_body`, which today is reachable only as
  `settings=QwenLLMService.Settings(extra={"extra_body": {"enable_thinking": False}})` — that works
  (TTFAT 3010 ms → 1599 ms) but is undiscoverable. Any default bump depends on settling this first,
  as do the aiewf-eval rows, which are all "thinking off". — *Needs a call: add an `enable_thinking`
  Settings field, or follow pipecat-ai/pipecat#5446's Anthropic precedent and disable thinking by
  default for thinking-capable Qwen models.*
- **Function-calling example pins `qwen3.6-27b`** (low, since 2026-09-01) — the model still serves;
  its successor `qwen3.8-27b` scores 98.2% on aiewf-eval's `aiwf_medium_context` against 97.3% for
  `qwen3.6-27b`, both thinking off. — *Needs a call: whether examples track the newest dense model,
  and it carries the same thinking-off question.*
