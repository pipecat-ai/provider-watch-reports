# Anthropic LLM — 2026-08-31

Nothing changed on Anthropic's side this week; the one thing worth a maintainer's
attention is effort, which this run measured at 2.7 s of TTFAT on the model Pipecat
ships as its default.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Effort control on the default model** (high, since 2026-08-25) — `output_config.effort` (`low`…`max`, no beta header) has no `Settings` field. Anthropic's effort page now tells Sonnet 4.6 users in as many words to "explicitly set effort when using Sonnet 4.6 to avoid unexpected latency", recommending `medium` as the everyday default and `low` for latency-sensitive work — and Sonnet 4.6 is our default model. Probed on a scheduling question, the provider default (`high`) gave TTFAT 4002 ms against 1264 ms with `extra={"output_config": {"effort": "low"}}`; a trivial prompt was 1178 ms either way. `extra` is the only route today. — *Needs a call: whether to expose Anthropic's nested `output_config` or a flat `effort` field, and whether Pipecat should pick a low-latency level on Sonnet 4.6 the way `_maybe_disable_thinking` already does for Sonnet 5.*
- **SDK pin behind the current major** (medium, since 2026-08-25) — `pyproject.toml` pins `anthropic>=0.49.0,<1`; the SDK is now at 1.2.0 (1.0.0 on 2026-08-20). Anthropic's deprecation page states the Python SDK 1.x removes `temperature`, `top_p` and `top_k` outright so passing them raises `TypeError`, and `_process_context` puts all three in every request, sentinel or not; 1.0 also moves the client to httpx2 and 1.1 removed the legacy response API. — *Needs a call: dropping the sampling parameters from the Anthropic request path, which changes what `Settings.temperature`, `top_k` and `top_p` do.*
- **Thinking dicts crash at request time** (low, since 2026-08-25) — `Settings.from_mapping` coerces a `thinking` dict into a `ThinkingConfig`, but `Settings(thinking={...})` keeps the dict and the turn fails with `'dict' object has no attribute 'model_dump'` at `llm.py:481`. Still reproduces. — *Needs a call: whether the coercion belongs in `__post_init__` so every path accepts the dict form.*
- **Sampling parameters on 4.7-and-later models** (low, since 2026-08-25) — Anthropic returns a 400 for a non-default `temperature`, `top_p` or `top_k` on Claude Opus 4.7 and later, including `claude-sonnet-5`; the service forwards whatever the user set, so carrying settings across a model switch fails the turn. — *Needs a call: warn, drop, or leave it to the provider's error.*

Closed since the last report: the `ThinkingConfig` adaptive-thinking gap (PR #5429, merged
2026-08-25), and the `claude-sonnet-5` default bump, which the team decided against on
aiewf-eval grounds — recorded in `decisions.md`, with the latency half of it shipped in
PRs #5446 and #5447. `AnthropicThinkingConfig.display` types its values as `... | str`, so
the SDK's new beta `updates` display mode already passes through and is not a gap.
