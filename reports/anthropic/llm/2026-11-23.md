# Anthropic LLM — 2026-11-23

Nothing to change in code this run: the Fable 5.2 reasoning-defaults branch
merged, no model shipped since, and the default still works. The one new
finding is a code reading, not a provider change — a streaming turn silently
discards a `betas` list set through `extra`.

## What's new for Pipecat

### PRs
Nothing.

### To consider
- **Sonnet 5.5 as the default** (medium, since 2026-10-28) — unchanged for a third run. `claude-sonnet-5-5` is Active to at least 2027-09-28 and is the replacement Anthropic names for the Sonnet 4.5 retiring on 2026-11-30, and on 2026-10-28 it beat our default through our class on both prompts (TTFAT 462 ms against 777 ms trivial, 466 ms against 921 ms on a scheduling prompt, medians of 5). The blocker is still the benchmark rule: `leaderboard-medium-context.md` carries `claude-sonnet-5-5 (low)` at 99.9% / 838 ms and no live `claude-sonnet-4-6` row, only the archived 100.0% / 850 ms that was copied over without rescoring under the refreshed judge. Neither published Sonnet 5.5 row is the configuration Pipecat sends either: `_THINKING_DEFAULTS` gives it `between_tools` with no effort, so it runs at `high`, while the rows are adaptive at `low` (838 ms) and `between_tools` at `low` (1180 ms). — *Needs a call: whether 99.9% against an archived, differently-judged 100.0% counts as parity, and whether the bump should also set an effort level so the shipped configuration matches a measured one.*
- **Preserved thinking's prefix check** (medium, since 2026-09-14) — Pipecat replays thinking blocks and its history is not append-only: `LLMContextSummarizer._apply_summary` replaces the message list with `set_messages`, and `_should_inject_trailing_user_message` injects a `"."` user turn that is never stored, so an edited earlier turn plus a replayed block is a 400. Fable 5.2 and Mythos 5.2 enforce it for every account; on Fable 5.1, Opus 5.5, Sonnet 5.5 and Haiku 5.5 it binds only accounts created on or after 2026-08-31. Correcting last run: the escape hatch is not merely awkward but unreachable on a conversation turn, because the streaming path overwrites `extra`'s `betas` (next item), and `thinking.block_binding` needs the `thinking-binding-controls-2026-08-01` beta. Still not `high`: the default model does not run the check. — *Needs a call: whether Pipecat should opt into `drop_block` for Anthropic by default, expose `block_binding` as a Settings field, or make the summarizer and the trailing-user injection thinking-aware.*
- **The SDK pin excludes anthropic 2.x** (medium, since 2026-10-28) — our extra pins `anthropic>=0.49.0,<2`; the latest release is now 2.13.0 (2026-11-23), six minors past last run's 2.7.0. Raising the ceiling is not only a number: SDK 2.0.0 sends API version `2026-10-21`, which removes `temperature`, `top_p` and `top_k` for every model and returns a 400 even at their default values. `_apply_sampling_settings` puts them in `extra_body`, which the SDK passes through untyped, so under 2.x they would fail every request that sets them rather than only those on Opus 4.7 and later. Nothing in 2.8.0–2.13.0 is something the service needs; they add error codes, Admin API endpoints, webhook events and a Bedrock profile-ID fix. — *Needs a call: whether to raise the ceiling and make the sampling settings version-aware, or hold the pin until the sampling item below is settled.*
- **A default effort level on Sonnet 4.6** (medium, since 2026-08-25) — `_THINKING_DEFAULTS` disables thinking on Sonnet 4.6, but effort applies to every output token, thinking or not, and the request omits it, so Sonnet 4.6 runs at `high`. The effort page is unchanged — "Claude Sonnet 4.6 defaults to `high` effort. Set effort explicitly to avoid unexpected latency", `medium` recommended, `low` for latency-sensitive work. Moot if the default moves to Sonnet 5.5. — *Needs a call: whether the service should choose an effort level the way `_THINKING_DEFAULTS` already chooses a thinking mode, which trades output quality for latency rather than only latency.*
- **`extra` cannot set `betas` on a conversation turn** (medium, since 2026-11-23) — the streaming path builds the request, merges `extra` at `llm.py:615`, and then at `llm.py:626` does `params.update({"betas": ["interleaved-thinking-2025-05-14"]})`, so whatever the user put in `extra["betas"]` is thrown away without a warning. `run_inference` orders the two the other way (`llm.py:514` before the merge), so `extra` wins there and the two paths disagree about the same key. The consequence is that no Anthropic beta beyond interleaved thinking can be used from a Pipecat conversation: not `fast-mode-2026-02-01`, not `thinking-binding-controls-2026-08-01`, not `message-threads-2026-08-12`. — *Needs a call: whether `extra` should win over the service's own betas or be merged with them, given that the interleaved-thinking beta is load-bearing for thinking between tool calls and dropping it would change behavior.*
- **Fast mode has no typed setting** (low, since 2026-11-09) — `speed: "fast"` is GA without a beta header on Opus 5.5 and Fable 5.2, giving up to 2.5x output tokens per second at double the token price — the kind of knob a voice agent wants. On those two models it is already reachable through `extra`; what is missing is a named field. It is not a clean pass-through, though: Opus 5 and Opus 4.8 still need the `fast-mode-2026-02-01` header, which the item above shows a streaming turn cannot send at all, fast mode on Opus 4.8 is removed on 2026-11-30, and every other model 400s on `speed`. — *Needs a call: whether a parameter only three models accept, and that `extra` already reaches on two of them, earns a typed field.*
- **Thinking dicts crash at request time** (low, since 2026-08-25) — `Settings.from_mapping` coerces a `thinking` dict into a `ThinkingConfig`, but `Settings(thinking={...})` keeps the dict and the turn fails with `'dict' object has no attribute 'model_dump'` at `llm.py:518` (one-shot) and `llm.py:607` (streaming). `AnthropicLLMSettings` still has no `__post_init__` on 218a7f836. — *Needs a call: whether the coercion belongs in `__post_init__` so every path accepts the dict form.*
- **Sampling parameters on 4.7-and-later models** (low, since 2026-08-25) — the parameter table still gives a 400 for `temperature`, `top_p` and `top_k` on Claude Opus 4.7 and later when set to a non-default value. `_apply_sampling_settings` moves them into `extra_body`, so they no longer raise client-side, but they still reach the API and still fail the turn. A second effect appeared on 2026-11-16: on the models that watermark their text, a non-default sampling value can leave the watermark off. Decided together with the SDK pin, which widens the rejection to every model. — *Needs a call: warn, drop, or leave it to the provider's error.*

No model shipped since Fable 5.2, and `_THINKING_DEFAULTS` needs no edit: every
model in the catalogue has an entry at the lowest setting Anthropic documents
for it, and no entry names a retired model. Claude Opus 4.5 was deprecated

names it as a model, and its `_THINKING_DEFAULTS` and `_PREFILL_SUPPORTED_PATTERNS`

comes back `model_not_available` because the organization must have data

next researcher: Fable and Mythos cannot be probed from this account at all.

Nothing else in the release notes since 2026-11-09 touches this service.
Message threads (beta, 2026-11-02) would cut request size and time to first
token, which a voice agent wants, but it needs server-side thread lifecycle
handling and a beta header the streaming path cannot send, so it is a project
rather than a gap. Linked billing, Enterprise Frontier Safeguards, IP

Messages API. No digest-issue comments named this unit.
